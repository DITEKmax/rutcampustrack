## Typography

All sizes use the Transit Grid CSS vars defined in `tokens.css:127–135`. Base font-size on `<html>` is 14px (set in `styles.scss:79`).

**Declared weights: 2 only — 400 (regular) and 600 (semibold).** Weight 500 is not used. Weight 700 is not used — semibold (600) at 24px display size provides sufficient visual hierarchy without a third distinct weight value.

| Role | Size | CSS var | Weight | Font family | Line height | Usage |
|------|------|---------|--------|-------------|-------------|-------|
| Body | 14px | `--text-sm` | 400 | `--font-sans` (DM Sans) | `--leading-body` (1.5) | Lesson meta, room, sidebar labels, paragraph copy |
| Label | 12px | `--text-xs` | 400 (non-emphasized) / 600 (eyebrow/uppercase) | `--font-sans` | 1.4 | Status chips (400), time badges (600), eyebrow labels (600, `text-transform: uppercase; letter-spacing: 0.05em`), section headers (600) |
| Heading | 16px | `--text-base` | 600 | `--font-heading` (General Sans) | `--leading-heading` (1.2) | Lesson subject name in cards, page sub-sections |
| Display | 24px | `--text-2xl` | 600 | `--font-display` (Clash Display) | `--leading-display` (1.1) | Active lesson subject name on `/student/checkin` hero; dashboard greeting; empty-state headings |

**Mono supplement** (not a body role — used for tabular data only):
- Time values (HH:MM): `--text-sm` / `--font-mono` / weight 600 / `font-variant-numeric: tabular-nums`
- User ID chip: `--text-xs` / `--font-mono` / weight 400

## Focal Points

Explicit primary focal point per page:

**`/student/dashboard`**
Primary focal point: `NextLessonCard` — the largest surface element, positioned directly below the greeting hero, visually emphasized with `--border-accent` border and `--glow-primary` box-shadow when the lesson is active. All other dashboard cards (today's summary chips, red-zone warnings) are visually subordinate to this card.

**`/student/schedule`**
Primary focal point: the active/today day tab and the current-time indicator row within the day view. Today's tab is rendered with weight 600 text and `--accent-primary` underline; the current-time position in the lesson list is visually marked by the accent-bordered active lesson row, anchoring the user's temporal position on first load.

**`/student/checkin`**
Primary focal point: the "Отметиться" button — 48px min-height, `--accent-primary` background, pill border-radius (`--radius-full`), centered in the max-width 480px column. When a lesson is active this button is the only interactive element above the fold; all surrounding content (subject name, time/room meta, attendee counter) serves as context for this single action.

### 3. `/student/schedule` — StudentScheduleComponent

Functional parity with PWA `SchedulePage.tsx`, adapted to Angular Material + desktop layout.

**Layout:** Full-width within `.shell__content` max-width container.

| Area | Description |
|---|---|
| Week nav strip | Top bar: `<prev-btn>` `[week range label]` `<next-btn>` `[floating "Сегодня" button]`. Week range format: `"1-6 апр"` or `"28 мар - 3 апр"`. Prev/next buttons: `ph-caret-left` / `ph-caret-right`, 20px, 44×44px tap area. Floating "Сегодня" pill: only shown when not on current week; `--gradient-brand` background; `ph-calendar-blank` 16px fill + "Сегодня" text. |
| Day tabs | 6 tabs (Пн–Сб). Active tab: `--accent-primary` underline + text color. Today's tab: weight 600. Past-day tabs: `--text-muted`. Use `MatTabGroup` with `[selectedIndex]` binding. |
| Lesson list | `<app-lesson-row>` for each lesson. Click → expand inline detail panel (no navigation). Column card layout (not mobile card stack) since desktop has width. Each row: left-rail time (start / station-dot / end), right: subject heading + room meta + status badge. |
| Lesson detail expand | `[@slideDown]` Angular animation on panel below clicked row. Shows: full subject name, lesson number, type badge (лекция/практика/лаб), room, attendance status chip, teacher name (if available from subject data). Close on second click or Escape. |

### 4. `/student/checkin` — StudentCheckinComponent

Centered single-column layout (max-width 480px, `margin: 0 auto`). Full remaining viewport height with flexbox centering.

**State machine:**

| State | Trigger | Visual |
|---|---|---|
| **Idle** — no active lesson | No ACTIVE lesson in today's schedule | Empty state (see below) |
| **Active** — lesson in progress | Lesson status = ACTIVE | Hero card with CTA |
| **GPS pending** | User clicked "Отметиться" | Button shows spinner + "Определяем координаты…" |
| **Submitting** | GPS success, sending to API | Button disabled, spinner |
| **Confirmed** | STOMP `attendance.marked` received OR 2xx HTTP response | Success badge replaces button |
| **Error** | GPS denied or API error | Inline error message under button, button re-enabled |

**Active lesson hero card:**
- Live indicator pill: `ph-circle` 6px fill (blinking via `@keyframes live-blink 1.6s ease-in-out infinite`), "Идёт сейчас" label — `--text-xs` / `--font-sans` / weight 600 / uppercase / letter-spacing 0.05em. Background: `color-mix(in oklab, --accent-primary 12%, transparent)`. Border: `1px solid --border-accent`.
- Subject name: `--text-2xl` / `--font-display` / weight 600 / centered.
- Time + room meta row: `ph-clock` 14px fill + HH:MM–HH:MM (mono tabular-nums) + `ph-map-pin` 14px fill + "Ауд. {room}". Color: `--text-secondary`.
- "Отметиться" button: `mat-flat-button` re-styled — background `--accent-primary`; color `--accent-primary-contrast`; border-radius `--radius-full` (pill); min-height 48px; min-width 180px; font-weight 600. On hover: `filter: brightness(1.08)`. On active: `transform: scale(0.97)`.
- Attendee counter: `ph-users` 12px fill + "{N} отметилось". Color: `--text-muted`. Animated counter (spring from STOMP updates) via Angular `@Input` with `ChangeDetectionStrategy.OnPush`.

**Empty state (Idle):**
- Circle icon container: 80×80px, `--bg-secondary` background, `1px solid --border-subtle`, `ph-clock` 36px duotone, color `--text-muted`.
- Heading: "Нет активной пары" — `--text-2xl` / `--font-display` / weight 600.
- Body: "Отметка станет доступна за 5 минут до начала следующего занятия." — `--text-sm` / `--text-secondary`. Max-width 300px, centered.
- If next planned lesson exists: show `<app-next-lesson-hint>` card (same as NextLessonHint from PWA: "Следующая пара", subject name, start time).
- If no lessons today: `--text-xs` / `--text-muted` — "На сегодня пар больше нет".

**STOMP wiring:**
- Connect on component `ngOnInit`: `StompClient.connect('/api/ws?token={accessToken}')`.
- Subscribe to `/topic/group/{groupId}`.
- On `attendance.marked` event where `userId` matches current user: update local status to `present`, animate button to confirmed badge.
- On component `ngOnDestroy`: disconnect STOMP client.
- Use Angular `signal<CheckinStatus>()` for reactive UI state.

**CTA label note:** The primary CTA label "Отметиться" is intentionally a single verb without an inline noun. Duplicating the noun inside the button would be visually redundant given the centered single-action layout of this page. This pattern matches the PWA implementation and aligns with CLAUDE.md business rule terminology for attendance marking.

## Accessibility Contract

- All interactive elements must have `focus-visible` ring: `2px solid --accent-primary, offset 2px` (already global in `tokens.css:228`).
- "Отметиться" button: `aria-label="Отметиться на текущей паре"` when not yet checked in; `aria-label="Вы уже отметились"` after confirmation; `aria-disabled="true"` when GPS is pending.
- Live STOMP attendee count: `aria-live="polite"` region so screen readers announce updates.
- Live blinking dot: `aria-hidden="true"`.
- Day tabs: `role="tablist"`, each tab `role="tab"`, lesson list `role="tabpanel"`.
- Lesson card expand: `aria-expanded` on the trigger row; `aria-controls` pointing to panel id.
- Skeleton placeholders: `aria-busy="true"` on container, `aria-label="Загрузка…"`.
- Color alone never conveys status — every status chip also has text (б/н/у/сп) per existing global class convention.
- Min touch target: 44×44px for all interactive elements (nav buttons, day tabs, CTA).
