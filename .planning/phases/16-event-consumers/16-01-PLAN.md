6. For each `StudentInfo student` in `members.getStudentsList()`:
   - Build `Query filter = Query.query(Criteria.where("lesson_id").is(lessonId).and("user_id").is(student.getUserId()))`.
   - Build `Update insert = new Update()` with ALL fields via `.setOnInsert(...)`:

     - `"group_id"` -> `groupId`

     - `"semester_id"` -> `semesterId` (may be null)
     - `"lesson_number"` -> `lesson.getLessonNumber()`
