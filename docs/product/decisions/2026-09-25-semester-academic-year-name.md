# Название семестра по учебному году

Решение владельца 2026-09-25 в главном чате: для осеннего семестра с сентября 2026 по январь 2027 использовать **«Осенний 2026/2027» — учебный год**.

Это закрывает вопрос формата года для принятой формы создания/редактирования семестра. Название должно формироваться из структурированных данных типа и учебного года. Старым записям не следует автоматически приписывать тип по тексту названия или массово менять сохранённое имя.

Решение не отменяет серверные ограничения пересечения периодов, правки завершённого семестра и изменения дат при существующих назначениях. Создание текущего семестра с настоящей датой начала в прошлом разрешено ранее.
