## Контракт переноса

1. Главная начинается с пар дня. Группы и назначения следуют за расписанием и занимают боковую колонку при достаточной ширине. Активная, разовая, перенесённая и отменённая пары различаются по данным, цвету и тексту.
2. Журнал сохраняет три строки шапки, закреплённое имя, внутреннюю прокрутку и точные ячейки. Перекрестие при наведении или фокусе лавандовое. Календарь и ввод даты связаны с применённым периодом и форматом выгрузки.
3. Из отметки открывается одна заявка, документ принадлежит точной паре и студенту. Проверяются ожидающая заявка, файл, запасной вариант просмотра и возврат фокуса.
4. В статистике режимы студентов и групп сохраняют свои поля, сортировку, пустой результат и возвраты. Карта, настройки и уведомления используют общие изменения Web.

В HTML на 1280 CSS px порядок начинается с «Пары на 5 нояб.». Текущая пара `#DDCFF9`, разовая `#E4F9F1`, отменённая `#FDECEC` с причиной отмены. Перенос отмечен текстом. Полный шаблонный diff расходится с уже перенесённым общим профилем.

### Документы

- У ручной причины Web теперь использует точный `GET /api/v1/teacher/lessons/{lessonId}/students/{studentId}/excuse/attachments/{attachmentId}`. Это действующий защищённый контракт, реализованный и проверенный в [архиве PWA/TMA преподавателя](03-TEACHER-MOBILE.md).
- Пара 1002, студент 503 открыли PDF. После закрытия фокус вернулся к исходной отметке. Студент 506 открыл свой PNG, предыдущий файл исчез. Обычная заявка открыла отдельную «Справка.pdf» по ID заявки и вложения.
- При 503 отсутствовала ссылка на скачивание. Явный повтор запросил те же три ID и отрисовал документ. Для истёкшего файла запрос не отправился. Неподдерживаемый HTML не отрисовался и не получил ссылку на скачивание.
- До исправления PDF из проверенных байтов не отображался из-за `fetch(blob:)` при действующей CSP. Общий компонент принимает уже проверенный Blob и соблюдает прежний лимит 20 МБ. При тех же заголовках рабочий PDF отрисовал canvas шириной 369 px. При сбое разбора показано сообщение по-русски, доступно отдельное открытие и скачивание.

Матрица содержит 28 сочетаний семи маршрутов, двух тем и ширин 390/1280 px. Прокрутка страницы по горизонтали отсутствует. Четыре рабочих маршрута дополнительно проверены при шрифте 125%. Снимок и замеры в `.agent/evidence/web-teacher-v2`.
