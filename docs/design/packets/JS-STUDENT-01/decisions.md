# Решения владельца

## 06.09.2026 — незахваченные UI-состояния

Владелец разрешил проектировать loading, error, offline, responsive, PWA-host и
TMA-host по ходу реализации, опираясь на существующие tokens, компоненты, логику
интерфейса и предметную область. Отсутствие Figma-node для этих состояний не делает
данный пакет blocked и не требуется отдельное согласование на их дизайн.

Решение не вводит API-контракт, backend/authz policy или runtime host behavior. Они
останутся отдельными gates реализации.
