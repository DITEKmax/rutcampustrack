## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-06 | I (Info Disclosure) | headman_alerts.py | mitigate | Only headmen (is_headman=True) receive excuse/late-checkin notifications. Filter applied before send_queue.put. Non-headman students never see these messages. |
| T-24-07 | T (Tampering) | homework payload | mitigate | Validate required fields (group_id, title) exist before processing. Missing fields cause KeyError caught by dispatcher's try/except, logged, message acked. |
| T-24-08 | D (Denial of Service) | consumer ack timing | mitigate | Handler exceptions caught inside dispatcher. Message always acked via `async with message.process()`. No infinite requeue on partial failure. |
| T-24-09 | R (Repudiation) | event processing | accept | Events logged at INFO level on receipt. No audit trail needed for notifications (best-effort delivery model per REQUIREMENTS.md out-of-scope). |
</threat_model>
