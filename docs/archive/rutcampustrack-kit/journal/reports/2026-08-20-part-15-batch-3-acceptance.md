## Запрос переопределений, который надо повторять на следующих страницах

Имя запроса: **`direct-instance-overrides-v1`**. Он читает штатное
`InstanceNode.overrides`, исключает экземпляры, которые находятся внутри
другого экземпляра, и сравнивает живое поле с соответствующим полем мастера.

```js
const instances = frame
  .findAllWithCriteria({ types: ['INSTANCE'] })
  .filter(instance => !hasInstanceAncestor(instance, frame))

for (const instance of instances) {
  const master = await instance.getMainComponentAsync()

  for (const override of instance.overrides) {
    const live = await figma.getNodeByIdAsync(override.id)
    const source = override.id === instance.id
      ? master
      : await figma.getNodeByIdAsync(override.id.split(';').at(-1))

    for (const field of override.overriddenFields) {
      emit({
        frame: frame.name,
        instance: instance.name,
        master: master?.name,
        node: live?.name,
        field,
        live: readField(live, field),
        source: readField(source, field),
      })
    }
  }
}
```

Важно сохранять три счётчика: **действующее** переопределение отличается от
мастера сейчас; **застывшее** числится в `overrides`, но уже равно мастеру;
**осиротевшее** ссылается на внутренний live-узел, которого больше нет.
Застывшее поле визуально не видно, однако оно может заблокировать следующую
правку мастера; осиротевшее уже не может принять значение.

## Отсоединённые экземпляры, потерянные правки и литералы

- `DETACHED` и фреймы с именем `block/*` вместо экземпляра: **0** на 48
  продуктовых кадрах.
- Осиротевшие override: **14 полей на 14 экземплярах**. У 101 CurrentLesson
  dark/light 1920 потерян live-узел для `primaryAxisAlignItems` (2 поля); у
  ModeTabs 102 и Tabs 107 во всех темах и ширинах потерян live-узел для
  `visible` третьей вкладки (12 полей). Source-узлы мастеров существуют, а
  адресованные внутренние live-узлы экземпляров — нет, поэтому это
  подтверждённый структурный разрыв. Исторического снимка до правки нет и
  восстановить прежнее визуальное значение только из массива невозможно.
- Застывшие override: **591 поле** на странице. Это не потеря, но будущий риск:
  поле уже равно мастеру, однако остаётся прямым override.
