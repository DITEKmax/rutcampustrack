# Счётчики главной администратора — решение владельца 2026-09-23

Владелец подтвердил: «Только активные роли и действующие группы».

- Студенты и преподаватели: уникальные пользователи с соответствующей активной ролью в каноническом user_role_grants. Один пользователь с двумя активными ролями учитывается в обоих счётчиках. Приостановленная/архивная роль не считается.
- Действующие группы: использовать существующее определение ACTIVE реестра групп, чтобы главная и реестр не расходились. DRAFT и ARCHIVED в этот счётчик не входят.
- Не использовать legacy одиночное users.role для многоролевого подсчёта. Права доступа не расширять: агрегат только ADMIN.
- Это решение о трёх текущих счётчиках. Оно не определяет новые правила пяти метрик активности и не разрешает выдумывать суточные дельты; эти критерии остаются отдельными.

Связь: JS-ADMIN-11; docs/wireframes/admin/131-admin-home.md содержит расширенный desktop scope, который не объявляется закрытым этими тремя mobile-карточками.
