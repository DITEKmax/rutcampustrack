**Test class setup:**
```java
package ru.rutcampustrack.schedule.grpc;

class ScheduleGrpcServiceImplTest extends AbstractScheduleIntegrationTest {

    @Autowired
    ScheduleGrpcServiceImpl grpcService;

    @Autowired
    LessonRepository lessonRepository;

    @Autowired
    ScheduleItemRepository scheduleItemRepository;

    @MockitoBean
    AcademicGrpcClient academicGrpcClient;  // Prevent outbound gRPC to academic-service

    @AfterEach
    void cleanup() {
        lessonRepository.deleteAll();
        scheduleItemRepository.deleteAll();
    }
```

CRITICAL: `@MockitoBean AcademicGrpcClient` is MANDATORY — without it, Spring context startup fails with `StatusRuntimeException: UNAVAILABLE` because AcademicGrpcClient tries to connect to academic-service port 19091 which is not running in tests.

CRITICAL: Do NOT use `@Transactional` on the test class — it would wrap each test in a transaction that rolls back, preventing `@TransactionalEventListener(AFTER_COMMIT)` from firing (not relevant here but is the established pattern in this project; see `LessonStatusTransitionJobTest`). Use `@AfterEach cleanup()` instead.
