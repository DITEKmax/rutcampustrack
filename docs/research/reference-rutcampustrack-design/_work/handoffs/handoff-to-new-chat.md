# Handoff: как продолжить работу в новом чате

Когда контекст текущего чата заполнился — открой **новый обычный чат** (не внутри Claude Project: инструкции проекта ограничивают его этапом 1 и запрещают писать код).

**Приложи:** `README.md` и `_work/knowledge/PROJECT_CONTEXT.md`
**Отправь текст ниже.**

Дополнительно прикладывай по ситуации:
- разговор про компоненты → `01-wireframes/registry/COMPONENT_REGISTRY.md` (66 КБ, только если нужен)
- разговор про API/GraphQL → `02-backend/backend-requests.md`
- разговор про конкретный экран → соответствующий файл из `01-wireframes/`

## Что этот промпт НЕ передаёт

Осознанно опущено, чтобы не раздувать:

- Детали разбора конкретных экранов — приложи нужный файл из `01-wireframes/`
- Полный список из 112 эндпоинтов — приложи `api-digest.md`
- Историю решений (почему отказались от старого брендбука, почему не Claude Design) — в `_work/plans/`
- Содержимое реестра — приложи файл, если разговор про компоненты

Если новый чат начнёт советовать то, что мы уже отвергли (Claude Design для основного пайплайна, старый брендбук, загрузку сырых OpenAPI в знания) — скажи об этом, и он поправится.
