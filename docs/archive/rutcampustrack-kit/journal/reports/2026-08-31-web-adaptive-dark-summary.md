## Накопленные долги

1. `AttendanceTrendChart`: мастер не ремонтировался. Историческое предложение —
   ветка `width=768` за **156 A** с алиасами 600/425/300; решение не принято.
   Перед отдельной партией охват снять заново.
2. Дубли смысла — отдельная партия: `Checkbox` `1541:4015` ↔ `71:86` и
   `attendance/TicketForm` ↔ `block/TicketForm`. Историческая оценка удаления
   дублей: `−49 A` и `−19 A`; число потребителей устаревает после каждой
   экранной партии и требует свежего baseline.
3. `block/TicketForm width=300`: ветка ценой **2 A** не заводилась; внешний
   адаптер 425 продолжает содержать вложенный `attendance/TicketForm width=300`.
4. Общий проход `border/interactive` (`neutral/500`) и смысловых размерных
   токенов отложен до завершения web-adaptive. Из конкретных мест остаётся
   `pager/value-min-width=120`: `StepPager/Value` пока использует литерал.
5. Узкая light-тема не собрана для student/headman/teacher; auth light 1920→300
   уже существует. Публикация остаётся действием владельца.
6. Admin narrow 1024→300 — следующий ролевой проход по фактическому состоянию
   page 20. PWA и Telegram Mini App, включая окончательное телефонное
   представление журналов, остаются отдельным циклом.
