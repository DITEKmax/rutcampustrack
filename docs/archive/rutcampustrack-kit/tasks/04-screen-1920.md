# Этап 4 — сборка экрана 1920

Начинается после проверки этапа 3.

## Первый экран — 101, главная студента

Спека: `specs/wireframes/student/101-student-home.md`. Читать целиком,
состав экрана брать только оттуда.

Почему он первый: на нём одновременно график, плотный список,
карточки метрик, полоса заполнения времени и единственный
выделенный объект. Если система выдерживает его — выдержит остальные.

## Правила сборки

- Экран собирается **из блоков этапа 3**. Ни одного нового компонента,
  ни одного нового блока без причины, записанной отдельно.
- Выделен **ровно один объект** — текущая пара.
- Прошедшие пары полновесны, будущие приглушены.
- Данные выдуманные, но правдоподобные и русские. Никакой рыбы
  и английских подписей.
- Сначала 1920. Ширины 1440 и 1280 — переключением вариантов блоков,
  после того как 1920 принят.

## Проверка

- [ ] Все блоки из спеки на месте, лишних нет
- [ ] Три независимых контекста периода не слиты в один
- [ ] Выделен один объект
- [ ] Обе темы
- [ ] Экран собран из блоков, а не из новых слоёв
