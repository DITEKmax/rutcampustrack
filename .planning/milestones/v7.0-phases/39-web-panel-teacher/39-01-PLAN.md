    - `journalData = signal<JournalResponse | null>(null)`
    - `loading = signal(false)`
    - `error = signal<string | null>(null)`
    - `selectedGroupId = signal<number | null>(null)`

    - `dateFrom = signal<string>('')` — default to first day of current month (computed on init)

    **On init (`ngOnInit`):**
    1. Call `journalApi.getMyAssignments()` to get teacher's assigned group+subject IDs
    2. Call `journalApi.getGroups()` — filter to only groups whose `id` is in assignments' `groupId` set
    3. Store filtered groups in `groups` signal
    4. Set `dateFrom` to first day of current month: `new Date(new Date().getFullYear(), new Date().getMonth(), 1).toISOString().slice(0,10)`
    5. Set `dateTo` to today: `new Date().toISOString().slice(0,10)`

    **On group selected (`onGroupChange(groupId)`):**
    1. Set `selectedGroupId(groupId)`
    2. Filter assignments by groupId to get available subjectIds
    3. Call `journalApi.getSubjects()` — filter to subjects whose `id` is in the filtered subjectIds
    4. Store in `subjects` signal
    5. Reset `selectedSubjectId(null)` and `journalData(null)`

    **On "Показать журнал" click (`loadJournal()`):**
    1. Set `loading(true)`, `error(null)`
    2. Call `journalApi.getJournal(selectedGroupId()!, selectedSubjectId()!, dateFrom(), dateTo())`
    3. On success: set `journalData(response)`, `loading(false)`
    4. On error: set `error('Не удалось загрузить журнал. Проверьте соединение и попробуйте снова.')`, `loading(false)`
