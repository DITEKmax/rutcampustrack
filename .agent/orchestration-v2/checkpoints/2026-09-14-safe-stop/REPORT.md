## Проценты: что они означают

Полный продукт нельзя честно оценить одним измеренным процентом: не зафиксирован полный вес сценариев всех ролей, а наличие старых API не доказывает их работоспособность. Число тестов, строк и операций API не является процентом готового продукта.

Для семи активных пакетов вводится прозрачный **индекс технической готовности**, не доля выполненного времени или всего продукта: по 20 баллов за принятый контракт, завершённый код, пройденные проверки, актуальное независимое review, интеграцию/сквозную приёмку. Частично выполненный этап — 10. Устаревшее review не засчитывается. Равные веса — условность для планирования, а не оценка трудозатрат.

|---|---:|---:|---:|---:|---:|---:|
| Binding-контракты Schedule L3 |20|20|20|20|0|80%|
| Чтение карты M2/M3 |20|20|0|20|0|60%|

Средний индекс этих семи пакетов — **51%**. Он не означает «продукт готов на 51%». Полностью принятый изолированный пакет: 1/7 = 14%; source-review PASS: 2/7 = 29%; новые пакеты, интегрированные сегодня в E: 0/7 = 0%. При этом ранее принятая функциональность E сохраняется.
