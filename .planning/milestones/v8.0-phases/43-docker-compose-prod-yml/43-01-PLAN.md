management:

        include: health,info

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-43-06 | Tampering | MongoDB unauthenticated | accept | MongoDB has no auth configured (inherited from dev). Out of scope for Phase 43 (DOCK-05/06/07/MON-03 only). Container is on private_net, not host-exposed. |
