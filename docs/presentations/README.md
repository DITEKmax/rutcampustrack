# Демонстрация экранов RutCampusTrack

Открой `index.html` локально.

- `student-final.html` — принятые экраны студента.
- `headman-final.html` — объединённые финальные экраны старосты по типам.

Изображения и Onest встроены. Слева PWA, справа браузерная TMA. Поиск, фильтр типов, увеличение и нижние кадры доступны без сервера. Это галерея сохранённых состояний, а интерактивные экраны реализованы в приложении.

Состояния реальных компонентов Vue с тестовым API. TMA показана в браузерной оболочке; это не проверка внутри Telegram. Профиль и Ещё используют принятые кадры предыдущей итерации с проверенной неизменностью зависимостей. Выбор темы сохраняется, палитра пока тёмная.

Семь предыдущих HTML сохранены неизменными как архив. `manifest.json` содержит количества, SHA256 и provenance; Student в этой итерации не пересобран.
