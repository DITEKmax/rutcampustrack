## Порядок переноса

1. Главная, список и карточка заявок, обе формы.
2. Расписание и календарь, посещаемость, статистика и рейтинг, задания, карта, уведомления и меню.
3. Общие настройки Web, включая открываемые по запросу аватар, историю, сессии и пароль.
4. Сверка предложения и действующего Vue на 1280 и 390 CSS px, в двух темах и с реальными сценариями запросов.

Рабочее полотно и контролы Web получают семантические токены. Верхняя навигация и структура маршрутов берутся из текущего приложения. Применяются действующие владельцы данных и права. Синтетические данные используются в отдельном локальном стенде для проверки интерфейса.

## Сверка перед изменениями

- Внутренний браузер открыл обе версии эталона и текущую главную Web. На светлом предложении фон рабочей области `#EAE7F0`, кнопка отметки `#DDCFF9`. Текущий Web использует прозрачную рабочую область и другой цвет кнопки.
- В предложении действия «Подать уважительную причину» и «Забыл отметиться» вынесены в свою группу. Текущий Web показывает буквенные обозначения и ставит номер заявки первым.

## Изменения и проверка

- Рабочий фон в действующем Vue совпал с цветами пакета в обеих темах. На главной действие текущей пары осталось первым и получило лавандовый акцент. Блок установки перенесён вниз. Доступность нативного приглашения зависит от браузера.
- В заявках раздельно оформлены создание и фильтр. Причина, статус, дата и число пар видны в списке. Номер и подробности открываются по запросу. При изменении границы дат сбрасывается выбор пары, даже если та остаётся в диапазоне. Начальное заполнение из карточки использует точный ID.
- В общих настройках четыре секции закрыты при входе. Выбор аватара в локальной сессии сохранился. В форме пароля клавиатурой проверены открытие, сворачивание, сохранение введённого черновика и переключение видимости. Пустая форма блокирует отправку.
- В расписании собраны период, календарь и режим. Стрелка переместила фокус с 30 на 29 сентября, Escape вернул его на кнопку. Переход к текущему периоду снова показал изменённую аудиторию.
- В посещаемости узкая область таблицы занимает 353 CSS px при содержимом шириной 1224 px. Заголовок светлой таблицы `#F4F0FA`. Переключение на предмет показало значение 66,7%. В статистике открывается своя строка рейтинга, сравнение с группой и точка без данных с прочерками и нулём учтённых пар.
- В заданиях на 390 px проверены День, Неделя и Месяц, группировка по дням и отметка выполнения. На карте проверены выбор этажа, масштаб, сброс к 100% и подготовка скачивания PNG/SVG. В уведомлениях проверены раскрытие текста, отметка о прочтении, закрытие меню кликом снаружи и переход к заданию.
- Проверены 40 сочетаний десяти маршрутов, двух тем и ширин 390/1280 CSS px. Прокрутка страницы по горизонтали отсутствует, таблицы прокручиваются внутри своих областей. Измерения сохранены в `.agent/evidence/web-student-v2/layout-matrix.json`.
- Для общего вызова Web старосты передан точный ID открытого студента в `useHeadmanCredentials`. Это стыковка с обязательным контекстом из мобильного пакета. В браузере после смены роли и открытия настроек Алексея Громова получен результат «Студент изменил пароль. Старый пароль недоступен». Проверен возврат к главной студента.

### Заявки на локальном стенде

| Сценарий | Наблюдение |
|---|---|
| Уважительная причина на 390 px | Отменённая пара скрыта. Изменение дат сбросило выбранную пару при пересекающемся диапазоне. Для «Другое» нужен комментарий. Возврат из подтверждения сохранил ввод без отправки. |
| Отправка, отмена и архив | Один POST с одним ключом, одна подтверждённая отмена. Заявка 7101 появилась в архиве. |
| Пропущенная отметка с потерянным ответом | Выбрана одна пара. После 503 форма заблокировалась до уточнения результата. Два POST использовали один ключ и дали одну заявку. |
| Исчерпанный бюджет | После загрузки показано пояснение, действие «Забыл отметиться» заблокировано, уважительная причина доступна. Ноль POST. |
| Сессия только для чтения | Обе формы и отмена недоступны. Карточка читается. Ноль POST. |
| Прямая карточка 7005 | PNG открылся после одного GET точного вложения. Кнопки отдельного открытия и скачивания используют выданный локальный URL. |
| Архивная карточка 7003 | Отдельно подписаны дата подачи 22 сентября, 12:15 МСК и решения 24 сентября, 11:30 МСК. После сворачивания и повторного открытия обе даты сохранились. |

Проверки выполнены на рабочем Vue и локальных ответах. ### Сервер и ревью

- Семь сценариев существующего Attendance-контракта прошли на MongoDB. Проверены оба вида заявок, остаток бюджета, точный повтор, ограничения файлов, отсутствие данных соседнего владельца и обязательный комментарий.
- Шесть тестов формата и фасада BFF прошли. В подписанном HTTP → gRPC прошли чтение и выполнение ДЗ с обычным доступом и запрет выполнения при доступном чтении в режиме просмотра. В обоих запусках первый вызов к холодному Academic превысил дедлайн. Случай режима просмотра прошёл при адресном повторе вторым, исторический вызов в начале этого прогона получил 503. Оба XML сохранены в локальных доказательствах.
- Независимое ревью нашло двойную подпись даты решения. Исправление проверено отдельным регрессионным тестом, в браузере на заявке 7003 и на повторном независимом ревью.
- Сборка Web со строгой проверкой типов прошла после исправления стыка старосты. Прошли 66 целевых тестов в семи наборах, затем восемь тестов после исправления подписи и проверка изменённых строк ESLint. В широком прогоне два падения в тестах выбора заявок мобильного старосты. Их причина ещё проверяется.
