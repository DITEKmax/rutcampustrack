**4. Create OtpService.java** (package `ru.rutcampustrack.auth.service`):

```java
@Service
public class OtpService {
    private final StringRedisTemplate redisTemplate;
    private final OtpProperties otpProperties;
    private final UserRepository userRepository;
    private final JwtService jwtService;
    private final JwtProperties jwtProperties;
    private final SecureRandom secureRandom = new SecureRandom();
```

Constructor injection for all 5 dependencies.

**Method `requestOtp(OtpRequest request)`** returning `void`:
1. Lookup user: `userRepository.findByTelegramId(request.telegramId())` — throw `InvalidCredentialsException` if not found
2. Check user status is `AccountStatus.ACTIVE` — throw `InvalidCredentialsException` if not
3. Check resend cooldown: Redis key `otp_sent:{telegramId}`. If exists, throw `new OtpRateLimitException("Please wait before requesting a new code")`
4. Check attempts: Redis key `otp_attempts:{telegramId}`. If value exists and `Integer.parseInt(value) >= otpProperties.maxAttempts()`, throw `new OtpRateLimitException("Too many OTP requests. Try again later")`
5. Generate 6-digit code: `String.format("%06d", secureRandom.nextInt(1_000_000))`
6. Store in Redis: key `otp:{telegramId}`, value = code, TTL = `otpProperties.ttlSeconds()` seconds
7. Set resend cooldown: key `otp_sent:{telegramId}`, value = `"1"`, TTL = `otpProperties.resendCooldownSeconds()` seconds
8. Increment attempts: `redisTemplate.opsForValue().increment("otp_attempts:" + telegramId)` — if the key is new, also set expiration to `otpProperties.attemptsWindowSeconds()` seconds (use `redisTemplate.expire()` only when increment returns 1L, meaning first attempt)

NOTE: The method does NOT send the OTP to Telegram. That will be handled by notification-bot in a future phase. For now, the code is only stored in Redis (can be read during testing via redis-cli).

**Method `verifyOtp(OtpVerifyRequest request)`** returning `TokenResponse`:
1. Lookup user: `userRepository.findByTelegramId(request.telegramId())` — throw `InvalidCredentialsException` if not found
2. Check user status is ACTIVE — throw `InvalidCredentialsException` if not
3. Get stored code: `redisTemplate.opsForValue().get("otp:" + request.telegramId())`
4. If stored code is null, throw `new OtpExpiredException()`
5. If `!storedCode.equals(request.code())`, throw `new OtpExpiredException()` (same exception for security — don't reveal if expired vs wrong)
6. Delete OTP key from Redis: `redisTemplate.delete("otp:" + request.telegramId())`
7. Delete attempts key: `redisTemplate.delete("otp_attempts:" + request.telegramId())`
8. Delete cooldown key: `redisTemplate.delete("otp_sent:" + request.telegramId())`
9. Generate JWT pair (same as login flow):
   - `String accessToken = jwtService.generateAccessToken(user);`
   - `String refreshToken = jwtService.generateRefreshToken(user);`
   - `String jti = jwtService.extractJti(refreshToken);`
   - Store refresh token in Redis: `redisTemplate.opsForValue().set("refresh:" + user.getId() + ":" + jti, "valid", Duration.ofSeconds(jwtProperties.refreshTokenExpiration()));`
10. Return `new TokenResponse(accessToken, refreshToken, jwtProperties.accessTokenExpiration())`
