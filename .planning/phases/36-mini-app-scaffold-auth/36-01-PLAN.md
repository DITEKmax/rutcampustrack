   - `onEvent` handler: responds to `web_app_request_theme` with `emitEvent('theme_changed', { theme_params: mockTheme })` and `web_app_request_viewport` with `emitEvent('viewport_changed', { height: window.innerHeight, width: window.innerWidth, is_expanded: true, is_state_stable: true })`

**src/main.tsx** — Per D-09, TMA-01. Async bootstrap function:
1. Import `setupMockEnv` from `@/shared/lib/mockWebApp`
2. Await `setupMockEnv()` — MUST run BEFORE `init()` (Pitfall 3)
3. Import and call `init()` from `@telegram-apps/sdk-react`
4. If `viewport.mount.isAvailable()`, await `viewport.mount()` then call `viewport.expand()` — wrap in try/catch
5. Call `miniApp.ready()` — CRITICAL for TMA-01 (prevents blank screen in Telegram, signals Telegram to hide loading splash)
6. Dynamic import `App` component: `const { default: App } = await import('./App')`
7. Render with `ReactDOM.createRoot(document.getElementById('root')!).render(<StrictMode><App /></StrictMode>)`

Wrap entire bootstrap in try/catch. On error, still call `miniApp.ready()` in catch block to prevent permanent blank screen, then render a minimal error div.
