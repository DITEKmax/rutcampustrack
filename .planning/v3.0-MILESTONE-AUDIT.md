## Cross-Phase Integration

**Score:** 24/25 wiring points verified

### Warnings (2)

1. **IllegalArgumentException → HTTP 500** (TMPL-01, TMPL-02, TMPL-03)
   - `ScheduleItemService` throws `IllegalArgumentException` for semesterId mismatch
   - `GlobalExceptionHandler` has no handler for it — falls through to catch-all → 500
   - `GrpcExceptionAdvice` correctly handles it for gRPC (→ INVALID_ARGUMENT)
   - Fix: Add `@ExceptionHandler(IllegalArgumentException.class)` returning 400

2. **LSSN-03 idempotency not fully implemented** (LSSN-01, LSSN-03)
   - `UNIQUE(schedule_item_id, date)` constraint exists in DDL
   - `LessonGenerationService.saveAll()` uses plain JPA, no `ON CONFLICT DO NOTHING`
   - Retry throws `DataIntegrityViolationException` (409) instead of silent dedup
   - Fix: Use native INSERT with ON CONFLICT DO NOTHING or catch-and-ignore

### Info (3)

3. **JPA flush behavior dependency** (CRON-01, CRON-02) — `LessonStatusTransitionJob` two-phase approach relies on `FlushMode.AUTO` implicit flush, not explicit commit. Works correctly but comment in code is misleading.

4. **GRPC-03 includes cancelled lessons** (GRPC-03) — Hardcoded status list includes `cancelled`. Attendance Service must filter client-side. API surface inconsistency with REST view endpoint.

5. **Short/integer schema alignment** (EVNT-01) — `lesson_number` serialized as Short, event schema expects integer. Compatible — no action needed.
