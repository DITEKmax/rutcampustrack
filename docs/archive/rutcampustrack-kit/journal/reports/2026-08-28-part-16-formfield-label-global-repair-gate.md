Других расхождений FormField не найдено. Onest, text style, цветовые и

# ✏️ 28.08.2026 — закрытие после решения владельца

## Ответы на вопросы

1. Верен первый вариант объяснения source-роста, но это не заранее
   зарезервированный запас. Длинная служебная подпись мастера реально
   переносится на две строки. `13 px × 140% = 18,2 px`, живая геометрия
   line box — 18 px; две строки дают 36 px.
2. Пустой второй строки нет: `textAutoResize=HEIGHT` вычисляет высоту из
   фактического текста при фиксированной ширине. У всех живых потребителей
   подпись укладывается в одну строку, поэтому row остаётся 18 px, root не
   растёт.
3. Подтверждённый baseline использован без пересчёта по ходу:
   149 default + 7 error = 156 A; экранное закрытие 287; 15
   `Part 16 / Root` исключены.

## Что изменено

Уровень текста:

- `55:8`, `55:14`: `textAutoResize WIDTH_AND_HEIGHT→HEIGHT`;
- те же Label: horizontal sizing `HUG→FILL`.

Уровень контейнера:

- `55:7`, `55:13` Label row: horizontal sizing `HUG→FILL`.
