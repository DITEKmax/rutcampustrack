**3. Create `frontends/pwa/src/shared/hooks/usePullToRefresh.ts` (per D-08):**

A reusable hook that implements pull-to-refresh gesture on touch devices. This hook will be reused by both AttendanceStatsPage (this plan) and HomeworkPage (Plan 02).

```typescript
import { useRef, useEffect, useCallback, useState } from 'react'

interface UsePullToRefreshOptions {
  onRefresh: () => Promise<void>
  threshold?: number // px to pull before triggering, default 80
}

export function usePullToRefresh({ onRefresh, threshold = 80 }: UsePullToRefreshOptions) {
  const containerRef = useRef<HTMLDivElement>(null)
  const [isRefreshing, setIsRefreshing] = useState(false)
  const [pullDistance, setPullDistance] = useState(0)
  const startY = useRef(0)
  const pulling = useRef(false)

  // ... touch event handlers for touchstart/touchmove/touchend
  // Only activate when scrollTop === 0 (at top of list)
  // On touchstart: record startY
  // On touchmove: if pulling down from top, set pullDistance = currentY - startY (capped at threshold * 1.5)
  // On touchend: if pullDistance >= threshold, call onRefresh(); reset state
  // Show a pull indicator: ArrowCounterClockwise icon from phosphor, rotates when isRefreshing

  return { containerRef, isRefreshing, pullDistance }
}
```

The hook attaches `touchstart`, `touchmove`, `touchend` listeners to the container ref. It tracks pull distance and triggers `onRefresh` callback when the user pulls past the threshold. Returns `containerRef` (attach to scrollable container), `isRefreshing` (show spinner), and `pullDistance` (for visual indicator positioning).

The pull indicator UI: render a `<div>` above the list content, positioned with `transform: translateY(pullDistance)` during pull. Show `ArrowCounterClockwise` icon (from `@phosphor-icons/react`) that spins when `isRefreshing`. Use `transition: transform 0.2s ease` for smooth snap-back.
