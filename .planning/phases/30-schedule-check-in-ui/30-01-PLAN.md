<!-- Backend API contracts verified from Java source -->

Schedule endpoint (via gateway):
GET /api/schedule/groups/{groupId}/lessons?dateFrom=YYYY-MM-DD&dateTo=YYYY-MM-DD&size=100
Response: PagedModel<EntityModel<LessonResponse>>
Access: _embedded?.lessonResponseList ?? [] (Spring HATEOAS omits _embedded on empty)

LessonResponse fields (from LessonResponse.java):
  id: number, scheduleItemId: number, groupId: number, subjectId: number,
  teacherId: number, date: string (YYYY-MM-DD), status: 'PLANNED' | 'ACTIVE' | 'CLOSED' | 'CANCELLED',
  dayOfWeek: number (1=Mon..7=Sun), lessonNumber: number,
  startTime: string (HH:mm:ss), endTime: string (HH:mm:ss),
  weekType: 'NUMERATOR' | 'DENOMINATOR' | 'BOTH', room: string,
  geoBlocked: boolean, cancelReason: string | null, createdAt: string

Subject endpoint: GET /api/academic/subjects/{id}
Response: EntityModel<SubjectResponse> with { id, name, ... }

Auth context: useAuth() returns { user: { id, role, groupId }, accessToken }

Axios client: apiClient at /api with withCredentials:true, Bearer token from AuthProvider
QueryClient: global staleTime 5min, gcTime 10min, retry 1
</interfaces>
