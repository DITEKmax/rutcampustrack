Он включает отдельный source `repo-history`: действующие `docs/**`, `.planning/**` и `CLAUDE.md` отражены как 941 retained existing address с SHA-256 identity, без переноса; на месте исключены 1 current workflow, 1 utility code file и 3 документа, заподозренных по пути как secret (содержимое не читалось). Исключены и не обходились 5 записей каталогов; число их файлов и байтов потомков неизвестно и не записано как ноль. Inventory содержит только метаданные: он не копировал исходные материалы и не менял продукт или runtime. SHA-256 указан для всех кандидатов точного копирования. В раннем ошибочном черновике `.mcp.json` неверно классифицировался как инструкция и хешировался по пути; содержимое не печаталось. Итоговый генератор до хеширования относит его к `config-by-path`, ставит null hash/destination, и только его можно использовать при следующем обновлении. Скрипт сохранён для повторной генерации карты перед будущим копированием; тогда нужно обновить timestamp и checksums.

Во время подготовки источника появились четыре prompt-файла, поэтому ранний inventory не считался финальным. Финальная проверка в `source-snapshot.json` началась `2026-09-05T23:39:05.5829168+03:00`, завершилась `2026-09-05T23:39:05.9493976+03:00` и сверила files/bytes по четырём корням с inventory (`stable: true`).
