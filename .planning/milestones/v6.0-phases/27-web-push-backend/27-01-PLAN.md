```java
@Tag(name = "Push", description = "Web Push subscription management")
@RequestMapping("/push")
public interface PushApi {
    @Operation(summary = "Get VAPID public key")
    @ApiResponse(responseCode = "200", description = "VAPID public key in Base64url")
    @GetMapping("/vapid-public-key")
    ResponseEntity<EntityModel<VapidPublicKeyResponse>> getVapidPublicKey();

    @Operation(summary = "Subscribe to push notifications")
    @ApiResponse(responseCode = "201", description = "Subscription stored")
    @PostMapping("/subscribe")
    ResponseEntity<Void> subscribe(@Valid @RequestBody SubscribeRequest request);

    @Operation(summary = "Unsubscribe from push notifications")
    @ApiResponse(responseCode = "204", description = "Subscription removed")
    @DeleteMapping("/subscribe")
    ResponseEntity<Void> unsubscribe(@Valid @RequestBody UnsubscribeRequest request);
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Gateway -> notification-app | Push subscription requests from untrusted browser clients |
| notification-app -> Push Service (FCM/Mozilla) | Outbound VAPID-signed requests to external push services |
| notification-app -> MongoDB | Push subscription storage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01 | Spoofing | PushApi endpoints | mitigate | Gateway JWT validation + @RequireRole(STUDENT) AOP in Plan 02 ensures only authenticated students can subscribe |
| T-27-02 | Tampering | SubscribeRequest | mitigate | @NotBlank validation on endpoint/keys fields in contract; Jakarta validation in Plan 02 |
| T-27-03 | Information Disclosure | VAPID private key | mitigate | Private key in env var only; never exposed via API; only public key returned by GET /vapid-public-key |
| T-27-04 | Denial of Service | Push subscribe endpoint | accept | Rate limiting deferred to Gateway-level config (not in scope); MongoDB unique index on user+endpoint prevents duplicate subs |
| T-27-05 | Elevation of Privilege | PushApi | mitigate | @RequireRole(STUDENT) on all push endpoints prevents TEACHER/ADMIN from subscribing (by design; teachers use web panel in v8.0) |
</threat_model>
