# Сверка PWA/TMA с Figma — решение владельца 28 сентября 2026
Владелец подтвердил: существующие отклонения от Figma нужно устранить после функционального этапа. Сейчас отдельный фиксинг дизайна не начинать.
До объявления продукта завершённым сверить все целевые экраны и состояния PWA/TMA с соответствующими принятыми фреймами: структура, размеры, размещение, типографика, цвета, иконки, интервалы, навигация, фильтры и действия. Добиться визуального совпадения при размерах макета и корректной адаптации; отсутствующие существенные состояния согласовать, не придумывать молча.
Конкретный обнаруженный пример: TeacherStatsScreen сейчас использует таблицу и дополнительные элементы управления, тогда как показанный владельцем макет FAMILY/32 использует карточки студентов/групп, цветные отметки, компактные значения и другое расположение фильтров. Функциональная приёмка API/состояния одной группы не является приёмкой дизайна этого экрана.
Функциональные исправления продолжаются. Они должны сохранять имеющийся согласованный дизайн и не расширяться в самостоятельный редизайн. Полная визуальная сверка остаётся обязательной частью готового продукта; наличие рабочего API её не заменяет.
