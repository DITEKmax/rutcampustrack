Exceptions:
- Journal grid sticky student column: width 200px (not a spacing token — layout constant inherited from `journal-grid.component.ts`)

- Journal grid row height: 40px — matches teacher grid exactly

- Touch target minimum: 40px height (Material default, aligns with `--space-7/2`)
- `--space-3` (12px): intermediate compact token outside the standard 4/8/16/24/32/48/64 set; required for 48px status cell layout arithmetic (48 − 2×12 = 24px content width)

## Interaction Contracts

### HeadmanJournalGridComponent — clickable cell

**State machine (NEXT_STATUS map):**
```
absent → present → excused → free_attendance → absent
```
`cancelled` is display-only — clicking a `cancelled` cell does nothing (no API call, cursor: default).

**Cell click flow:**
1. User clicks a cell — optimistic update: cell signal updated to `nextStatus` immediately
2. PUT `markAttendance(lessonId, userId, nextStatus)` fires
3. On success: no UI change (already updated)
4. On error: revert signal to previous status, show `MatSnackBar` with message "Не удалось изменить статус. Попробуйте снова." duration 4000ms

**Visual feedback on click:**
- Cursor: `pointer` on all editable cells (status is not `cancelled`)
- `:hover` on editable cell: background `color-mix(in srgb, var(--accent-primary) 8%, transparent)`
- Active/press: `transform: scale(0.92)`, `--duration-fast` (150ms)
- No spinner inside cell — the optimistic update is instant; error reverts

**Loading state (subject switch):**
- `MatProgressBar` (mode=indeterminate) displayed above the journal grid card
- Grid card receives `pointer-events: none` + `opacity: 0.6` while loading
- Duration: `--duration-base` (200ms) CSS transition for opacity

### HeadmanJournalPageComponent — filter bar

Filters displayed in `.page-filters` row:
1. Subject MatSelect — label "Предмет", required; placeholder "Выберите предмет"
2. Date from MatInput — type=date, label "Начало", default = first day of current month
3. Date to MatInput — type=date, label "Конец", default = today
4. "Применить" button (`.btn-brand`) — enabled only when subject is selected

Load trigger: clicking "Применить" (not auto-load on select change, consistent with teacher journal).

### HeadmanExcusesComponent & HeadmanLateCheckinComponent — degradation

Template structure when API returns null (404/error):
```
.page-card
  └── .page-empty
        ├── .page-empty__icon  (ph-clock-countdown for late-checkin, ph-file-text for excuses)
        ├── .page-empty__title  "Нет активных заявок"
        └── .page-empty__text   "Функция находится в разработке. Заявки появятся здесь автоматически."
```
No action buttons rendered. `aria-live="polite"` on the empty container.

### HeadmanStatsComponent — inline threshold edit

Stats table row columns:
1. Subject name (`--text-sm`, `--font-sans`, weight 400)
2. Attendance % per student — `--font-mono`, `--text-sm`, weight 400, colored by red-zone status
3. Group average % — `--font-mono`, `--text-sm`, weight 400
4. Threshold (%) — MatInput `type=number`, `min=0`, `max=100`, width 64px

**Threshold edit flow:**
1. Display: resolved threshold value in MatInput (pre-filled from `resolveThreshold()`)
2. User focuses input — outline: `var(--accent-primary)` ring (`:focus-visible` global rule)
3. On blur or Enter key: if value changed, call `setSubjectThreshold(subjectId, minPercentage)`
4. On success: update the threshold signal for that row; re-evaluate color coding of attendance % cells without page reload
5. On error: revert input value to previous, show MatSnackBar "Не удалось сохранить порог. Попробуйте снова." duration 4000ms
6. Input accepts only integers 0–100; invalid values (NaN, out of range) reset to previous value on blur

## Animation Contract

All 4 new components use `routeFade` trigger (established pattern from Phase 54):
```ts
trigger('routeFade', [
  transition(':enter', [
    style({ opacity: 0, transform: 'translateY(8px)' }),
    animate('200ms cubic-bezier(0.16, 1, 0.3, 1)',
      style({ opacity: 1, transform: 'translateY(0)' })),
  ]),
])
```
Applied via `host: { '[@routeFade]': '' }`. Duration: `200ms` = `--duration-base`.

Journal cell optimistic revert animation: none (instant revert is clearer for data correction).

## Accessibility Contract

- Journal grid cells (`<button>` or `role="button"`): `aria-label="Статус: {statusSymbol}, {studentName}, {date}"` — updated after click
- `cancelled` cells: `aria-disabled="true"`, `tabindex="-1"`
- `MatProgressBar` on journal load: `aria-label="Загрузка журнала"`, `aria-busy="true"` on grid wrapper while loading
- Threshold MatInput: `aria-label="Порог для предмета {subjectName}, процент"`, `aria-describedby` pointing to validation hint
- Empty state containers: `role="status"`, `aria-live="polite"` for degradation messages
- All interactive cells: minimum 40×40px touch target (48px column width satisfies this)
- Keyboard: cell cycle on `Enter` and `Space`; `Escape` on threshold input — blur without saving changes
