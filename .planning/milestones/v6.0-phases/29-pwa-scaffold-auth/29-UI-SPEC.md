## Spacing Scale

Declared values (all multiples of 4, using Tailwind spacing tokens):

| Token | Value | Tailwind class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | p-1, gap-1 | Icon gaps, inline padding |
| sm | 8px | p-2, gap-2 | Compact element spacing, input internal |
| md | 16px | p-4, gap-4 | Default element spacing, card padding |
| lg | 24px | p-6, gap-6 | Section padding, form groups |
| xl | 32px | p-8, gap-8 | Layout container padding (login card) |
| 2xl | 48px | py-12 | Vertical centering offset |
| 3xl | 64px | py-16 | Full-page vertical centering |

**Exceptions:**
- Touch targets (buttons, interactive elements): minimum 44px height — use `min-h-[44px]` on all interactive controls per iOS HIG
- Bottom navigation bar height: 56px (`h-14`) — safe area inset handled by `pb-safe` (env(safe-area-inset-bottom))
- iOS safe area bottom: add `pb-[env(safe-area-inset-bottom)]` to bottom nav wrapper

## Typography

System font stack: `font-sans` (Tailwind default — Inter/system-ui fallback chain). No custom font loading in Phase 29.

| Role | Size | Tailwind | Weight | Line Height | Usage |
|------|------|----------|--------|-------------|-------|
| Body | 16px | text-base | 400 (normal) | 1.5 | Form labels, body text, status messages |
| Label | 14px | text-sm | 400 (normal) | 1.4 | Input helper text, secondary labels, caption |
| Heading | 20px | text-xl | 600 (semibold) | 1.2 | Screen titles, card headings |
| Display | 28px | text-3xl | 600 (semibold) | 1.1 | App name on login screen ("RutTrack") |

**Rules:**
- Only 2 font weights in Phase 29: 400 (normal) and 600 (semibold). The 28px size differential between Display and Heading provides sufficient visual hierarchy without a third weight.
- Do NOT use text sizes outside this table in Phase 29.
- All text must pass WCAG AA contrast (4.5:1 for body, 3:1 for large text).

## Color

shadcn/ui slate theme. All values are Tailwind CSS custom properties set by shadcn — do not hardcode hex values in components, use semantic tokens.

| Role | shadcn token | Tailwind class | Usage |
|------|-------------|----------------|-------|
| Dominant (60%) | `background` | `bg-background` | App shell background, page surfaces |
| Secondary (30%) | `card` / `muted` | `bg-card`, `bg-muted` | Login card, bottom nav, offline banner |
| Accent (10%) | `primary` | `bg-primary`, `text-primary` | **Reserved for:** Login button CTA, active nav indicator dot, link text |
| Destructive | `destructive` | `bg-destructive`, `text-destructive` | Logout confirmation button only |
| Foreground | `foreground` | `text-foreground` | All body text |
| Muted foreground | `muted-foreground` | `text-muted-foreground` | Helper text, placeholders, disabled states |
| Border | `border` | `border` | Input borders, card borders, dividers |

**Accent reserved for (explicit list):**
1. Login button (primary CTA) background
2. Active tab indicator in bottom navigation bar
3. Hyperlink text color (if any inline links appear)

Accent is NOT used for: input focus rings (use `ring` token), status indicators (use semantic green/red/yellow), icons in default state.

**Status colors (semantic, not from 60/30/10 palette):**
- present / success: `text-green-600` / `bg-green-50`
- absent / error: `text-red-600` / `bg-red-50`
- excused / warning: `text-amber-600` / `bg-amber-50`
- offline / info: `text-slate-500` / `bg-slate-100`

**Dark mode:** Do NOT implement dark mode in Phase 29. shadcn default light theme only. Dark mode is deferred.

## Interaction Contract

### Login Form

- **Username field:** `type="text"`, `autocomplete="username"`, `inputmode="text"`, placeholder: "student00001"
- **Password field:** `type="password"`, `autocomplete="current-password"`, no show/hide toggle in Phase 29
- **Submit:** Enter key submits form (no click required), button shows loading spinner while awaiting response
- **Error display:** shadcn `Alert` with `variant="destructive"` placed above the form fields, not inline with inputs
- **Disabled state (offline):** Both inputs `disabled`, button `disabled` with text "Нет подключения"
- **Field validation:** Client-side only — username required (non-empty), password required (non-empty). No format validation — server returns 401 for bad credentials.

### Page Transitions

Use Motion `AnimatePresence` with `key={location.pathname}`:
- Entry: `opacity: 0 → 1`, `y: 8px → 0`, duration: 150ms, easing: `easeOut`
- Exit: `opacity: 1 → 0`, duration: 100ms
- Do NOT animate Login → App Shell transition (immediate replace, no stagger)

### Offline Detection

- Listen to `window.addEventListener('online'/'offline')` in a custom `useNetworkStatus` hook
- `OfflineBanner`: fixed top banner (does not push content), `bg-slate-100 text-slate-600`, height 32px, text: "Нет подключения к интернету"
- Banner animates in/out: `y: -32px → 0` via Motion

### iOS Onboarding Overlay

- Trigger: `navigator.userAgent` contains "iPhone" or "iPad" + `window.navigator.standalone === false` + `localStorage.getItem('ios_onboarding_shown')` is null
- Steps shown:
  1. Иконка Share (стрелка вверх) — "Нажмите «Поделиться»"
  2. Иконка AddSquare — "Выберите «На экран Домой»"
  3. RutTrack icon — "Приложение готово к установке"
- Dismiss: "Понятно" text button at bottom → sets `localStorage.setItem('ios_onboarding_shown', '1')`
- Animation: `AnimatePresence` fade in/out, duration 200ms

## Accessibility Baseline

- All interactive elements: `focus-visible:ring-2 focus-visible:ring-ring` (shadcn default)
- Form inputs: associated `<label>` via `htmlFor`/`id` pairing
- Error Alert: `role="alert"` (shadcn Alert renders this by default)
- Bottom nav: `<nav aria-label="Основная навигация">`, active tab has `aria-current="page"`
- iOS overlay: `role="dialog"`, `aria-modal="true"`, `aria-label="Установка приложения"`
- Minimum contrast: WCAG AA. shadcn slate theme passes by default.
- Touch targets: all buttons and nav items `min-h-[44px] min-w-[44px]`
