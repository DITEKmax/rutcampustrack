## No UI Work in This Phase

Phase 12 is a purely backend phase. It contains:

- Flyway migration V6 in `academic-service` — adds `first_week_type week_type` column to `semesters` table in `academic_db`
- Proto contract extension — adds `first_week_type` field to `SemesterResponse` in `academic.proto`
- `LessonGenerationService` in `schedule-service` — in-memory date iteration logic with week-parity algorithm
- `LessonRepository` query additions — `deletePlannedFromDate()` for re-generation on template update
- Wiring in `ScheduleItemService.createScheduleItem()` and `updateScheduleItem()`

There are no frontend components, screens, pages, forms, modals, or user-facing interactions introduced or modified in this phase. All changes are internal to the backend services.

**Requirements covered:** LSSN-01, LSSN-02
