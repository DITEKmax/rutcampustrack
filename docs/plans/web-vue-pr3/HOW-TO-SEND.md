## Передача

1. Когда владелец даст команду на старт, создать новую cloud задачу для
   DITEKmax/rutcampustrack с веткой codex/web-vue-redesign; выбрать модель
   самостоятельно. Эта ветка основана на проверенном main, при старте сверить
   свежесть. Не создавать вместо неё новую ветку без подготовленной паузы CI.
2. В первом сообщении прикрепить web-vue-handoff-20261023.zip как файл.
   Дождаться завершения загрузки. Можно также приложить небольшой
   OWNER-BRIEF.md отдельно, чтобы основной контракт сразу был читаем.
   Исходные388 PNG уже внутри ZIP, повторно прикреплять их по одному не нужно.
3. Попросить распаковать архив и фактически прочитать handoff/README.md,
   OWNER-MESSAGES.md, OWNER-BRIEF.md, IMPLEMENTATION-PLAN.md,
   CI-DEVELOPMENT-POLICY.md и INPUT-REVIEW.md. Затем проверить
   screens-manifest.json и наличие388 PNG /33 видов экранов.
4. До большой реализации получить первый технический отчёт: материалы
   доступны, baseline main определён, новая ветка/PR связаны с задачей,
   Figma/dev backend/headless screenshots доступны или указан конкретный gap.
   После GO остальные неблокируемые пакеты выполняются автономно.

Локальный путь C:\Users\maksd\... не является доступным cloud путём.
Открытие этой папки здесь само по себе не загружает её в облако.
Передача подтверждается чтением файлов в целевой среде, а не только
значком успешно загруженного вложения.

Если выбранный интерфейс не принимает ZIP или его размер, не заявлять,
что пакет получен. Можно подготовить меньшие архивы по ролям; для интерфейса
совсем без ZIP-вложений понадобится согласованная скачиваемая ссылка или
репозиторный способ передачи. Сам ZIP пока наружу не загружался.

## Что должен видеть внешний обозреватель в GitHub

- актуальный план/checklist и состояние ветки/PR;
- короткий отчёт после законченного пользовательского пакета;
- API-CHANGES.md с причиной и совместимостью;
- OPEN-QUESTIONS.md с неблокирующими/блокирующими решениями;
- HTML/screenshots с постоянными IDs и достаточная runtime evidence;
- оставшиеся ограничения, без объявления synthetic/mock доказательства реальным.
