# v6.0 PWA + Web Push — Roadmap Archive

**Shipped:** 2026-04-06
**Phases:** 27-32 (6 phases, 14 plans)

## Milestone Goal

Student mobile client «RutTrack» (React PWA) with native Web Push notifications — installable on Android/iOS, offline-capable app shell, geo check-in, schedule view, attendance stats, homework tracker.

## Phases

- [x] **Phase 27: Web Push Backend** — VAPID infrastructure and push subscription endpoints in notification-web (3/3 plans, completed 2026-04-05)
- [x] **Phase 28: API Gateway CORS + nginx** — Gateway CORS config for PWA origin, push route, nginx serving container (2/2 plans, completed 2026-04-06)
- [x] **Phase 29: PWA Scaffold + Auth** — React PWA project, login, JWT auth, manifest, A2HS, Service Worker shell (3/3 plans, completed 2026-04-06)
- [x] **Phase 30: Schedule + Check-in UI** — Today/week schedule view with offline cache, geo check-in button and feedback (2/2 plans, completed 2026-04-06)

- [x] **Phase 32: Stats + Homework** — Attendance stats/records with red zone indicator, homework list with completion tracker (2/2 plans, completed 2026-04-06)

**Requirements**: PUSH-01, PUSH-02, PUSH-03, PUSH-04, PUSH-05, PUSH-06, PUSH-07, INFRA-02
**Plans:**
- [x] 27-01-PLAN.md — Module restructure + API contract + VAPID config + Gateway route
- [x] 27-02-PLAN.md — Push subscription CRUD + @RequireRole security
- [x] 27-03-PLAN.md — Async push delivery + EventConsumer hook + 410 cleanup

**Goal**: API Gateway accepts cross-origin requests from the PWA origin, and the nginx container serves the PWA static build
**Depends on**: Phase 27 (push route target exists)
**Requirements**: INFRA-01, INFRA-03
**Plans:**
- [x] 28-01-PLAN.md — Gateway CORS config + JwtAuthenticationFilter OPTIONS bypass + tests
