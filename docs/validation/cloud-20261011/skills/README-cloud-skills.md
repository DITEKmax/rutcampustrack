SKILL.md и сопутствующие файлы скопированы без изменения bytes. Неактивные
исторические .inactive версии исключены. Проектные скиллы не имеют локальных
scripts/references: их дополнительные исходные документы находятся в репозитории.
Архив ограничен текущей задачей; посторонние навыки Pets, Sites, презентаций,
таблиц, установки плагинов и управления локальным Windows здесь не требуются.

## Приём пакета и применение

1. Найди именно прикреплённый rutcampustrack-cloud-skills-20261011.zip.
   Проверь безопасные относительные пути ZIP, CRC и каждый размер/SHA256 из
   manifest.json. Не запускай scripts автоматически при распаковке.
2. Сохрани пакет в каталоге этой задачи, например
   docs/validation/cloud-20261011/skills, без изменения protected .agents/.codex
   или global config. Это перенос файлов, а не установка плагинов.
3. Прочитай три project/*/SKILL.md как предоставленные project skill instructions.
   Перед UI-правкой обязательно применяй rutcampustrack-design и открой нужные
   оригиналы документов. Копия файла пригодна для чтения независимо от того,
   появился ли skill автоматически в системном каталоге доступных навыков.
4. Читай tools/*/SKILL.md и их references только по применимой операции. Если
   соответствующий навык уже доступен в Cloud, используй его актуальную встроенную
   версию. Не используй файлы пакета для обхода отсутствующего инструмента.
5. Запиши receipt приёма и применимые пути в CURRENT/решения этой Cloud-задачи.
   После compaction/resume перечитывай TASK-CONTRACT и CURRENT, затем применимые
   SKILL.md до соответствующей операции. Передай нужные пути дочерним агентам.

Актуальные решения владельца и TASK-CONTRACT определяют scope. Дополнительный
tool skill не разрешает новый дизайн, новые токены, Figma write/publication,
изменение прав, production/deploy или вмешательство в другие задачи.
Текущее исключение actual model/effort UNKNOWN остаётся действующим по контракту.

При отсутствии подключения к Figma сначала используй доступные принятые исходники
репозитория для независимой диагностики. Операция, требующая конкретного недоступного
внешнего оригинала, остаётся неподтверждённой: задай точный вопрос и продолжай другие
scopes. Не выдавай наличие SKILL.md за наличие MCP, авторизации или пройденного UI.

## Предел проверки этого переноса

Локально проверены точность копий, размеры/SHA256, безопасные пути, состав и CRC
архива. Cloud-приём, наличие MCP, запуск helper scripts и runtime UI ещё должны
быть подтверждены самой действующей Cloud-задачей. Архив содержит инструкции,
справочники и helper scripts, не облачные сервисы, подключённые аккаунты или
установленные зависимости. Примерные /mnt/data и локальные helper paths в skills
адаптируй к реально доступным каталогам Cloud без изменения инструкционных оригиналов.
