## What Was Done

### Task 1: init-letsencrypt.sh

Created `nginx/scripts/init-letsencrypt.sh` -- a one-time bootstrap script for first SSL certificate issuance on a fresh VPS. The script solves the chicken-and-egg problem where nginx needs certs to start HTTPS but certbot needs nginx HTTP to complete the ACME challenge.

Script flow:
1. Reads DOMAIN and CERTBOT_EMAIL from `.env.prod`
2. Generates `dhparam.pem` via openssl if missing
3. Disables `default.conf` (HTTPS config), ensures `http-only.conf` is active
4. Starts nginx in HTTP-only mode via docker compose
5. Runs certbot with `--staging` flag (test, no rate limit risk)
6. Prompts user confirmation, then runs certbot with `--force-renewal` for production cert
7. Swaps config back: activates `default.conf`, backs up `http-only.conf`
8. Reloads nginx to pick up SSL cert and HTTPS config
9. Prints verification command (`curl -I https://$DOMAIN`)

Uses `--cert-name rutcampustrack` to prevent duplicate certificate names across runs.

### Task 2: .gitignore updates

Added entries to prevent committing VPS-generated files:
- `nginx/dhparam.pem` -- generated by init script
- `nginx/conf.d/*.bak` -- http-only.conf.bak after bootstrap
- `nginx/conf.d/*.disabled` -- default.conf.disabled during bootstrap

Source config files (`default.conf`, `http-only.conf`, `nginx.conf`) remain tracked.
