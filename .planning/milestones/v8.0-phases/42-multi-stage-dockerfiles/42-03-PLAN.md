Both pwa and mini-app are Vite/React apps with identical Dockerfile patterns. Build context is the frontend directory itself.

**Create `frontends/pwa/Dockerfile`:**
```dockerfile
# Stage 1: Build
FROM node:22-alpine AS builder
WORKDIR /app

COPY package.json package-lock.json ./
RUN npm ci

COPY . .
RUN npm run build

# Stage 2: Runtime
FROM nginx:1.27-alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80
```

**Create `frontends/mini-app/Dockerfile`:** Identical content to pwa Dockerfile above. Both Vite apps output to `dist/`.
