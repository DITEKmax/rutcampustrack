**ScheduleItemService.java** — `ru.rutcampustrack.schedule.item` package, `@Service`, `@Transactional`:

Constructor-inject: `ScheduleItemRepository`, `AcademicGrpcClient`, `RequestContext`.

Private helper method:
```java
private void requireHeadmanForGroup(Long targetGroupId) {
    UserRole role = requestContext.getRole();
    if (role == UserRole.ADMIN) return; // ADMIN bypasses per D-08/D-10
    if (!requestContext.isHeadman()) {
        throw new AccessDeniedException("Only headman or admin can perform this action");
    }
    boolean confirmed = academicGrpcClient.isHeadman(requestContext.getUserId(), targetGroupId);
    if (!confirmed) {
        throw new AccessDeniedException("You are not headman of group " + targetGroupId);
    }
}
```

Methods:

1. `createScheduleItem(CreateScheduleItemRequest request)`:
   - Call `requireHeadmanForGroup(request.groupId())` FIRST
   - Call `academicGrpcClient.validateGroup(request.groupId())` — validates group exists and is active per D-06
   - Call `academicGrpcClient.getActiveSemester()` — validate semester is the active one. If `response.getId() != request.semesterId()`, throw `new IllegalArgumentException("Semester " + request.semesterId() + " is not the active semester")`
   - Create new `ScheduleItem`, set all fields from request, set `isActive = true`, set `createdAt = OffsetDateTime.now()`
   - Save and return

2. `getScheduleItem(Long id)`:
   - Find by ID or throw `ResourceNotFoundException("ScheduleItem", "id", id)`
   - Return the entity

3. `listScheduleItems(Long groupId, Long semesterId, Pageable pageable)`:
   - Query `scheduleItemRepository.findByGroupIdAndSemesterIdAndIsActiveTrue(groupId, semesterId)`
   - Convert to Page manually: create `PageImpl` from list with pageable (or use a `Page`-returning repository method — add `Page<ScheduleItem> findByGroupIdAndSemesterIdAndIsActiveTrue(Long groupId, Long semesterId, Pageable pageable)` to the repository if not already present).
   - BETTER: Add overload `Page<ScheduleItem> findByGroupIdAndSemesterIdAndIsActiveTrue(Long groupId, Long semesterId, Pageable pageable)` to `ScheduleItemRepository`. Spring Data JPA supports both List and Page return types from the same method name by overloading with Pageable parameter.
   - Return the Page

4. `updateScheduleItem(Long id, UpdateScheduleItemRequest request)`:
   - Find existing by ID or throw `ResourceNotFoundException`
   - Call `requireHeadmanForGroup(existing.getGroupId())` — re-validates group ownership. groupId comes from EXISTING entity, not request (D-09)
   - Update fields: `subjectId`, `teacherId`, `dayOfWeek`, `lessonNumber`, `startTime`, `endTime`, `weekType`, `room` from request
   - Save and return

5. `deleteScheduleItem(Long id)`:
   - Find existing by ID or throw `ResourceNotFoundException`
   - Call `requireHeadmanForGroup(existing.getGroupId())`
   - Set `existing.setActive(false)` — soft delete per D-07
   - Save (no physical delete)
