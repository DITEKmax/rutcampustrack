```nginx
worker_processes auto;
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;

events {
    worker_connections 1024;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent"';
    access_log /var/log/nginx/access.log main;

    sendfile on;
    keepalive_timeout 65;
    client_max_body_size 10m;

    # Hide nginx version in Server header (NET-01 security)

    include /etc/nginx/conf.d/*.conf;
}
```

**nginx/conf.d/http-only.conf** — Bootstrap config for first certbot run (rename to .conf.bak after cert issued):

# Bootstrap config — HTTP only, no SSL references.
# Used for first certbot certificate issuance.
# After cert is issued, rename this to http-only.conf.bak
# and rename default.conf.disabled to default.conf, then reload nginx.

    server_name _;

**nginx/conf.d/default.conf** — Full production config (rename to .disabled before first deploy, enable after cert issued):
NOTE: This file ships as `default.conf.disabled` initially. The init script renames it.

Create it as `default.conf` in the repo. The init-letsencrypt.sh script (Plan 02) handles the rename dance.

```nginx
# Production config — HTTPS termination + reverse proxy
# Requires SSL certificate at /etc/letsencrypt/live/${DOMAIN}/

# HTTP -> HTTPS redirect (NET-05)
server {
    listen 80;
    server_name _;

    # ACME challenge MUST come before redirect (Pitfall 3)
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }

    location / {
        return 301 https://$host$request_uri;
    }
}

# HTTPS server (NET-01, NET-02)
server {
    listen 443 ssl;
    server_name _;

    ssl_certificate     /etc/letsencrypt/live/rutcampustrack/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/rutcampustrack/privkey.pem;
    ssl_dhparam         /etc/nginx/dhparam.pem;

    # TLS hardening — TLSv1.2 + TLSv1.3 only (no TLSv1.0/1.1)
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_prefer_server_ciphers on;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384';
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;

    # Security headers
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # --- API Gateway: all /api/* traffic (NET-01) ---
    location /api/ {
        proxy_pass http://rct-api-gateway:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # --- WebSocket / STOMP (SockJS) for notification-web ---
    location /api/ws/ {
        proxy_pass http://rct-api-gateway:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 86400s;
    }

    # --- Landing page (NET-02) ---
    location /landing/ {
        proxy_pass http://rct-landing-nginx:80/;
        proxy_set_header Host $host;
    }

    # --- Admin Web Panel (NET-02) ---
    location /admin/ {
        proxy_pass http://rct-web-panel-nginx:80/;
        proxy_set_header Host $host;
    }

    # --- Telegram Mini App (NET-02) ---
    location /mini-app/ {
        proxy_pass http://rct-mini-app-nginx:80/;
        proxy_set_header Host $host;
    }

    # --- PWA at root (NET-02) — MUST be last (catch-all) ---
    location / {
        proxy_pass http://rct-pwa-nginx:80;
        proxy_set_header Host $host;
    }
}
```

Important implementation details:
- Use `server_name _` as placeholder — actual domain is configured via certbot cert directory name `rutcampustrack` (matches the `-d` flag in init script)
- The cert path uses a directory name `rutcampustrack` not the domain itself — certbot `--cert-name rutcampustrack` flag sets this
- ACME challenge location MUST appear before `return 301` in the HTTP server block
- WebSocket location `/api/ws/` MUST appear before the generic `/api/` block
- PWA location `/` MUST be last in the HTTPS server block (catch-all)
- `proxy_read_timeout 86400s` on WebSocket location prevents 60s idle disconnect
- `server_tokens off` in nginx.conf hides version from response headers

    image: nginx:1.27-alpine

      - "80:80"

      - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro

      - private_net

      api-gateway:

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet -> nginx (port 80/443) | All external traffic enters through nginx |
| nginx -> api-gateway (internal) | Proxied traffic on private_net, trusted |
| nginx -> frontend containers (internal) | Proxied traffic on private_net, trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-01 | Tampering | TLS config | mitigate | `ssl_protocols TLSv1.2 TLSv1.3` only — no TLSv1.0/1.1; strong cipher suite in default.conf |
| T-44-02 | Tampering | HTTP downgrade | mitigate | `return 301 https://$host$request_uri` for all non-ACME port 80 traffic (NET-05); HSTS header with max-age=31536000 |
| T-44-03 | Information Disclosure | Server header | mitigate | `server_tokens off` in nginx.conf hides nginx version |
| T-44-04 | Information Disclosure | Response headers | mitigate | `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin` |
| T-44-05 | Denial of Service | Certificate expiry | mitigate | Certbot sidecar runs `certbot renew` every 12h; nginx reloads every 6h to pick up new certs |
| T-44-06 | Elevation of Privilege | Internal service ports exposed | mitigate | Only nginx has `ports:` binding; all other services use `expose:` only (DOCK-06 compliant) |
| T-44-07 | Spoofing | Clickjacking | mitigate | `X-Frame-Options: SAMEORIGIN` header on all HTTPS responses |
</threat_model>
