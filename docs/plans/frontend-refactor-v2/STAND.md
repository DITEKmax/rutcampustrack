# Локальный стенд второго рефакторинга

Стенд запускает компоненты ветки `codex/frontend-refactor-v2` с синтетическими данными. Настоящие API, учётные записи и Telegram на этих адресах не используются. Серверы слушают только `127.0.0.1`. При перезагрузке в той же вкладке сохраняются тема и настройки уведомлений. Остальные тестовые изменения сбрасываются.

Для мобильных ролей выбери роль внутри приложения. Меняй тему через профиль. На Web параметр `role` выбирает начальную роль, `width=390` даёт узкий экран, `font=125` увеличивает размер текста. Рядом с таблицами и редакторами могут быть собственные области прокрутки. Для просмотра отказов, частичных состояний и повторов используй адреса из [плана и отчётов](PLAN.md).

Чтобы проверить переключатели доставки, открой уведомления на стенде с тестовой привязкой Telegram. [PWA](http://127.0.0.1:14272/viewport?width=390&notifications=linked) · [TMA](http://127.0.0.1:14273/viewport?width=390&notifications=linked)

Для проверки уведомлений переключи роль внутри приложения и открой ленту, настройки и цвета. На стенде преподавателя есть смена аудитории с переходом к паре и публикация задания. У администратора есть операция с семестром и переименование группы. У студента нажми заголовок [напоминания о сроке ДЗ](http://127.0.0.1:14273/viewport?width=320&text=125&notifications=due-reminder), чтобы открыть конкретное задание на его дату.

Чтобы проверить «Сегодня» преподавателя, выбери эту роль на [PWA](http://127.0.0.1:14272/viewport?width=390&teacher=v3&assignments=history) или [TMA](http://127.0.0.1:14273/viewport?width=320&text=125&teacher=v3&assignments=history). Календарь ограничен периодом с 1 сентября по 31 января. Перейди на любой день и сравни «Мои назначения». В этом сценарии «Архитектура ЭВМ» и «Проектирование систем» доступны в списке, а журнал открывается для текущих назначений.

В «Учёте» перейди к первой неделе сентября. У «н» за 1 сентября доступны обе формы. На других парах этой недели есть примеры активных заявок обоих типов. В разрезе «По предметам» открой «Компьютерные сети» и нажми первый жёлтый сегмент в «Практике». Он показывает причину, комментарий и тестовую справку. [TMA с исчерпанным лимитом](http://127.0.0.1:14273/viewport?width=390&attendanceBudget=zero) показывает ноль попыток на следующем шаге.

На [стенде восстановления пароля](http://127.0.0.1:14277/viewport?width=390) введи логин `student.preview`, запроси код и введи `246810`. Для нового пароля подойдёт любая тестовая строка от 10 символов. После сохранения можно войти с этим паролем в той же вкладке. Состояние этой учётной записи хранится до перезагрузки.

В «Ещё → Заявки» тестовые открытые заявки можно отменить и найти в архиве. В [сценарии временного отказа](http://127.0.0.1:14273/viewport?width=320&text=125&requestCancel=fail-once) первая отмена показывает сообщение рядом с заявкой, повтор переносит её в архив.

Для проверки отметок выбери роль «Староста» на [PWA](http://127.0.0.1:14272/viewport?width=390&headman=marks&linked=excuse) или [TMA](http://127.0.0.1:14273/viewport?width=390&headman=marks&linked=excuse). На текущей паре одна отметка «у» ведёт к одобренной тестовой заявке с PDF. На прошедшей паре можно открыть ручную «у» и изменить причину. Счётчик над приложением показывает, когда прошла команда записи. В [сценарии выгрузки](http://127.0.0.1:14272/viewport?width=390&headman=stats) открой пару, нажми «Скачать журнал» и выбери недели и формат. Этот сценарий доступен и в [TMA](http://127.0.0.1:14273/viewport?width=390&headman=stats).

Чтобы проверить «Группу», на обычном стенде выбери роль «Староста» и открой «Ещё → Группа». Кнопка «Скачать состав группы» открывает выбор Excel или PDF. В карточке Бориса Алексеева доступны тестовый сброс, выдача ссылки, увеличение лимита и настройка прав. Ссылка показывает состояние выдачи. Изменения живут в памяти вкладки и сбрасываются при перезагрузке. [PWA](http://127.0.0.1:14272/viewport?width=390) · [TMA](http://127.0.0.1:14273/viewport?width=390)

Для сравнения карточек ДЗ выбери роль «Староста» на [PWA](http://127.0.0.1:14272/viewport?width=390&headman=marks) или [TMA](http://127.0.0.1:14273/viewport?width=390&headman=marks). В проверочном расписании открой «Сегодня» и прокрути до блока ДЗ на второй паре. Затем нажми «Предыдущая пара». На первой паре есть тестовые задания, которые можно раскрыть.

Для календаря ДЗ выбери роль «Староста» на обычном стенде. Открой «Ещё → Домашнее задание → Посмотреть актуальные». На обычном стенде на сегодня есть два задания. Выбери дату без точки, чтобы увидеть пустой день, затем нажми «Сегодня». Чтобы проверить контур полей, нажми «Выдать ДЗ» и пройди до шага «Содержание». На локальном TMA используй «Продолжить · Telegram» рядом с рамкой приложения. [PWA](http://127.0.0.1:14272/viewport?width=390) · [TMA с увеличенным шрифтом](http://127.0.0.1:14273/viewport?width=320&text=125)

Для проверки завершения сессии открой две вкладки изолированного стенда PWA. [Студент](http://127.0.0.1:14279/?role=STUDENT) · [Староста](http://127.0.0.1:14279/?role=HEADMAN). В первой вкладке выбери «Профиль → Выйти». В обеих откроется форма входа. «Сбросить сессию стенда» возвращает исходные синтетические данные для повтора. «Отозвать сессию на стенде» имитирует подтверждённый отказ Auth. Локальная конфигурация для повторного запуска находится в `.agent/evidence/pwa-session-end-feedback/vite.config.mjs`.

Для проверки конструктора выбери роль «Староста» и открой «Ещё → Конструктор расписания». В [PWA с архивом](http://127.0.0.1:14272/viewport?width=390&headman=constructor&archive=present) есть один убранный шаблон. Открой первую пару понедельника, выбери пятницу и 4-ю пару, сохрани и проверь новую карточку. В [TMA со сценарием конфликта](http://127.0.0.1:14273/viewport?width=320&text=125&headman=constructor&conflict=apply) архив пуст, а при сохранении того же переноса стенд вернёт конфликт. В [PWA со сценарием повтора](http://127.0.0.1:14272/viewport?width=390&headman=constructor&replay=lost-once) первый ответ теряется после записи. Нажми «Повторить исходный запрос». В [сценарии с параллельным изменением](http://127.0.0.1:14272/viewport?width=390&headman=constructor&replay=superseded) после повтора откроется четверг с последним сохранённым слотом. Данные каждого сценария сбрасываются при перезагрузке вкладки.

## Повторный запуск

Рабочая копия Windows находится в `C:/Users/maksd/.codex/worktrees/9689/rutcampustrack/.agent/worktrees/frontend-refactor-v2`. Команды ниже выполняются из её корня. Нужны Node.js 24.14, npm 11.9 и установленные зависимости в `frontends/node_modules`. Если их нужно восстановить, выполни `npm --prefix frontends ci`.

Конфигурации и сценарии хранятся в `.agent/evidence/student-mobile-v2` и `.agent/evidence/web-student-v2`. Их актуальная резервная копия находится в `.agent/evidence/frontend-refactor-v2-stand/fixtures-headman-feedback.zip` исходной рабочей копии `9689/rutcampustrack`. Для новой рабочей копии этой ветки распакуй архив в её корень. В ZIP 28 файлов с путями от корня рабочей копии. SHA-256 `607a683cca61bb50cf40f56ecda6d6845429b4821211c0e9ec4b9982be9148cc`.

Поверх основной копии распакуй в тот же корень `.agent/evidence/headman-constructor-feedback/constructor-stand.zip` из рабочей копии второго рефакторинга. В дополнении четыре файла сценария конструктора. SHA-256 `bf4f3bf9c1451d4fc3ceb49ff8d1198b4f270c97e178031465c0ea8086655c81`.

Дополнение для назначений преподавателя и уведомлений находится в `.agent/evidence/teacher-semester-notifications/mobile-stand-overlay.zip` рабочей копии второго рефакторинга. Распакуй его последним в тот же корень. В ZIP пять файлов. SHA-256 `6d8dfcad0fbea09bbdbeb875a9ed8dd30f69afd78ae04dfbdb2a59c5f4e91509`.

Каждая команда запускается в своём окне PowerShell.

    node frontends/node_modules/vite/bin/vite.js --config .agent/evidence/student-mobile-v2/pwa-qa/vite.config.mjs
    node frontends/node_modules/vite/bin/vite.js --config .agent/evidence/student-mobile-v2/tma-qa/vite.config.mjs
    node frontends/node_modules/vite/bin/vite.js --config .agent/evidence/web-student-v2/vite.config.mjs
    node frontends/node_modules/vite/bin/vite.js --config .agent/evidence/student-mobile-v2/pwa-qa/recovery.config.mjs
    node frontends/node_modules/vite/bin/vite.js --config .agent/evidence/pwa-session-end-feedback/vite.config.mjs

Для HTML запусти две команды из исходной рабочей копии `9689/rutcampustrack`. Каталог Web-эталонов содержит четыре оригинальных HTML. Остальные оригиналы лежат по отдельным каталогам в `.agent/inputs/frontend-refactor-v2`. ZIP владельца сохранены в `C:/Users/maksd/OneDrive/Desktop/frontendrefactor`.

    python -m http.server 14274 --bind 127.0.0.1 --directory .agent/inputs/frontend-refactor-v2/checkin-impulse
    python -m http.server 14276 --bind 127.0.0.1 --directory .agent/inputs/frontend-refactor-v2/web-student

Замеры, снимки и журналы проверок находятся в `.agent/evidence` рабочей копии второго рефакторинга. Пути и границы проверок приведены в отчётах каждого архива. Для приёмки в установленной PWA и нативном Telegram нужно отдельно пройти открытие ссылки, геолокацию и скачивание на устройстве.
