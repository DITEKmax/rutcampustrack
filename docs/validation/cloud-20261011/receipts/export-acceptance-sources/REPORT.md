Empty type default remains a tentative frontend proposal in ПК123:122–125; a complete nonempty type selector has clear oracle and does not wait on that proposal.
- Accepted async is common ExportButton behavior, not an optional lecture optimization. Do not call ticket issuance or Telegram host “accepted” callback successful file completion.

- Content-Disposition attachment, UTF-8 safe filename, no-store, 20MiB response/document limits and reusable ticket TTL/redemption budgets are current implementation/test contracts. They are useful security/runtime checks; their precise constants are not owner product rules. Existing reusable ticket policy is not exactly-once generation: each redemption may regenerate.
