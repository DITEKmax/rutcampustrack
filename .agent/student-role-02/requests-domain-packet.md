## Required behavior

Nonempty unique own current-semester lessonIds; PLANNED/ACTIVE with no record or ABSENT allowed, CLOSED needs actual ABSENT, CANCELLED/PRESENT/EXCUSED/active EXCUSE rejects. Blockage and pending late do not block EXCUSE. Manual late: one own CLOSED/ABSENT, no blockage/pending late of either origin, five submissions per semester charged at submit. Rejection/cancel never refunds; new key re-submit charges. AUTO_GEO_FAILURE and EXCUSE unlimited. Active EXCUSE does not block manual late (consultant inference from independent mechanisms and PRESENT priority).

Public domain projections: RequestSummary(id,kind,status,origin,lessons,createdAt,updatedAt); status PENDING/APPROVED/REJECTED/CANCELLED (Excuse SUBMITTED maps PENDING). Detail adds reason/comment/attachments/decision as applicable, no peer data. OPEN=PENDING, ARCHIVE=terminal, owner-scoped Mongo union aggregation/pagination sorted updatedAt DESC,kind ASC,id ASC; page0,size20 default, bounded size. Options returns reasons, server limits, budget(semesterId,limit5,used,remaining), lesson snapshots with eligibility by kind and pendingRequests[{id,kind,origin}]. No single pending boolean. Include immutable lesson snapshots so archive does not depend on current schedule availability.

Create requires visible-ASCII idempotency key16..128, unique receipt(studentId,commandKind,key); canonical hash kind, sorted unique lessons, normalized reason/comment, ordered file hashes/size/type.
