# Демонстрация экранов RutCampusTrack

Открой `index.html` локально. Активны `student-final.html` и единственная `headman-final.html`, сгруппированные по типам экранов. Изображения и Onest встроены; слева PWA, справа браузерная TMA. Поиск, фильтр и увеличение кадров работают без сервера.

Реальные компоненты Vue с тестовым API. TMA показана в браузерной оболочке; это не проверка внутри Telegram. Фактическая ревизия каждого кадра сохранена; переиспользование принято после проверки неизменных зависимостей относительно финальной ревизии. Серверные изменения проверяются отдельно. Предпочтение темы сохраняется, палитра пока тёмная.

Глобальный архив ДЗ старосты удалён из актуальных состояний; история доступна у каждого задания. Семь исторических HTML сохранены неизменными. Точные количества, SHA256 и provenance — в `manifest.json`.

Новая итерация: группа, права помощника и предметы добавлены в тот же headman-final.html. Предыдущие 83 состояния и галерея студента сохранены. Точный состав и происхождение кадров — в manifest.json.

Новая итерация: конструктор расписания, управление парами и заявки добавлены в тот же headman-final.html. Предыдущие107 состояний и галерея студента сохранены. Точный состав и происхождение кадров — в manifest.json.

Итерация 7 октября: обновлены экраны старосты, добавлены видимые графики и отдельная аналитика. Точный состав и происхождение кадров — в manifest.json.

Вторая итерация 7 октября: дополнительные правки старосты, раскрытые варианты управления статистикой, календарная ось и исключение пар одним нажатием. Точный состав и происхождение кадров — в manifest.json.
