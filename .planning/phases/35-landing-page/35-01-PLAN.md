    - Inline `<script>`:
      ```javascript
      gsap.registerPlugin(ScrollTrigger);
      const mm = gsap.matchMedia();
      mm.add("(prefers-reduced-motion: no-preference)", () => {
        // Hero — immediate, no ScrollTrigger
        gsap.from(".hero-headline", { autoAlpha: 0, y: 30, duration: 0.8, ease: "power3.out" });
        gsap.from(".hero-sub", { autoAlpha: 0, y: 20, duration: 0.8, delay: 0.15, ease: "power2.out" });
        gsap.from(".hero-cta", { autoAlpha: 0, y: 15, duration: 0.6, delay: 0.3, ease: "power1.out" });
        // Feature cards — batch ScrollTrigger
        ScrollTrigger.batch(".feature-card", {
          onEnter: (els) => gsap.to(els, { autoAlpha: 1, y: 0, stagger: 0.10, duration: 0.6, ease: "power2.out" }),
          start: "top 85%",
          once: true
        });
        // Role cards — batch ScrollTrigger
        ScrollTrigger.batch(".role-card", {
          onEnter: (els) => gsap.to(els, { autoAlpha: 1, y: 0, stagger: 0.08, duration: 0.5, ease: "power2.out" }),
          start: "top 85%",
          once: true
        });
      });
      ```

**Color contrast note:** Use `text-gray-600` (`#4B5563`) minimum for description text on white backgrounds. The UI-SPEC warns that gray-500 on white is only 3.95:1 — below the 4.5:1 WCAG AA threshold. Use `text-gray-600 dark:text-gray-400` for card descriptions.

**Tailwind darkMode:** Must be `'media'` (not `'class'`) — dark mode activates automatically via CSS `prefers-color-scheme` media query. No JS toggle.

**CSS bounce animation for scroll indicator:** Add a `<style>` block in `<head>`:
```css
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-8px); }
}
.animate-bounce { animation: bounce 2s infinite; }
```
(Or rely on Tailwind CDN's built-in `animate-bounce` class — test that it works with the CDN version.)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDN -> browser | External JS (Tailwind, GSAP, Phosphor Icons) loaded from CDN — trusted publishers |
| user -> nginx | Public HTTP access to static files — no auth required |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-01 | Tampering | CDN scripts (Tailwind, GSAP, Phosphor) | accept | CDN URLs pinned to specific versions (3.12.5, 2.1.1). No SRI hashes due to Tailwind CDN being a JIT compiler (hash changes per load). Risk: LOW — no user data processed, page is read-only. |
| T-35-02 | Information Disclosure | nginx directory listing | mitigate | nginx.conf uses `try_files $uri $uri/ =404` — already configured in Phase 33. No autoindex enabled. |
| T-35-03 | Denial of Service | Large static file requests | accept | nginx:1.27-alpine default rate limits apply. Static HTML is < 50KB. Risk: LOW — internal university tool. |
| T-35-04 | Spoofing | Clickjacking via iframe | accept | Landing page is public marketing content with no auth or forms. Embedding in iframe causes no security risk. X-Frame-Options not required. |
</threat_model>
