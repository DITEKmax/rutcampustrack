|------|------|--------|-------------|---------|

## Color

| Role | Hex | Tailwind | Usage |
|------|-----|----------|-------|
| Dominant (60%) | `#FFFFFF` | `bg-white` | Page background, nav background (with glass blur), hero section |
| Secondary (30%) | `#F9FAFB` | `bg-gray-50` | Feature section background, role card backgrounds, footer background |
| Brand primary | `#2563EB` | `bg-blue-600` / `text-blue-600` | Nav logo, primary CTA button, icon color on feature cards |
| Accent (10%) | `#10B981` | `bg-emerald-500` / `text-emerald-500` | Success indicators only: `present` status badge, Student role card highlight stripe |
| Text primary | `#111827` | `text-gray-900` | Body text, headings |
| Text secondary | `#6B7280` | `text-gray-500` | Card descriptions, nav links (non-active), caption text |
| Border | `#E5E7EB` | `border-gray-200` / `border-gray-100` | Card borders, nav bottom border |
| Destructive | `#EF4444` | `text-red-500` | Red zone attendance warning copy only (role card: "порог красной зоны") |

**60/30/10 split:**
- 60% dominant: white `#FFFFFF` — backgrounds, surfaces
- 30% secondary: `#F9FAFB` gray-50 — alternating section backgrounds, cards
- 10% accent: `#2563EB` blue-600 — CTA button, logo, icon fills, active states

Accent reserved for ONLY:
1. Primary CTA button background (`bg-blue-600`)
2. Nav logo text (`text-blue-600`)
3. Feature card icon color (`text-blue-600`)
4. Hover underline on nav links
5. Focus ring on interactive elements

Green (`#10B981`) is a second semantic color reserved for: attendance success status copy only. Not used decoratively.

Red (`#EF4444`) is reserved for: red zone threshold copy in role overview section only. Not used for any interactive destructive actions (this page has none).

Dark mode: implement `prefers-color-scheme` via CSS media query only (no JS toggle). Background flips to `#111827` (gray-900), surfaces to `#1F2937` (gray-800), text inverts. Tailwind's `dark:` classes used. No interactive toggle button (simplicity requirement).

**Tailwind config dark mode setting:** Use `darkMode: 'media'` (not `'class'`). The `'class'` strategy requires a JS class toggle on `<html>`, which contradicts the no-JS dark mode requirement. The `'media'` strategy activates `dark:` classes automatically via `prefers-color-scheme` CSS media query.

**Source:** RESEARCH.md (Pattern 2: tailwind config, brand #2563EB, accent #10B981), design-decisions.md (status color convention), RESEARCH.md (open question 3 resolved as CSS-only dark mode)

## Component Inventory

The following HTML component patterns are declared. No React components, no library components.

### Nav (Sticky Header)

```
<header class="sticky top-0 z-50 bg-white/90 backdrop-blur border-b border-gray-100">
```

- Logo: "RutCampusTrack" text, `font-bold text-xl text-blue-600`
- Short name "RutTrack" as secondary label below logo on mobile (hidden on desktop)
- Anchor links: "Возможности", "Роли" — hidden on mobile, visible `sm:flex`
- Mobile hamburger: CSS-only toggle using `<input type="checkbox">` peer pattern
  - The `<label>` element must carry `aria-label="Открыть меню"` in the closed state and `aria-label="Закрыть меню"` in the open state. Implement via CSS-only peer pattern: use `peer-checked` sibling selector to swap between two `<span>` elements, each with its own `aria-label`, or apply `aria-label` on the label and accept the static default `aria-label="Открыть меню"` with the open icon hidden via CSS.
  - Recommended implementation: two `<label>` variants toggled via `peer-checked:hidden` / `peer-checked:flex`, one with `aria-label="Открыть меню"` (default visible), one with `aria-label="Закрыть меню"` (visible when checked).

## Animation Contract

**Engine:** GSAP 3.12.5 + ScrollTrigger (CDN). Loaded at bottom of `<body>`.

**Accessibility first:** All GSAP animations wrapped in `gsap.matchMedia()`. When `prefers-reduced-motion: reduce` — no animations run, elements shown at final state immediately.

```javascript
const mm = gsap.matchMedia();
mm.add({ reduceMotion: "(prefers-reduced-motion: reduce)" }, (ctx) => {
  if (!ctx.conditions.reduceMotion) {
    initAnimations();
  }
  // If reduceMotion — no-op. Elements already visible via CSS.
});
```

**Hero animations** (no ScrollTrigger — elements above fold):
- `.hero-headline`: `gsap.from()` — autoAlpha 0→1, y 30→0, duration 0.8, ease "power3.out"
- `.hero-sub`: same, delay 0.15
- `.hero-cta`: same, delay 0.30, duration 0.6

**Feature cards** (ScrollTrigger.batch):
- `onEnter`: autoAlpha 0→1, y 24→0, stagger 0.10, duration 0.6, ease "power2.out"
- `start: "top 85%"`, `once: true`
- Initial state set via CSS: `opacity: 0; transform: translateY(24px)` (noscript-safe fallback: `<noscript>` style overrides to `opacity: 1`)

**Role cards** (ScrollTrigger.batch, same pattern as feature cards):
- stagger 0.08, duration 0.5

**Nav** (no animation — sticky, always visible)

**Scroll indicator** (hero down arrow): CSS keyframe `bounce` animation, `animation: bounce 2s infinite`

## Interaction Contract

| Interaction | Behavior |
|-------------|---------|
| Nav anchor links | Smooth scroll to section via `scroll-behavior: smooth` on `<html>`. No JS required. |
| Mobile hamburger | CSS-only toggle: `<input type="checkbox" id="menu-toggle">` + `<label>` + sibling `<nav>` revealed via `:checked` + `peer` classes. Label carries `aria-label="Открыть меню"` (closed) and `aria-label="Закрыть меню"` (open) — see Component Inventory for implementation pattern. |
| Hero CTA button | `<a href="#">` — placeholder until Mini App URL is known. Opens in same tab (no `target="_blank"` — internal navigation) |
| Feature/role card hover | `hover:shadow-md transition-shadow duration-200` — subtle elevation. No complex transform. |
| Dark mode | Responds to OS `prefers-color-scheme` automatically via CSS `@media (prefers-color-scheme: dark)` + Tailwind `dark:` classes. Tailwind config must declare `darkMode: 'media'`. No JS toggle, no localStorage. |
| Scroll indicator (hero) | CSS `animation: bounce 2s infinite`. Rendered as `<a href="#features" aria-label="Прокрутить к возможностям">` wrapping the Phosphor down-arrow icon (`aria-hidden="true"`). Clicking scrolls to `#features`. |

No forms. No modals. No destructive actions. No loading states. No error states.

## Accessibility Contract

- Heading hierarchy: `h1` (hero) → `h2` (section titles: "Возможности", "Роли") → `h3` (card titles). No skips.
- Skip-to-content link: `<a href="#main" class="sr-only focus:not-sr-only">Перейти к содержимому</a>` as first element in `<body>`
- All Phosphor Icons: `aria-hidden="true"` + adjacent visible text label. Icons are decorative only.
- Color contrast: all text on white backgrounds minimum 4.5:1. Gray-500 on white = 3.95:1 — use gray-600 (`#4B5563`) minimum for body text on white. Gray-500 only for placeholder/secondary where 3:1 is acceptable (large text).
- Focus-visible: `focus-visible:ring-2 focus-visible:ring-blue-600 focus-visible:ring-offset-2` on all interactive elements (links, buttons)
- Motion: `prefers-reduced-motion` respected via GSAP `matchMedia()` (see Animation Contract)
- `lang="ru"` on `<html>`
- All `<img>` tags (if any screenshots used): `alt=""` for decorative, descriptive alt for informational
- Scroll indicator anchor: `aria-label="Прокрутить к возможностям"` on the `<a href="#features">` element
- Hamburger toggle labels: `aria-label="Открыть меню"` on the closed-state label, `aria-label="Закрыть меню"` on the open-state label
