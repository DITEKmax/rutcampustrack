## Spacing Scale

Declared values (multiples of 4 only). Inherited from Phase 36 — no changes.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, tab indicator gap |
| sm | 8px | Card inner row gaps, list item internal spacing, gap between lesson cards |
| md | 16px | Card padding, page horizontal padding, list item padding |
| lg | 24px | Section vertical spacing between cards, between stat rows |
| xl | 32px | Top/bottom page padding (viewport-safe zones) |
| 2xl | 48px | Bottom nav height, MainButton safe-area buffer |
| 3xl | 64px | Page scroll bottom clearance (above fixed bottom nav) |

Exceptions:
- Touch targets (nav tab icons, lesson card tap areas, homework toggle): minimum 44px × 44px hit area (WCAG 2.5.5)
- Bottom nav: fixed height 56px, with `pb-[env(safe-area-inset-bottom)]` for iOS home indicator
- Lesson card tap area spans full card width × full card height (not just icon/text)
- Homework item toggle checkbox: 44px × 44px hit area, visual checkbox 20px × 20px

## Typography

Font: Geist Variable, sans-serif. Inherited from Phase 36. Exactly 4 sizes, 2 weights.

| Role | Size | Weight | Line Height | Usage in Phase 37 |
|------|------|--------|-------------|-------------------|
| Display | 28px (1.75rem) | 600 semibold | 1.2 | Overall attendance KPI percentage only (overall stats card) |
| Title | 16px (1rem) | 600 semibold | 1.5 | Screen titles ("Расписание", "Статистика", "ДЗ"), lesson subject name in LessonCard |
| Body | 16px (1rem) | 400 regular | 1.5 | Lesson time range, homework description body, stats secondary text |
| Label | 14px (0.875rem) | 600 semibold | 1.4 | Section headers ("Сегодня"), room label, stats subject name, percentage in SubjectStatsCard |
| Caption | 12px (0.75rem) | 400 regular | 1.4 | Tab labels (active and inactive), lesson number, muted hints, "чел" attendance count, homework due date, sub-stats rows |

Rules:
- Maximum 2 font weights: 400 (regular) and 600 (semibold) — no 500, no 700
- No italic
- Subject name in LessonCard: `line-clamp-2` to prevent overflow on long subject names
- Title and Body share the same 16px size — differentiated by weight (600 vs 400)
- 28px Display is reserved exclusively for the single overall KPI percentage in StatsPage overall card
- Bottom nav tab labels: 12px (Caption size) — active label uses weight 600 semibold, inactive label uses weight 400 regular

## Screens and States

### Screen 1: SchedulePage (`/`)

Root screen. Shows today's lessons for the student's group.

**Primary visual anchor:** The ACTIVE lesson card with its `border-l-4 border-l-primary` accent stripe is the focal point of SchedulePage. It is the only card with an accent-colored left border and is always rendered at its natural position in the lesson list.

**Layout:** Full-screen scroll container. Page horizontal padding 16px. Header: "Расписание" 16px semibold + today's date caption 12px regular muted. Lesson list: vertical stack, 8px gap between cards.

**States:**
- Loading: 3 skeleton cards — `bg-muted rounded-xl h-24 animate-pulse` — no spinner, skeleton list only
- Empty (no lessons today): `CalendarBlank` Phosphor icon 32px bold muted, heading "Сегодня пар нет" 16px semibold, body "Наслаждайтесь свободным днём" 16px regular muted
- Teacher role (no groupId): icon `Info` 32px bold muted, heading "Расписание студентов" 16px semibold, body "Расписание доступно только для студентов" 16px regular muted
- Error: icon `WarningCircle` 32px bold destructive, heading "Не удалось загрузить расписание" 16px semibold, body "Проверьте соединение и попробуйте снова" 16px regular muted + "Обновить расписание" label button

**LessonCard anatomy** (adapted from PWA, no PWA check-in button):
- Container: `bg-card border border-border rounded-xl p-4`
- ACTIVE lesson: add `border-l-4 border-l-primary` left accent stripe
- CANCELLED lesson: `opacity-60`
- Row 1: time range "HH:mm — HH:mm" 16px semibold left + `StatusBadge` right
- Row 2: subject name 16px semibold, `line-clamp-2`, `mt-1`
- Row 3: "Ауд. {room}" 14px regular muted, `mt-1`
- ACTIVE lesson row 4: "Войти на пару →" 14px semibold primary color — tap navigates to `/checkin/:lessonId`
- Motion: `initial={{ opacity: 0 }} animate={{ opacity: 1 }}` per card, stagger 50ms between cards using Motion `variants`

**StatusBadge** (copy from PWA `StatusBadge.tsx` verbatim — same label text, same classes):
- `present`: label "б", `bg-green-100 text-green-700`
- `absent`: label "н", `bg-red-100 text-red-700`
- `excused`: label "у", `bg-yellow-100 text-yellow-700`
- `free_attendance`: label "сп", `bg-blue-100 text-blue-700`
- `ACTIVE`: label "Идёт", `bg-primary text-primary-foreground`
- `PLANNED`: label "Запланировано", `bg-muted text-muted-foreground`
- `CANCELLED`: label "Отменена", `bg-muted text-muted-foreground line-through`
- `CLOSED`: label "Завершено", `bg-muted text-muted-foreground`

### Screen 2: CheckInPage (`/checkin/:lessonId`)

Detail page for a single ACTIVE lesson. Student checks in here via Telegram MainButton.

**Layout:** Full-screen, no scroll. Page padding 16px. Shows selected lesson details (time, subject, room) + GPS status feedback.

**BackButton:** show on mount via `useBackButton()` hook — navigates to `/` on press. Hide on unmount.

**MainButton (Telegram native):**
- Default state: text "Отметиться" — `isVisible: true`, `isEnabled: true`, Telegram's button_color
- Loading state (GPS acquiring): text "Определяем местоположение..." — `isEnabled: false`
- Submitting state (API call in flight): text "Отправляем отметку..." — `isEnabled: false`
- Success: `hapticFeedback.notificationOccurred('success')` → navigate back to `/`
- Error: `hapticFeedback.notificationOccurred('error')` → show error toast in page, re-enable button
- Dev mode fallback button: `<button className="w-full bg-primary text-primary-foreground rounded-xl py-3 text-label font-semibold min-h-[48px]">Отметиться</button>` — only rendered when `VITE_TMA_DEV=true`

**GPS status indicator (inline, not a full-screen overlay):**
- Acquiring: `CircleNotch` Phosphor 20px bold animate-spin muted, label "Определяем местоположение..." 14px muted
- Acquired: `MapPin` Phosphor 20px fill green, label "Геолокация получена" 14px regular
- Error: `MapPinOff` Phosphor 20px bold destructive, label "Не удалось получить геолокацию" 14px destructive

**Check-in result states (inline feedback card, not page replacement):**
- Success: `CheckCircle` 24px fill green, "Отметка принята!" 16px semibold — auto-navigate back after 1.5s
- Already checked: 409 → `Check` 24px fill green, "Вы уже отметились на этой паре" 16px muted
- Outside window: 422 → `ClockCountdown` 24px bold muted, "Окно отметки ещё не открыто или уже закрыто" 16px muted
- Outside location: 403 → `MapPinOff` 24px bold destructive, "Вы находитесь слишком далеко от аудитории" 16px destructive
- Rate limited: 429 → `Timer` 24px bold muted, "Слишком много попыток. Подождите немного." 16px muted

**Motion:** page enters with `initial={{ opacity: 0, x: 16 }} animate={{ opacity: 1, x: 0 }}` 150ms ease-out (slides in from right).

### Screen 3: StatsPage (`/stats`)

Shows per-subject attendance percentages with red zone indicators.

**Layout:** Full-screen scroll container. Page padding 16px. Header "Статистика" 16px semibold. Overall card at top, then subject list.

**BackButton:** NOT shown — this is a root tab (bottom nav tab), not a detail page.

**Overall stats card:**
- Container: `bg-card border border-border rounded-xl p-4`
- "Общая посещаемость" 14px semibold muted (section label)
- Large percentage: 28px semibold — the single Display-size element in this phase, reserved for this KPI only
- Sub-stats row: "Присутствовал: N" / "Отсутствовал: N" / "Уважит.: N" — 12px regular muted, space-between

**SubjectStatsCard:**
- Container: `bg-card border border-border rounded-xl p-4`
- Red zone: add `border-l-4 border-l-destructive` when `percentage < 60`
- Subject name: 14px semibold, `line-clamp-1`
- Percentage value: 14px semibold — `text-destructive` when < 60, `text-foreground` when >= 60
- Progress bar: `h-2 rounded-full bg-muted` track, `bg-primary` fill (or `bg-destructive` when < 60), width = `{percentage}%`, `transition-all duration-300`
- Sub-stats row: "Н: {absent}" / "У: {excused}" — 12px regular muted

**Red zone threshold:** hardcoded 60% for Phase 37. Comment in code: `// TODO: use backend threshold when available`.

**States:**
- Loading: 4 skeleton cards — `bg-muted rounded-xl h-20 animate-pulse`
- Empty (no data): `ChartBar` 32px bold muted, "Нет данных о посещаемости" 16px semibold, "Статистика появится после первых пар" 16px muted
- Error: same pattern as SchedulePage error state

### Screen 4: HomeworkPage (`/homework`)

Lists group homeworks for the active semester with completion toggle.

**Layout:** Full-screen scroll container. Page padding 16px. Header "Домашние задания" 16px semibold. Grouped by subject (section headers 14px semibold muted). Homework items as vertical list.

**BackButton:** NOT shown — root tab.

**HomeworkItem anatomy:**
- Container: `bg-card border border-border rounded-xl px-4 py-3 flex items-start gap-3`
- Checkbox (left): 20px × 20px visual, 44px × 44px touch target. Completed: `CheckSquare` 20px fill primary. Uncompleted: `Square` 20px regular muted.
- Optimistic update: toggle visually immediately on tap, `hapticFeedback.impactOccurred('light')` on tap
- Text block (right): title 14px semibold, description (if any) 12px regular muted, due date 12px regular muted
- Completed state: title has `line-through text-muted-foreground`, checkbox `CheckSquare` fill primary
- Motion on completion: `animate={{ opacity: completed ? 0.6 : 1 }}` transition 150ms

**States:**
- Loading (waiting for active semester + homework list): 5 skeleton items — `bg-muted rounded-xl h-14 animate-pulse`
- Empty (no homework): `Books` 32px bold muted, "Нет домашних заданий" 16px semibold, "Всё сдано или пока ничего не задано" 16px muted
- Error: same pattern as other pages. If semester not found: "Активный семестр не найден. Обратитесь к старосте." 16px muted (no retry — informational)

### Screen 5: Bottom Navigation (persistent on all root tabs)

Fixed bottom bar shared across SchedulePage, StatsPage, HomeworkPage. Hidden on CheckInPage.

**Layout:** `fixed bottom-0 left-0 right-0`, height 56px + `pb-[env(safe-area-inset-bottom)]`, `bg-background border-t border-border`. Three equal-width columns.

**Tab items:**
| Tab | Icon (inactive) | Icon (active) | Label |
|-----|-----------------|---------------|-------|
| Расписание (`/`) | `CalendarBlank` 24px regular | `CalendarBlank` 24px fill | Расписание |
| Статистика (`/stats`) | `ChartBar` 24px regular | `ChartBar` 24px fill | Статистика |
| Домашние задания (`/homework`) | `BookOpen` 24px regular | `BookOpen` 24px fill | ДЗ |

- Active tab: icon fill primary color + label 12px semibold primary + 4px dot below icon
- Inactive tab: icon regular muted + label 12px regular muted
- Touch target: full column width × 56px
- No transition animation on tab switch (instant)

**Scroll clearance:** all page scroll containers must add `pb-[calc(56px+env(safe-area-inset-bottom)+16px)]` to prevent content hidden under bottom nav.

## Interaction Contract

### Navigation Contract

- Route `/` → SchedulePage, no BackButton, bottom nav tab "Расписание" active
- Route `/stats` → StatsPage, no BackButton, bottom nav tab "Статистика" active
- Route `/homework` → HomeworkPage, no BackButton, bottom nav tab "ДЗ" active
- Route `/checkin/:lessonId` → CheckInPage, BackButton visible, bottom nav hidden

**Page transition animations:**
- Tab switch (root tabs): `initial={{ opacity: 0 }} animate={{ opacity: 1 }}` 100ms ease-out — no slide (tabs are siblings, not depth navigation)
- Forward navigation to CheckInPage: `initial={{ opacity: 0, x: 16 }} animate={{ opacity: 1, x: 0 }}` 150ms ease-out
- Back navigation (BackButton): handled by `navigate(-1)` — React Router manages history, no custom exit animation

### Haptic Feedback Contract

| Action | Haptic call |
|--------|-------------|
| Tap lesson card to open CheckInPage | `hapticFeedback.impactOccurred('light')` |
| Tap homework completion toggle | `hapticFeedback.impactOccurred('light')` |
| Check-in success | `hapticFeedback.notificationOccurred('success')` |
| Check-in error (any 4xx) | `hapticFeedback.notificationOccurred('error')` |
| GPS acquisition failure | `hapticFeedback.notificationOccurred('error')` |

All haptic calls gated with `.isAvailable()` check per SDK 3.x pattern.

### Loading and Skeleton Contract

- Skeletons appear immediately on query initiation — no delay
- Skeletons match card size to prevent layout shift on data arrival
- No full-page spinners on feature pages — only skeleton lists
- Full-page spinner retained only for auth (inherited from Phase 36 LoadingScreen)

### Optimistic Update Contract

Homework toggle only:
1. Tap checkbox → immediate visual toggle (`setQueryData` optimistic)
2. Fire `hapticFeedback.impactOccurred('light')`
3. Call `POST` or `DELETE` in background
4. On error: rollback `setQueryData` to previous state + show brief toast/inline error
5. On settle (success or error): `invalidateQueries` to sync with server

No optimistic updates for check-in (GPS + API sequence has too many failure modes).

### Touch Target Contract

- All interactive elements: minimum 44px × 44px hit area
- Bottom nav tabs: full column width × 56px
- Lesson cards: full card tap area (not just text)
- Homework toggle: 44px × 44px hit area around 20px checkbox
- No hover-only states (touch-first)
