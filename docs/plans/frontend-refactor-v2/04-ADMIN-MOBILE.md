## Сверка с текущей веткой

- Реестр Vue с 33 синтетическими записями нашёл пользователя вне первой страницы. Рабочая форма студента сохранила ID одним PATCH. Зафиксированы отличия в состоянии кнопки при невалидном ID и в доступности кнопки при пустой форме создания группы.

- Реальный Admin в исходной TMA сохранял светлую настройку в профиле, но обзор оставался тёмным. Тема теперь применяется внутри Admin shell. Подтверждены `#f2f2f4` и `#0b0b0c` в обеих оболочках. - В PWA обычные уведомления открылись из обзора, затем сработали Back, «Ещё» и профиль. Формат выгрузки виден сразу. Синтетический PDF отправлен штатному клиенту с фактически применённым поиском `student.qa25`, один POST и одно чтение файла.

Проверены полномочия, CAS, защищённая цель, отзыв сеансов и ссылок, одновременная генерация и откат. WSL запущен с каноническими Git-байтами миграций в отдельной папке тестов. ## Коррекция после независимой сверки

При открытии уведомлений экран аккаунтов остаётся смонтированным. Панель синхронно освобождает пароль, сбрасывает подтверждение и отменяет запрос. В TMA отложенный GET возвращён после открытия уведомлений. После системного Back значение осталось скрытым. В PWA то же проверено для уже открытого текущего и начального пароля.

Экран создания показывает успешный результат и логин. Начальный пароль доступен по отдельному Auth GET при `origin: initial`. PWA подтвердила один POST создания и один новый GET только после кнопки. Обычные чтения профиля и ролей отбрасывают возвращаемый совместимым Academic контрактом пароль. Для Web сохранён действующий контракт выдачи при создании и восстановлении операции. Пустые обязательные поля блокируют создание, пустой или пробельный табельный номер блокирует назначение преподавателя.

## Воспроизведение и ограничения

- Открой PWA `http://127.0.0.1:14272/viewport?width=390&admin=v2` или TMA `http://127.0.0.1:14273/viewport?width=320&admin=v2&text=125`, выбери роль «Администратор». Для реестра ищи `student.qa25`. Переключай тему через профиль.
- Добавь `group=read-fail`, выбери «5 курс» и создай `ТСТ-134` со сроком 4 года. После 503 «Обновить реестр» раскрывает черновик, счётчик POST остаётся 1. Вариант `credentials=uncertain` показывает GET после неопределённой генерации, `credentials=late` удерживает первый ответ до внешней кнопки, `credentials=limited` включает роль просмотра.
- При 401 во время чтения уведомлений интегрированная TMA переходит на экран повторного входа. HTML показывает ошибку внутри уведомлений. Сохранён действующий переход приложения при потере сессии.
- Встроенный браузер показал передачу PDF клиенту скачивания. Факт записи файла на диск и нативный Telegram остаются для приёмки на устройстве. Проверки роли и ротации выполнялись на изолированных записях.
