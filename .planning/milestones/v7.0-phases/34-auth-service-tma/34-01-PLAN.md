<objective>
Implement Telegram Mini App authentication in auth-service: `POST /auth/tma` endpoint that validates Telegram initData via HMAC-SHA256 and returns a JWT pair, plus `POST /auth/refresh-body` endpoint for body-based token refresh (Telegram WebView drops httpOnly cookies).

Purpose: Enable Telegram Mini App users to authenticate without username/password by exchanging Telegram initData for JWTs. The refresh-body endpoint provides cookie-less refresh for WebView environments.

Output: TmaService, TmaAuthRequest DTO, TmaProperties config, TmaValidationException, two new controller endpoints, SecurityConfig update, GlobalExceptionHandler update, integration tests.
</objective>
