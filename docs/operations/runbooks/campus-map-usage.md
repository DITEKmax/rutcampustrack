# Ключ счётчика открытий карты

Для `academic-service` production Compose требует `CAMPUS_MAP_USAGE_HMAC_KEY`. Если переменная отсутствует или пуста, Compose остановится с сообщением об ошибке.

Задай её через используемое хранилище секретов как отдельный постоянный секрет длиной не менее 32 байт в UTF-8. Не используй ключи JWT или gRPC, не записывай секрет в репозиторий или логи и не генерируй его при запуске приложения.

Сохраняй одно значение между перезапусками: ключ формирует псевдоним владельца для дедупликации открытий карты. Его смена меняет этот псевдоним. Ротацию выполняй только по отдельному плану миграции и хранения данных.
