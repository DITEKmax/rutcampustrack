**2. Create `security/RequestContext.java`** (per D-01):

CRITICAL: `proxyMode = ScopedProxyMode.TARGET_CLASS` is mandatory — without it, singleton beans (RoleCheckAspect) will get a stale instance. See Pitfall 1 in RESEARCH.md.

**3. Create `security/RequestContextFilter.java`** (per D-01):
```java
@Component
public class RequestContextFilter extends OncePerRequestFilter {
    private final RequestContext requestContext;
    // constructor injection
    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain) {
        String userIdHeader = request.getHeader("X-User-Id");
        if (userIdHeader != null) {
            requestContext.setUserId(Long.parseLong(userIdHeader));
            requestContext.setRole(UserRole.valueOf(request.getHeader("X-User-Role").toUpperCase()));
            String groupIdHeader = request.getHeader("X-Group-Id");
            if (groupIdHeader != null && !groupIdHeader.isEmpty()) {
                requestContext.setGroupId(Long.parseLong(groupIdHeader));
            }
            requestContext.setHeadman(Boolean.parseBoolean(request.getHeader("X-Is-Headman")));
        }
        chain.doFilter(request, response);
    }
}
```
Note: Gateway already injects these headers. Filter parses them into the request-scoped bean.

**4. Create `security/RequireRole.java`** (per D-02):
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RequireRole {
    UserRole[] value();
}
```

**5. Create `security/RoleCheckAspect.java`** (per D-02):
```java
@Aspect
@Component
public class RoleCheckAspect {
    private final RequestContext requestContext;
    // constructor injection
    @Around("@annotation(requireRole)")
    public Object checkRole(ProceedingJoinPoint pjp, RequireRole requireRole) throws Throwable {
        UserRole[] required = requireRole.value();
        UserRole actual = requestContext.getRole();
        if (actual == null || !Arrays.asList(required).contains(actual)) {
            throw new AccessDeniedException("Required role: " + Arrays.toString(required));
        }
        return pjp.proceed();
    }
}
```

**7. Create `exception/GlobalExceptionHandler.java`**:
```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(ResourceNotFoundException.class) → 404 ErrorResponse
    @ExceptionHandler(AccessDeniedException.class) → 403 ErrorResponse
    @ExceptionHandler(BadRequestException.class) → 400 ErrorResponse
    @ExceptionHandler(ConflictException.class) → 409 ErrorResponse
    @ExceptionHandler(MethodArgumentNotValidException.class) → 400 ErrorResponse with fieldErrors list
    @ExceptionHandler(Exception.class) → 500 ErrorResponse (fallback)
}
```
Each handler builds `ErrorResponse` with: status, type URI (`https://api.rutcampustrack.ru/problems/{type}`), title in Russian, detail from exception message, instance from `request.getRequestURI()`, `Instant.now()` timestamp, fieldErrors (only for validation). Use `HttpServletRequest` parameter to get request URI.
