# DESIGN.md — RutCampusTrack

Дизайн-система веб-приложения учёта посещаемости и расписания вуза.
Поверхность — веб-десктоп 1920. Язык интерфейса только русский.

Две равноправные темы. Тёмная — родная среда системы, светлая проверяется наравне.
Композиция при смене темы не меняется, меняются только значения.

Имена токенов совпадают с `tokens-v2.json`. Значения здесь развёрнуты в hex,
потому что Stitch не работает со ссылками между слоями.

## 2. Типографика

Гарнитура — **Onest**, единственная в системе. Начертания 400, 500, 600.

**Табличные цифры включаются глобально, в корне документа:**

```css
:root { font-feature-settings: "tnum" 1, "lnum" 1; }
```

У Onest табличные цифры есть, но не по умолчанию. Без глобального правила числа
в таблицах не выстраиваются по разряду.

### 2.1. Шкала, корень 16px

| Стиль | Размер | Вес | Межстрочный | Межбуквенный | Где |
|---|---|---|---|---|---|
| `display` | 2rem | 600 | 1.15 | −0.015em | крупная метрика |
| `title-screen` | 1.5rem | 600 | 1.15 | −0.015em | заголовок экрана |
| `title-block` | 1.125rem | 600 | 1.35 | 0 | заголовок карточки, панели |
| `body` | 1rem | 400 | 1.5 | 0 | основной текст |
| `body-strong` | 1rem | 500 | 1.5 | 0 | значение в списке пар |
| `dense` | 0.875rem | 400 | 1.45 | 0 | ячейки таблиц, строки списков |
| `dense-strong` | 0.875rem | 500 | 1.45 | 0 | первый столбец, ФИО, итог |
| `caption` | 0.8125rem | 400 | 1.4 | 0 | подписи полей, подсказки |
| `micro` | 0.75rem | 500 | 1.35 | +0.01em | заголовки колонок, счётчики, символ статуса |

Прописные в разрядку не применяются: русский текст в разрядке теряет читаемость.
Заголовки колонок отличаются весом и приглушённостью, а не регистром.

### 2.2. Числа

- выключка вправо, разряд под разрядом;
- разделитель разрядов — пробел: `22 091`;
- ведущий ноль в нумерации: `01`, `02`, `08`;
- дробь «текущее из общего» как основная форма величины: `18/24`;
- процент не показывается без числителя и знаменателя рядом;
- единица мельче и приглушённее числа, вплотную: `45 мин`;
- отсутствие значения — прочерк `—`;
- даты фиксированной ширины `02.12.2025`, время 24-часовое.

Внутри ячейки таблицы `space/2`–`space/3`. Внутри карточки `space/4`.
Между блоками `space/6`. Между регионами страницы `space/8`.

### 3.2. Радиусы

| Токен | Значение | Что |
|---|---|---|
| `radius/sm` | 0.375rem | чипы, мелкие плашки, вложения |
| `radius/md` | 0.625rem | кнопки, поля ввода, пункты меню |
| `radius/lg` | 0.75rem | карточки, панели, поповеры |
| `radius/xl` | 1rem | крупные регионы, модалка |
| `radius/full` | 999px | статусы, кнопка-иконка без подписи, аватар |

### 3.3. Границы и фокус

| Токен | Значение |
|---|---|
| `border/hairline` | 1px |
| `border/emphasis` | 2px |
| `focus/width` | 2px |
| `focus/offset` | 2px |

`hairline` — всё по умолчанию. `emphasis` — выделенное состояние, обводка статуса,
акцентная рамка.

Кольцо фокуса — контур `color/border/focus` толщиной 2px с отступом 2px наружу,
по `:focus-visible`. Видимо в обеих темах. На элементе, несущем статус
посещаемости, кольцо берёт `color/status/*/ring`.

### 3.4. Плотность

| Токен | Значение |
|---|---|
| `row-height/compact` | 2rem |
| `row-height/regular` | 2.5rem |
| `row-height/roomy` | 3rem |
| `control/height` | 2.5rem |

Высота строки таблицы по умолчанию — `compact`: на 1920 это около пятидесяти строк
на экран. Высота контрола от плотности таблицы не зависит.

## 4. Тени

| Токен | Тёмная | Светлая |
|---|---|---|
| `shadow/raised` | `0 1px 2px rgba(0,0,0,0.60)` | `0 1px 2px rgba(41,37,49,0.06)` |
| `shadow/overlay` | `0 8px 24px rgba(0,0,0,0.70), 0 2px 6px rgba(0,0,0,0.50)` | `0 8px 24px rgba(41,37,49,0.12), 0 2px 6px rgba(41,37,49,0.08)` |

`raised` — карточка над фоном страницы. `overlay` — поповер, меню, модалка,
залипшая шапка.

**Тень дублирует, а не заменяет.** Уровень поверхности всегда несут собственный
токен поверхности и граница; тень идёт третьим носителем. Тень не может быть
единственным отличием одного уровня от другого.

Не больше одной ступени подъёма внутри региона: карточка над фоном — да,
карточка внутри карточки — нет.

## 5. Движение

| Токен | Значение | Где |
|---|---|---|
| `duration/instant` | 0ms | смена статуса на месте |
| `duration/fast` | 120ms | наведение, фокус, нажатие |
| `duration/base` | 180ms | раскрытие строки, появление панели |
| `duration/slow` | 260ms | полоса текущей пары, переход графика |
| `easing/out` | `cubic-bezier(0.2, 0, 0, 1)` | появление, раскрытие |
| `easing/in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | перемещение, перестроение |

При `prefers-reduced-motion: reduce` все длительности равны `duration/instant`,
переходы снимаются. Смысл сохраняется полностью: полоса текущей пары остаётся,
но заполняется дискретно.

## 6. Правила генерации

Это инструкции, а не справочные значения. Применять ко всем экранам.

1. **Тёмная тема родная.** Генерируй в тёмной, светлую проверяй наравне, а не по
   остаточному принципу. Композиция в обеих темах одинаковая — различаются только
   значения токенов.
2. **Ровно один выделенный объект на экран.** Акцент фиолетовый, его работа —
   «сейчас». Если выделено два объекта, экран сделан неверно.
3. **Акцент не заходит** в навигацию, кнопки действий, категории и типы, метрики,
   метку актуальности, служебные плашки. Активный пункт навигации выделяется
   нейтральной заливкой или границей.
4. **Градиентов, свечения и размытия нет.** Ни в заливках, ни в кнопках, ни в
   карточках, ни в шкалах.
5. **Иллюстраций на рабочих экранах нет.** Иконки строго функциональные, единого
   веса. Иллюстрация допустима только на экране входа.
6. **Статус кодируется символом и словом, цвет третий.** Символ (`+`, `у`, `н`)
   и подпись обязательны всегда; цвет только дублирует их.
7. **В плотных сетках отклика на наведение нет** — ячейки таблиц молчат.
   Единственное исключение — журнал посещаемости: там наведение и фокус
   подсвечивают строку и столбец целиком, поверхностью `color/surface/raised`,
   без изменения цвета текста и без сдвига геометрии.
8. **Наложений нет.** Формы, фильтры и панели раскрываются на самой странице
   сдвигом в разметке. Единственная модалка — подтверждение необратимого действия.
9. **Плотность — норма.** Разрежённые экраны хуже плотных. Не увеличивай отступы
   ради воздуха, не добавляй пустых зон.
10. **Только горизонтальные разделители** в сетках данных. Вертикальных линий,
    пунктирной сетки и фоновой линовки нет.
11. **Язык интерфейса только русский**, обращение на «ты». Приветствий по имени,
    восклицательных знаков и оценок поведения пользователя нет.
12. **Пустое состояние — факт времени,** а не извинение: «сегодня пар нет»,
    «семестр не начался». Иллюстраций в пустых состояниях нет.

## 7. Чего в этом файле нет

Перечислено, чтобы не додумывалось при генерации.

- **Анатомия компонентов и их размерные варианты** — отдельный документ
  `figma-spec.md`, Stitch его не читает.
- **Состав экранов, поведение, механика отметки, права ролей** — вне этого файла.
- **Цвета серий графиков.** Не назначены. Серии различаются подписями и рисунком
  линии, а не только цветом.
- **Набор иконок.** Не выбран. Требование — системный и расширяемый,
  единого веса, читаемый в мелком размере.
- **Ширины колонок сетки страницы и максимальная ширина контента.** Задаются
  на этапе экранов.
- **Поведение на узкой ширине.** Проверка отложена; файл описывает десктоп 1920.
