2. `testAdminCreateUser_validationError_returns400WithFieldErrors()`:
   POST `/academic/users` with admin headers, body: `{"displayName": "", "role": "STUDENT"}` (empty name).
   Assert: status 400, response `type` = `https://api.rutcampustrack.ru/problems/validation-error`, response contains `fieldErrors` array with entry for `displayName`.

3. `testStudentCannotCreateUser_returns403()`:
   POST `/academic/users` with student headers.
   Assert: status 403, response `type` = `https://api.rutcampustrack.ru/problems/forbidden`.

4. `testAdminCreateAndActivateSemester()` — GSEM-02, GSEM-03:
   POST `/academic/semesters` with admin headers, body semester 1. Assert 201.
   POST `/academic/semesters` with admin headers, body semester 2. Assert 201.

   PATCH `/academic/semesters/{id2}/activate`. Assert 200, isActive=true.
   GET `/academic/semesters/{id1}`. Assert isActive=false (deactivated atomically).

5. `testSemesterDeleteWithWrongConfirmation_returns400()` — GSEM-04:
   Create semester "Fall 2025". DELETE with `{"confirmation": "wrong name"}`. Assert 400.

6. `testStudentGetMe_returnsOwnProfile()` — USER-06:
   Create a student user (as admin). GET `/academic/users/me` with student headers (X-User-Id = created user's ID).
   Assert: status 200, response login matches created user.

   As admin: PUT `/academic/thresholds/global` with `{"minPercentage": 50}`.

   GET `/academic/thresholds/resolve?groupId={gid}&subjectId=null`. Assert level="group", minPercentage=70.
   GET `/academic/thresholds/resolve?groupId=null&subjectId=null`. Assert level="global", minPercentage=50.

8. `testListUsers_returnsPaginatedHateoas()` — HATEOAS:
   Create 3 users. GET `/academic/users?page=0&size=2` with admin headers.
