<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL entry ↔ Angular Router | Router matches path → applies canActivate chain → loads component |
| guestGuard ↔ already-authenticated user | Защищает форму логина от повторного доступа |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-10 | Elevation of Privilege | TEACHER пытается открыть `/student/dashboard` напрямую | mitigate | `canActivate: [studentGuard]` на `/student` блоке. studentGuard (Plan 02) редиректит TEACHER на `/teacher/dashboard`. |
| T-50-11 | Elevation of Privilege | Plain STUDENT открывает `/headman/dashboard` напрямую | mitigate | `canActivate: [headmanGuard]` на `/headman` блоке. headmanGuard редиректит plain STUDENT на `/student/dashboard` (D-10). |
| T-50-12 | Spoofing | Аутентифицированный пользователь видит форму логина и повторно логинится | mitigate | `canActivate: [guestGuard]` на `/login` маршруте. guestGuard редиректит на resolveDashboardFor. |
| T-50-13 | Information Disclosure | Заголовок в sidebar показывает 'Студент' или 'Староста' для incorrect роли | accept | `data: { eyebrow }` — просто visual breadcrumb, не раскрывает данные. Guard отфильтровал пользователя до рендеринга. |
| T-50-14 | Tampering | Placeholder компонент подвергается inject через user input | accept | Placeholder — статический template без привязок к user input. Нет XSS vector. |
</threat_model>
