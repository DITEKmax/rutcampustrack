| Route | Screen | Tab |
|-------|--------|-----|
| `/stats` | AttendanceStatsPage | Новый таб «Статистика» в BottomNav |

**BottomNav update:** Current 4 tabs (Главная, Расписание, Отметка, Профиль) expand to 5 or the «Главная» placeholder is replaced. Phase 32 adds «Статистика» and «Задания». With 5+ tabs the BottomNav fits within `justify-around` layout — existing pattern holds, each tab remains `min-w-[44px]`.

## Spacing Scale

Declared values (multiples of 4). Inherited from existing codebase — do not change.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-label gaps, badge internal padding (`px-1 py-0.5`) |
| sm | 8px | Compact row gaps, checkbox margin |
| md | 16px | Card internal padding (`px-4`), page horizontal padding |
| lg | 24px | Section heading top spacing |
| xl | 32px | Empty state vertical centering padding |
| 2xl | 48px | Empty state top offset (`py-16 = 64px` — existing pattern) |
| 3xl | 64px | Page-level `pb-20` bottom padding (BottomNav clearance) |

Exceptions:
- Touch targets: all interactive rows and checkboxes must be `min-h-[44px]` (iOS HIG minimum — established pattern in BottomNav and buttons)
- Subject row tap area: full-width, `min-h-[56px]` to accommodate two-line subject names

## Typography

All sizes in px; Tailwind class equivalent in parentheses. Source: observed in SchedulePage and LessonCard.

| Role | Size | Tailwind | Weight | Line Height | Used For |
|------|------|----------|--------|-------------|----------|
| Display | 20px | `text-xl` | 600 semibold | 1.3 (`leading-snug`) | Subject name on stats row, page section heading |
| Body | 16px | `text-base` | 600 semibold | 1.25 | Time range, percentage value (`"73%"`) |
| Body | 14px | `text-sm` | 400 regular | 1.5 | Count breakdown (`"б: 12 / н: 3 / у: 2"`), homework deadline, muted secondary text |
| Label | 12px | `text-xs` | 600 semibold | 1.0 | Status badge labels (`б`, `н`, `у`, `сп`), homework completion toggle caption |

Two weights in use: regular (400) and semibold (600). No other weights.

## Color

Inherited from `index.css` CSS variables (neutral palette). Extend with semantic status colors already established in StatusBadge.tsx.

| Role | oklch value | Tailwind / Usage |
|------|-------------|-----------------|
| Dominant (60%) | `oklch(1 0 0)` light / `oklch(0.145 0 0)` dark | `bg-background` — page background |
| Secondary (30%) | `oklch(1 0 0)` light / `oklch(0.205 0 0)` dark | `bg-card` — subject row cards, homework item cards |
| Accent (10%) | `oklch(0.205 0 0)` light / `oklch(0.922 0 0)` dark | `bg-primary` / `text-primary` — checked homework checkbox fill, active tab indicator |
| Destructive | `oklch(0.577 0.245 27.325)` | `text-destructive` / `bg-destructive/10` — red zone warning only |

Accent reserved for:
1. Checkbox fill state when homework is marked done
2. Active BottomNav tab indicator dot (existing pattern, unchanged)
3. "Сегодня" floating pill (existing pattern, unchanged)

**Status colors (from StatusBadge.tsx — MUST match exactly):**

| Status | Russian abbrev | Background | Text |
|--------|---------------|------------|------|
| present | б | `bg-green-100` | `text-green-700` |
| absent | н | `bg-red-100` | `text-red-700` |
| excused | у | `bg-yellow-100` | `text-yellow-700` |
| free_attendance | сп | `bg-blue-100` | `text-blue-700` |

**Red zone warning color:**
- Subject row in red zone: left border `border-l-4 border-destructive` + percentage text `text-destructive font-semibold`
- Subject row above threshold: no colored border, percentage text `text-foreground`
- Red zone badge: `bg-red-100 text-red-700 text-xs` pill with label «Красная зона»

## Interaction Contracts

### ATT-01 / ATT-02: Attendance Stats

| Interaction | Behavior |
|-------------|----------|
| Page load | TanStack Query fetches stats; show `LoadingSpinner` during fetch |
| Empty state | No attendance data yet: heading "Нет данных", body "Посещаемость ещё не была зафиксирована" |
| Error state | "Не удалось загрузить данные. Проверьте соединение и попробуйте снова." + retry button |
| Red zone row | `border-l-4 border-destructive` + `RedZoneBadge` + percentage in `text-destructive` |
| Row tap | Navigate to `/stats/:subjectId` with subject name as route state for page title |

### ATT-03: Attendance Records

| Interaction | Behavior |
|-------------|----------|
| Page load | Fetch records for subjectId; `LoadingSpinner` during fetch |
| Back navigation | `CaretLeft` button → `router.back()` or `navigate('/stats')` |
| Empty state | "Нет записей" heading, body "Посещаемость по этому предмету не зафиксирована" |
| Error state | Same error copy as stats page |
| Scroll | Full-height scrollable list, `pb-20` for BottomNav clearance |

### HW-01: Homework List

| Interaction | Behavior |
|-------------|----------|
| Page load | TanStack Query fetches homework by groupId; `LoadingSpinner` during fetch |
| Empty state | Heading "Нет заданий", body "Домашних заданий пока нет" |
| Error state | "Не удалось загрузить задания. Проверьте соединение и попробуйте снова." |
| Sort order | Undone items first, sorted by deadline ascending; done items below |

### HW-02: Homework Completion Toggle

| Interaction | Behavior |
|-------------|----------|
| Tap checkbox | Optimistic update — immediate visual toggle |
| Success | State persists in localStorage keyed by `hw:{userId}:{homeworkId}` |
| Error | Revert checkbox to previous state; show inline text "Не удалось сохранить" in `text-destructive text-xs` below item |
| Re-open app | Read from localStorage — state persists client-side |

Note: HW-02 is client-side only. The backend has no "completion" endpoint for individual students — persists in localStorage, not a server mutation.

## Animation Contract

Consistent with established Motion patterns from SchedulePage:

| Trigger | Animation | Values |
|---------|-----------|--------|
| Page mount | `initial={{ opacity: 0, y: 8 }}` → `animate={{ opacity: 1, y: 0 }}` | `duration: 0.15, ease: 'easeOut'` — handled by AppShell |
| Stats list items | Stagger children `0.04s`, `opacity: 0 → 1` | Same as lesson cards |
| Homework item toggle | `layout` animation on list reorder (done items move to bottom) | `transition={{ type: 'spring', stiffness: 300, damping: 30 }}` |
| Checkbox state change | `scale: 0.85 → 1` on tap (spring) | `stiffness: 400, damping: 20` |

## API Surface (for executor reference)

| Requirement | Endpoint | Notes |
|-------------|----------|-------|
| ATT-01/02 | `GET /api/attendance/stats?studentId={id}` | Returns per-subject: percentage, present/absent/excused counts, redZone boolean |
| ATT-03 | `GET /api/attendance/records?studentId={id}&subjectId={id}` | Returns list: date, lessonName, status |
| HW-01 | `GET /api/schedule/homework?groupId={id}` | Returns list: id, title, subjectName, deadline |
| HW-02 | localStorage only | Key: `hw:{userId}:{homeworkId}`, value: `"done"` or absent |

Route through API Gateway at port 8080.
