    **Create `GrpcExceptionAdvice.java`** in package `ru.rutcampustrack.academic.grpc`:
    ```java
    package ru.rutcampustrack.academic.grpc;

    import io.grpc.Status;
    import net.devh.boot.grpc.server.advice.GrpcAdvice;
    import net.devh.boot.grpc.server.advice.GrpcExceptionHandler;
    import ru.rutcampustrack.academic.contract.exception.ResourceNotFoundException;

    @GrpcAdvice
    public class GrpcExceptionAdvice {

        @GrpcExceptionHandler(ResourceNotFoundException.class)
        public Status handleNotFound(ResourceNotFoundException e) {
            return Status.NOT_FOUND.withDescription(e.getMessage()).withCause(e);
        }

        @GrpcExceptionHandler(IllegalArgumentException.class)
        public Status handleBadRequest(IllegalArgumentException e) {
            return Status.INVALID_ARGUMENT.withDescription(e.getMessage()).withCause(e);
        }

        @GrpcExceptionHandler(Exception.class)
        public Status handleInternal(Exception e) {
            return Status.INTERNAL.withDescription("Internal server error").withCause(e);
        }
    }
    ```

    **Create `AcademicGrpcServiceImpl.java`** in package `ru.rutcampustrack.academic.grpc`:

    - Annotate with `@GrpcService`
    - Extend `AcademicGrpcServiceGrpc.AcademicGrpcServiceImplBase`
    - Constructor-inject these 6 repositories: `GroupRepository`, `UserRepository`, `SemesterRepository`, `SubjectRepository`, `TeacherSubjectGroupRepository`, `CampusSettingRepository`
    - CRITICAL: Do NOT inject any REST service (GroupService, UserService, etc.) — they depend on RequestContext which is request-scoped and unavailable in gRPC context (per RESEARCH.md Pitfall 1)

    **RPC implementations:**

    **getGroup (GRPC-01):** Query `groupRepository.findById(request.getGroupId())`. If empty, throw `ResourceNotFoundException("Group", "id", request.getGroupId())`. Map to `GroupResponse` with `id`, `name`, `code`, `isActive`.

    **getGroupMembers (GRPC-02):** Query `userRepository.findByGroupId(request.getGroupId())` — this returns only active (non-archived) users due to `@SQLRestriction` on User entity (per D-04). Map each user to `StudentInfo` with `userId=user.getId()`, `displayName=user.getDisplayName()`, `isHeadman=user.isHeadman()`, `telegramId=user.getTelegramId() != null ? user.getTelegramId() : 0`. Build `GroupMembersResponse` with the list.

    **getTeacherSubjects (GRPC-03):** Query `assignmentRepository.findByTeacherIdAndSemesterId(request.getTeacherId(), request.getSemesterId())`. For each `TeacherSubjectGroup`, look up `subjectRepository.findById(a.getSubjectId())` and `groupRepository.findById(a.getGroupId())`. Skip entries where either is missing. Build `TeacherSubjectInfo` with `subjectId`, `subjectName=subject.getName()`, `subjectType=subject.getType().name().toLowerCase()`, `groupId`, `groupName=group.getName()`. Return `TeacherSubjectsResponse` with the list.

    **isHeadman (GRPC-04):** Query `userRepository.findById(request.getUserId())`. If empty, return `HeadmanCheckResponse` with `isHeadman=false`. Otherwise check `user.isHeadman() && user.getGroupId() != null && user.getGroupId().equals(request.getGroupId())`.

    **getActiveSemester (GRPC-05):** Query `semesterRepository.findByIsActiveTrue()`. If empty, throw `ResourceNotFoundException("Semester", "isActive", true)`. Map to `SemesterResponse` with `id`, `name`, `dateFrom=semester.getDateFrom().toString()` (ISO-8601), `dateTo=semester.getDateTo().toString()`.

    **getCampusGeofence (GRPC-06):** Query `campusSettingRepository.findById(1L)`. If empty, throw `ResourceNotFoundException("CampusSetting", "id", 1L)`. Map to `GeofenceResponse` with `lat`, `lng`, `radiusM`.

    **getUserById (GRPC-07):** Use `userRepository.findByIdIncludingArchived(request.getUserId())` — this native query bypasses `@SQLRestriction` so downstream services can access historical data for archived users. If empty, throw `ResourceNotFoundException("User", "id", request.getUserId())`. Map to `UserResponse` with `id`, `login`, `displayName`, `role=user.getRole().name().toLowerCase()`, `status=user.getStatus().name().toLowerCase()`, `groupId=user.getGroupId() != null ? user.getGroupId() : 0`, `isHeadman`, `telegramId=user.getTelegramId() != null ? user.getTelegramId() : 0`.

    After creating both files, run `.\gradlew.bat :services:academic-service:academic-app:compileJava` to verify compilation.
