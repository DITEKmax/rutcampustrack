# Проверка входных материалов

Дата: 2026-10-23. Источники прочитаны; исходная папка не изменялась.

## Результат

- 388 PNG, 93 489 759 bytes (около89.16MiB).
- 33 основных вида экранов: auth5/student8/headman11/teacher4/admin5.
- Группы физических папок:31, потому что auth пароль/OTP/QR лежат вместе.
- Каждый PNG проверен по signature, структуре chunks, CRC, IHDR и IEND.
- Все388 имён и размеров точно сопоставлены с соответствующими Figma frames.
- Нет unmatched, dimension mismatch, отсутствующих PNG относительно этих
  экспортируемых frames и одинакового содержимого по SHA256.
- SHA256 нужен для передачи/целостности, не для закрепления реализации в тестах.

## Темы и размеры

Темнота:300/425/600/768/1024/1280/1440/1920.
Auth light тоже на всех восьми. Остальные28 видов light только1280/1440/1920.
Нет140 light сочетаний на300/425/600/768/1024: их нет и в соответствующем
экспортном наборе Figma. Это известный дизайн-gap, который владелец разрешил
заполнить по dark композиции; не ошибка копирования.
Полный базовый объём themes×widths:33×8×2=528 вариантов, не отдельных страниц кода.
Высота PNG проверена против Figma; высота готовой реализации может изменяться
по разрешённой доработке композиции.

## Организация

Исходные role folders и имена сохранены, в том числе headmen-11, ststistic,
rullung the pairs. В manifest используется канонический role=headman.
Переименование сотен файлов не требуется: portable paths + role/node IDs
снимают неоднозначность. Отдельных SVG в папке screenshots не было;
icons Figma metadata и repository SVG index приложены в handoff.

## Ограничения проверки

Это проверка полноты экспортов и структуры/целостности файлов, не ручное
визуальное сравнение каждого пикселя и не декодирование всех изображений
на реальном экране. PNG chunk CRC не доказывает соответствие бизнес-сценарию.
Нет утверждения, что в33 макетах перечислены все backend функции и состояния.
Нет runtime проверки будущего web, тем, realtime, auth или браузеров.

Metadata шести Figma страниц сохранена. Variable/style dumps выборочные,
не полная design-system выгрузка каждого узла. Auth содержит дополнительные
template/QA frames вне demo экспортов. Большие student/headman contexts вернули
SPARSE; продолжить извлечение на дочерних блоках после GO.
Готовые Vue/PCSS файлы не генерировались, Figma не изменялась.
