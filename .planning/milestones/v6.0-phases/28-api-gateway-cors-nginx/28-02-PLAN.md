    **File 1: `frontends/pwa/nginx.conf`**

    ```nginx
    server {
        listen 80;
        root /usr/share/nginx/html;
        index index.html;

        # Service worker and entry point — must not be cached
        location ~* ^/(sw\.js|index\.html)$ {
            add_header Cache-Control "no-cache, no-store, must-revalidate";
            add_header Pragma "no-cache";
            expires 0;
        }

        # Static assets (JS/CSS with content hash) — cache aggressively
        location ~* \.(js|css|png|jpg|jpeg|svg|ico|woff|woff2)$ {
            add_header Cache-Control "public, max-age=31536000, immutable";
        }

        # SPA fallback — all routes go to index.html
        location / {
            try_files $uri $uri/ /index.html;
        }
    }
    ```

    Note: The `sw.js` location block uses regex `^/(sw\.js|index\.html)$` which takes priority over the general static assets block because nginx processes regex locations before prefix locations. The `sw.js` file will match the no-cache rule, NOT the aggressive cache rule for `.js` files, because regex locations are evaluated before the extension-based location.

    ```yaml
      # ============================================================
      # PWA
      # ============================================================

      pwa-nginx:
        image: nginx:1.27-alpine
        container_name: rct-pwa-nginx
        ports:
          - "80:80"
        volumes:
          - ./frontends/pwa/dist:/usr/share/nginx/html:ro
          - ./frontends/pwa/nginx.conf:/etc/nginx/conf.d/default.conf:ro
        networks:
          - private_net
        restart: unless-stopped
    ```

    Place it between the `notification-bot` service and the `networks:` section at the bottom.

    Key details:
    - `image: nginx:1.27-alpine` — pinned version for reproducibility (~12 MB image)
    - `ports: "80:80"` — PWA accessible at http://localhost:80
    - Two bind mounts: dist directory (content) and nginx.conf (config), both read-only (`:ro`)
    - On `private_net` so it can reach the gateway if needed in future
    - No `depends_on` — nginx serves static files independently
    - No healthcheck needed — nginx starts instantly and serves static files
