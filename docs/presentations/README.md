# Галереи RutCampusTrack

Открой [index.html](index.html) или отдельную галерею в браузере. Каждая галерея содержит кадры и Onest внутри файла, работает без приложения, локального сервера и доступа к сети. Слева PWA, справа TMA.

Имена принятых итераций неизменяемые: следующие правки получают новый файл. `manifest.json` фиксирует SHA256 и размер исходного принятого HTML. Это снимки интерфейса, а не второе приложение; source, synthetic/live ограничения и проверка настоящего Telegram перечислены внутри галерей.

Каталог предназначен для локального просмотра и презентации в репозитории. Публикация и push не выполняются автоматически.
