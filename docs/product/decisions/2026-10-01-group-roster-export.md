# Выгрузка состава группы

Решение владельца от 2026-10-01: ответ «Да, такой состав» на уточнение полей серверной выгрузки.

Файл содержит номер строки по алфавиту, ФИО, логин и роль в группе. В шапке — название группы и дата выгрузки. Пароли, Telegram ID и ссылки восстановления не включаются.

Это отдельный контекст отчёта по текущему составу группы, предусмотренный ПК-116 §4.6. Доступ старосты ограничен своей группой. Ранее согласованное право помощника «Просмотр статистики» не предоставляет выгрузку персонального состава группы: см. решение 2026-09-24-assistant-report-export.md.

Сервер использует существующую инфраструктуру форматов и шаблонов. Подключение кнопки и визуальная сверка относятся к следующему frontend-этапу.
