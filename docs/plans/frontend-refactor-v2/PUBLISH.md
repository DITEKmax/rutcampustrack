## Состав

- Общие Vue features и оформление PWA/TMA/Web для студента, старосты, преподавателя и администратора.
- Уведомления, профиль, темы, вход и восстановление, журнал, статистика, заявки, документы, группа, предметы, расписание, карты и вход из Telegram-уведомления с анимацией.
- Связанные изменения Academic, Attendance, Schedule, Auth, Mobile BFF, Notification и бота; additive proto/API, актуальные OpenAPI snapshots и generated TS consumers.
- Миграция Schedule V36 находится в штатном Flyway пути. Это публикация исходников; production migration и deploy выполняются отдельным релизным шагом.
- Полный поэкранный состав и доказательства отдельных пакетов: [PLAN.md](PLAN.md), документы 01–09 рядом с ним.

Локальная демонстрационная обвязка, raw HTML, архивы моков, бинарник тестовой MongoDB, временные логи и накопленные process CURRENT/SLOTS/checks/metrics не добавляются в публикационный коммит. Production entrypoints используют действующие API и не включают локальную визуальную оболочку.

Потеря сети обнуляла progress, который подтверждал привязку предмета семестру. Из-за этого карточка перемещалась в «Семестр не указан». Смена контекста, семестра и восстановление сети очищают snapshot и требуют загрузки заново. Исходный падающий тест сохранён и усилен.

## GitHub и следующий шаг

Main защищён от удаления и non-fast-forward; правила проверены, bypass не требуется. Публикация выполняется обычным fast-forward без force.
