24 оригинальных runtime кадров на настоящем изолированном backend. Это render samples, не отдельные тесты или действия. Figma/reference здесь отсутствуют.

  • 6 семейств ×300/1440 ×light/dark, точный root634cd до copy-only correction01b39.
  • Read-only canonical home: FULL1→dashboard, USERS_VIEW-only17→users; обе собственные сессии logout204.
  • Реальная system тема следует browser media; private dialogs/credentials/capabilities не публикуются.
  • Источник старых46 кадров имеет отдельные честные provenance ограничения; они не подменяют эти24.
  • Положительные ACCESS/promotion/activation/FULL-self/map-final/group-final gates остаются; галерея их не закрывает.

Точные metadata и SHA256. Для просмотра открой index.html рядом с папкой screenshots из checkout или ZIP существующей ветки PR3; сайт не публиковался.
