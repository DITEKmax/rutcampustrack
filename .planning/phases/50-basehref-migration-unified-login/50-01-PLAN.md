```typescript
// frontends/web-panel/src/app/core/auth/auth.service.ts:18-32
readonly currentUser = computed((): AuthUser | null => {
  const token = this._accessToken();
  if (!token) return null;
  try {
    const parts = token.split('.');
    if (parts.length !== 3) return null;
    const payload = JSON.parse(atob(parts[1]));
    return {
      id: Number(payload.sub),
      role: (payload.role as string).toUpperCase() as 'TEACHER' | 'ADMIN',
    };
  } catch {
    return null;
  }
});
```

```java
return Jwts.builder()
    .claim("role", user.getRole().name())    // → "ADMIN" / "TEACHER" / "STUDENT"
    .claim("group_id", user.getGroupId())    // → Long | null
    .claim("is_headman", user.isHeadman())  // → boolean true/false
    .subject(user.getId().toString())        // → числовая строка "1"
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser ↔ JWT claims | Клиентский JWT декодируется без сигнатурной проверки — клиент доверяет серверу что JWT подписан HS256 и не тамперен в транспорте (HTTPS) |
| AuthUser signal ↔ app code | `currentUser()` — единственный централизованный источник роли и isHeadman для всех UI-компонентов и guards |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-01 | Tampering | JWT `is_headman` claim decoded client-side | accept | Клиент-side is_headman влияет ТОЛЬКО на UI маршрутизацию. Серверная авторизация (API Gateway + WPAN-13 в Phase 54) валидирует `is_headman` из свежего JWT на каждом запросе. Клиент-side tamper даёт только возможность увидеть пустой placeholder экран. Sidebar/navigation — UX affordance, не access control. |
| T-50-02 | Information Disclosure | `groupId` из JWT читается clientside | accept | `groupId` — публичная информация для владельца JWT (его собственная группа). Логирование не производится. |
