<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP Client → ExcuseController | JWT claims (userId, role, groupId, isHeadman) доверяются как header-ам от API Gateway |
| ExcuseService → MongoDB | Все запросы с context.userId — могут содержать инъекции |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-59-02-01 | Spoofing | ExcuseController: headman claims | mitigate | requestContext.isHeadman() читается из JWT через X-Is-Headman header; API Gateway ставит его из токена — нельзя подделать из браузера |
| T-59-02-02 | Elevation of Privilege | updateStatus: plain STUDENT пытается approve | mitigate | if (!requestContext.isHeadman()) throw AccessDeniedException — проверка в ExcuseService.updateStatus |
| T-59-02-03 | Information Disclosure | getGroupTickets: headman видит чужую группу | mitigate | if (requestContext.getGroupId() != groupId) throw AccessDeniedException |
| T-59-02-04 | Elevation of Privilege | headman самоодобрение тикета | mitigate | if (ticket.getStudentId().equals(requestContext.getUserId())) throw ConflictException |
</threat_model>
