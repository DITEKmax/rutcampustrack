# Подробности студента в статистике старосты

Решение владельца 2026-09-25 в главном чате: подтверждены все предложенные подробности.

Встроенная панель выбранного по ID студента показывает показатели по предметам и типам занятий, динамику по неделям и историю заявок с решениями. Панель немодальная, доступна старосте и помощнику с действующим VIEW_STATS в рамках своей группы; история учитывает датированное членство. Это уточняет открытый состав ПК113 §4.9 и не разрешает отдельную выгрузку персонального состава группы.
