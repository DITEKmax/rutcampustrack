## Приоритет при расхождении

1. `brandbook-v2.md` — значения и состояния
2. `BRAND_DIRECTION.md` — характер и запреты
3. `COMPONENT_REGISTRY.md` — состав компонентов
4. `tokens-v2.json` — имена токенов
5. `figma-spec.md` — анатомия
6. `figma-spec-shadcn-overlay.md` — **выше `figma-spec.md` по составу базовых контролов**

Скилл `rutcampustrack-design` — выжимка из этих файлов. При расхождении выигрывает файл, а не выжимка.

## Как читать большие файлы

`COMPONENT_REGISTRY.md` и `figma-spec.md` в контекст целиком не помещаются. У обоих есть оглавление в начале: находить нужный раздел по нему и читать диапазоном строк. Не пересказывать себе файл «в общих чертах» — из этого получаются несуществующие правила.

Если правила для ситуации в этих файлах нет — сказать отдельным списком в конце ответа. Не подставлять умолчание и не ссылаться на пункт, которого нет.
