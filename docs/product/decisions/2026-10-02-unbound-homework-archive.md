# ДЗ без привязки: дата архивирования — 2026-10-02

Прямое решение владельца в главном чате: «Да, в 00:00 следующего дня по Москве».

Задание в режиме «любой день», без привязки к паре, автоматически становится архивным в начале следующего календарного дня по Europe/Moscow после выбранной даты. Граница включительная: начиная с этого момента задание не редактируется и не возвращается из архива; при необходимости создаётся новое.

Для задания с привязкой сохраняются принятые правила окончания/отмены пары. Режим без привязки не следует за переносом какой-либо пары. Сохраняются история и отметки выполнения; архивирование не означает физического удаления.

Основание режима и истории: JS-HEADMAN-16/17/28/29 в docs/research/reference-rutcampustrack-design/knowledge/job-stories.md. Это решение закрывает только ранее открытое время автоархивации режима без пары. Оно не разрешает production-миграции или deploy.
