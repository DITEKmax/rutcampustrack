# M17 — Decisions

Архитектурные решения, принятые в ходе milestone. Заполняется по мере
работы; на старте — пусто.

Формат: `### Dx (YYYY-MM-DD) — короткое название`, потом контекст /
решение / альтернативы / последствия.

---

## D1 (2026-04-28) — Формат файла = `.docx`, не PDF/Excel

**Контекст:** Деканат принимает отчёты в строгом формате. У старосты
есть готовый эталон, нарисованный в Word.

**Решение:** Генерируем `.docx`, используя готовый шаблон + подстановку
плейсхолдеров. PDF/Excel не делаем.

**Альтернативы:**
- Excel `.xlsx` — отвергнут: эталон в Word, деканат может потребовать
  именно doc.
- PDF — отвергнут: деканат в гос-учреждениях обычно требует
  редактируемый формат (для своих правок/штампов).

**Последствия:** Завязка на стек генерации docx (POI / docx4j /
docx-stamper). Шаблон должен лежать как ассет в репо.

---

## D2 (2026-04-28) — Только web-panel, не PWA (для первой версии)

**Контекст:** Староста скачивает отчёт для печати/email. На телефоне
docx неудобен.

**Решение:** Кнопка «Скачать» только в web-panel. PWA не получает
функционал.

**Альтернативы:** Дублировать в PWA — отвергнуто как лишняя работа без
явной пользы.

**Последствия:** Если кто-то всё-таки попросит на телефоне — добавим
позже. Эндпоинт уже будет готов.
