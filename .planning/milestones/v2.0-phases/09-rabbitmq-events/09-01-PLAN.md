**2. Create `DomainEvent.java` in package `ru.rutcampustrack.academic.event` (per D-03, D-06):**

Abstract class extending `org.springframework.context.ApplicationEvent`. This class represents the ENVELOPE -- it holds only the envelope fields, NOT the payload. Constructor takes `Object source`, `String eventType`, and `Object payload`. Auto-generates:
- `eventId` = `UUID.randomUUID()` (serializes as `event_id` via `@JsonProperty("event_id")`)
- `occurredAt` = `OffsetDateTime.now()` (serializes as `occurred_at` via `@JsonProperty("occurred_at")`)
- `eventType` stored as field (serializes as `event_type` via `@JsonProperty("event_type")`)
- `payload` stored as field (serializes as `payload` via `@JsonProperty("payload")`) -- this is the nested payload object

Add `@JsonIgnoreProperties({"source", "timestamp"})` at class level to prevent ApplicationEvent internal fields from being serialized into the AMQP message. Provide public getters for all four fields (eventId, occurredAt, eventType, payload). Mark class `@JsonTypeInfo(use = JsonTypeInfo.Id.NONE)` to prevent any default typing from interfering.

**CRITICAL per D-03:** The serialized JSON MUST have the structure `{"event_type": "...", "event_id": "...", "occurred_at": "...", "payload": {...}}` where `payload` is a NESTED object containing entity-specific fields. The `DomainEvent` base class holds the envelope; each subclass defines a `Payload` inner record/class for the nested object.

**4. Create `RabbitConfig.java` in package `ru.rutcampustrack.academic.event` (per D-07, D-08, D-09):**

```java
@Configuration
public class RabbitConfig {

    @Bean
    public FanoutExchange academicEventsExchange() {
        return new FanoutExchange("rut-uit.events", true, false);
        // durable=true, autoDelete=false (per D-07)
    }

    @Bean
    public Jackson2JsonMessageConverter jacksonMessageConverter(ObjectMapper objectMapper) {
        return new Jackson2JsonMessageConverter(objectMapper);
        // Uses the Spring Boot autoconfigured ObjectMapper with JavaTimeModule (per D-08)
        // Do NOT create new ObjectMapper() -- would lose JavaTimeModule (Pitfall 3 from RESEARCH.md)
    }

    @Bean
    public RabbitTemplate rabbitTemplate(ConnectionFactory connectionFactory,
                                          Jackson2JsonMessageConverter converter) {
        RabbitTemplate template = new RabbitTemplate(connectionFactory);
        template.setMessageConverter(converter);
        // Do NOT set channelTransacted=true -- causes message loss with AFTER_COMMIT (Pitfall 1 from RESEARCH.md)
        return template;
    }
}
```

**5. Create `DomainEventListener.java` in package `ru.rutcampustrack.academic.event` (per D-04, D-05):**

```java
@Component
public class DomainEventListener {

    private static final Logger log = LoggerFactory.getLogger(DomainEventListener.class);
    private static final String EXCHANGE = "rut-uit.events";

    private final RabbitTemplate rabbitTemplate;

    public DomainEventListener(RabbitTemplate rabbitTemplate) {
        this.rabbitTemplate = rabbitTemplate;
    }

    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onDomainEvent(DomainEvent event) {
        log.debug("Publishing event: type={}, id={}", event.getEventType(), event.getEventId());
        rabbitTemplate.convertAndSend(EXCHANGE, "", event);
    }
}
```

Use `org.springframework.transaction.event.TransactionalEventListener` and `org.springframework.transaction.event.TransactionPhase`. Fire-and-forget -- no retry logic needed (Claude's discretion from CONTEXT.md).
