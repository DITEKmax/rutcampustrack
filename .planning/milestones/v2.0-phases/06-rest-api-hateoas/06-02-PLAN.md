public interface UserApi {
    @PostMapping ResponseEntity<EntityModel<UserCreatedResponse>> createUser(@Valid @RequestBody CreateUserRequest);

    @GetMapping ResponseEntity<PagedModel<EntityModel<UserResponse>>> listUsers(...);

    @PostMapping("/{id}/transfer") ResponseEntity<EntityModel<UserResponse>> transferStudent(...);

public interface GroupApi {

**UserService.java** — `@Service` with constructor injection of `UserRepository`, `HeadmanAssistantRepository`, `StudentGroupHistoryRepository`, `RequestContext`, `UserAssembler`:
- Field: `private final PasswordEncoder passwordEncoder = new BCryptPasswordEncoder();`
- Field: `private static final String CHARSET = "ABCDEFGHJKLMNPQRSTUVWXYZabcdefghjkmnpqrstuvwxyz23456789";` (no ambiguous chars)

**createUser(CreateUserRequest request)** — per D-08, D-09, USER-01:
1. Generate login: `role == STUDENT ? String.format("student%05d", userRepository.nextStudentLoginSeq()) : String.format("teacher%05d", userRepository.nextTeacherLoginSeq())`. For ADMIN role, use teacher sequence with prefix "admin".
2. Generate random 12-char password from CHARSET using `SecureRandom`
3. Hash with `passwordEncoder.encode(plainPassword)`
4. Build User entity: set login, displayName, passwordHash, role, status=ACTIVE, groupId (required for STUDENT), employeeNumber (for TEACHER), telegramId, isHeadman=false, createdAt=now
5. `userRepository.save(user)`
6. Return `UserCreatedResponse` with `initialPassword` = plain password (exposed ONE TIME only per D-10)

**getUser(Long id)** — per USER-02:
- `@RequireRole({ADMIN})` — admin uses `findByIdIncludingArchived(id)` to see archived users too (Pitfall 6)
- Throws `ResourceNotFoundException("User", id)` if not found

**listUsers(UserRole roleFilter, Pageable pageable)** — per USER-02:
- `@RequireRole({ADMIN})`
- If roleFilter != null: `userRepository.findByRole(roleFilter, pageable)` else `userRepository.findAll(pageable)`
- Return via `pagedAssembler.toModel(page, userAssembler)`

**updateUser(Long id, UpdateUserRequest request)** — per USER-02 (PUT full update):
- `@RequireRole({ADMIN})`
- Find user via `findByIdIncludingArchived(id)`, update all fields from request
- Save and return assembled EntityModel

**patchUser(Long id, PatchUserRequest request)** — per USER-02, USER-03, USER-04:
- `@RequireRole({ADMIN})`
- Find user via `findByIdIncludingArchived(id)`
- Update only non-null fields from request
- **Headman revoke cascade (D-13):** If `request.isHeadman() != null && request.isHeadman() == false && user.isHeadman()`: within same `@Transactional`, call `headmanAssistantRepository.revokeAllByGroupId(user.getGroupId())` then set `user.setHeadman(false)`
- **Headman assign (USER-03):** If `request.isHeadman() != null && request.isHeadman() == true`: set `user.setHeadman(true)`. Validate user role is STUDENT
- **Soft delete (D-14):** If `request.status() == ARCHIVED`: set `user.setStatus(AccountStatus.ARCHIVED)`
- Save and return

**archiveUser(Long id)** — per USER-02:
- `@RequireRole({ADMIN})`
- Find via `findByIdIncludingArchived(id)`, set status=ARCHIVED, save
- Return 204 No Content

**transferStudent(Long id, TransferStudentRequest request)** — per USER-05:
- `@RequireRole({ADMIN})`
- `@Transactional`
- Find user, validate role=STUDENT
- Find current active StudentGroupHistory via `findByUserIdAndLeftAtIsNull(id)`, set `leftAt=LocalDate.now()`, set `reason=request.reason()`
- Create new StudentGroupHistory: userId, groupId=request.newGroupId(), joinedAt=LocalDate.now()
- Update user.groupId = request.newGroupId()
- If user was headman in old group: set isHeadman=false, revokeAllByGroupId(oldGroupId) (same cascade as D-13)
- Save all, return updated user

**getMe()** — per D-06, USER-06:
- `@RequireRole({STUDENT})`
- Get userId from `requestContext.getUserId()`
- Find user by id, return assembled
