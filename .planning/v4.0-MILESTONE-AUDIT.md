## Integration Issues

### INT-01: Missing @RequireRole on ReportController (Medium)

**Affects:** RPRT-01, RPRT-02, RPRT-03, RPRT-04

All 4 report endpoints in `ReportController.java` lack `@RequireRole` annotations. The business-level authorization in `ReportService.authorizeHeadmanOrTeacher()` handles headman/teacher checks, but the AOP role gate that rejects unauthenticated requests is bypassed.

- RPRT-01/02 (headman/teacher endpoints): Unauthenticated call hits `authorizeHeadmanOrTeacher` which throws `AccessDeniedException` (403) — functional but inconsistent with other controllers.
- RPRT-03/04 (student endpoints): Unauthenticated call passes `requestContext.getUserId()` as null to MongoDB query, returning 200 with empty data instead of 403.

**Fix:** Add `@RequireRole({UserRole.STUDENT, UserRole.TEACHER})` to each ReportController method, consistent with the pattern in CheckinController and MarkingController.

### INT-02: Report URL Path Convention (Low)

**Affects:** RPRT-01, RPRT-02, RPRT-03, RPRT-04

`ReportApi` uses `@RequestMapping("/reports")`, so gateway-exposed paths are `/api/reports/*`. Milestone documentation references `/api/attendance/reports/*`. Either update gateway routing or documentation.
