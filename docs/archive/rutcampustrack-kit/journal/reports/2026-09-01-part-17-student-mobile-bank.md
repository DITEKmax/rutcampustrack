## Ответы на вопросы

- Существующие экраны на странице 24 оставлены на месте: 31-кадровый probe,
  shell, states и adapters не удалены и не переставлены. Новая группа
  `PRODUCT / Student screens 10–19` добавлена ниже.
- Собран весь основной student-bank, а не один экран за пользовательский цикл.
  При этом Figma записывалась последовательно: один мастер или кадр за одну
  мутацию с отдельным readback; субагенты работали только с анализом и QA.
- Нумерация семейная: первая цифра `1` означает student. Номер 12 повторён для
  «по дням / по предметам», номер 19 — для «Ещё / Профиль / Смена роли».
  Итого 10 семейств, 13 реальных канонических кадров.
- Для редактирования владельцем показан один понятный dark-кадр каждого
  маршрута. Матрица 320/360/390/430, PWA/TMA и все состояния не размножалась
  рядом с каждым экраном: она остаётся в сохранённом probe.

## Варианты и принятое решение

- Принята спокойная непрозрачная структура для данных и принятый mobile glass
  для нижней навигации. `color/accent/now` используется у текущего момента и
  выбранного пункта; активная навигация может быть самым сильным акцентом.
- Desktop-таблицы, месячный календарь рядом со списком, широкие рейтинги и
  многостолбцовые журналы отклонены: они требуют горизонтального переноса и
  не отвечают на мобильную задачу за 1–3 касания.
- Для карты отклонено изображение несуществующего плана. Принято существующее
  состояние «Для этого этажа схема не загружена» до появления реального ассета.
- Для Profile сначала был только вход-маршрут. Финальная независимая QA нашла
  незамкнутый flow, поэтому добавлен отдельный task «19 · Смена роли» с
  существующим `RoleSwitcher`.

## Подсчёт касаний

- `Сегодня → Отметиться → подтвердить отметку`: 2 касания от Today; 1 касание
  действия при входе сразу в task/deep link.
- `Посещаемость → по дням / по предметам`: 1 касание на смену режима.
- `Пропуск → Подтвердить 10:40 → Отправить`: 2 касания от конкретного события.
- `Ещё → Статистика / Карта / Заявки`: 1 касание внутри root «Ещё».
- `Профиль → Сменить роль → Староста`: 2 касания от Profile и 3 от любого root.
- `Профиль → Оформление / Безопасность / Сеансы / История`: 1 касание.

## Что убрано или переработано

- Массовая отметка, batch-selection и Checkbox не используются.
- В расписании нет повторного CTA: действие остаётся только в текущей паре.
- «Посещаемость» в строках заменена существующими круглыми статусами `+ / Н / У`.
- Из screen 13 удалён счётчик попыток: он относится к `н → +`, а не к
  подтверждению уважительной причины.
- В screen 11 иконка выполненной посещаемости заменена нейтральной иконкой
  «Сегодня», чтобы состояние «Можно отметиться» не читалось как успех.
- В screens 12 и 16 процент предмета оставлен один раз; подпись внутри
  `ProgressScale` скрыта.
- Desktop Homework cards заменены мобильной композицией без сжатых колонок;
  действие `Готово` и ссылка `Материалы` имеют прямой смысл.
- В Homework detail убраны повторный текст и внутренний маленький link;
  оставлена одна 44 px ссылка `Материалы к заданию`.
- В map убран desktop `BuildingFloorPicker`; используются два вертикальных
  `SelectField` и существующий empty-state.
- В tickets убраны desktop `TicketCard`, дублирующий таб
  «На рассмотрении» и сильная danger-кнопка отмены.
- В Profile добавлен маршрут смены роли; список ролей не выводится из прав и
  всегда приходит с сервера.
