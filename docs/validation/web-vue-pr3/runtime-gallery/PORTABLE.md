# Единый HTML просмотра

Скачайте [portable.html](portable.html) через Download raw file в GitHub и откройте
локально. Файл размером 202059 байт содержит поиск и метаданные 201 runtime-кадра.
PNG загружаются из публичного GitHub по неизменному commit
`e48b569846a536c94b62ca2319de6c2c7228d75c`; для изображений нужен интернет.
Внешних скриптов и hosting/deploy нет. Для полностью локального просмотра
checkout содержит обычный [index.html](index.html), manifests и исходные PNG.

У каждого кадра есть постоянный ID, экран, состояние, тема, ширина, revision,
название, описание и SHA256. Первые 22 исторических кадра помечены отдельно.
Reference/Figma в эту галерею не включены. Число кадров не равно числу тестов:
реализовано 115/117 действий, локально подтверждено 111/117. Настоящий check-in
выполнен на source1aea; новый readonly-снимок43b7 не повторяет эту команду.

[Текущая проверка данных](portable-check.json) сверяет 201 уникальный ID,
безопасные пути и хеши PNG. Код отрисовки и фильтров побайтно совпадает с прежним
HTML. После изменения только данных/pin/count браузерная проверка не повторялась.
Новый PNG действительно скачан с закреплённого commit через наследуемый HTTPS
proxy с проверкой TLS: 128884 байта, SHA256
`95a0d585a4a863b12ef655f5e3c74d9696c74d1250006892e830240e62539510`.

[Прежний browser smoke](portable-check-200-51e46f715.json) сохраняет исходный
pin51e46f715 и хеш HTML с 200 кадрами. Проверены фильтры, пустая выдача,
22 исторических кадра, реальный PNG и отсутствие JS-ошибок. Smoke использовал
localhost HTTP: политика облачного браузера запрещает file://. Изображения
передавались через Playwright API с доверенным CA среды и включённой проверкой
TLS; прямое доверие Chromium к proxy CA этим не подтверждено. Первые ошибки
транспорта и cleanup сохранены; финальная команда завершилась с exit0,
собственные браузер и сервер закрыты. Новая кампания для 201 кадра не запускалась.
