Output: PublicKeyConfig (key fetch + cache), JwtAuthenticationFilter (GlobalFilter), updated application.yml and GatewayApplication.

    **Create `JwtAuthenticationFilter.java`** in package `ru.rutcampustrack.gateway.filter`:

    - Annotate with `@Component`
    - Implement `GlobalFilter, Ordered`
    - Constructor-inject `PublicKeyConfig publicKeyConfig`
    - Logger: `private static final Logger log = LoggerFactory.getLogger(JwtAuthenticationFilter.class)`

    **Public routes whitelist** (FR-9.1 — use FULL gateway paths, NOT stripped paths):
    ```java
    private static final Set<String> PUBLIC_PATHS = Set.of(
            "/api/auth/login",
            "/api/auth/refresh",
            "/api/auth/public-key"
    );
    private static final List<String> PUBLIC_PREFIXES = List.of(
            "/api/auth/otp/"
    );
    ```

    **`filter(ServerWebExchange exchange, GatewayFilterChain chain)`**:
    1. Get path: `exchange.getRequest().getURI().getPath()`
    2. If `isPublicRoute(path)` → return `chain.filter(exchange)` immediately
    3. Get Authorization header: `exchange.getRequest().getHeaders().getFirst(HttpHeaders.AUTHORIZATION)`
    4. If null or not starting with `"Bearer "` → return `unauthorized(exchange)`
    5. Extract token: `authHeader.substring(7)`
    6. Try-catch block (catch `JwtException | IllegalArgumentException`):
       - Parse: `Jwts.parser().verifyWith(publicKeyConfig.getPublicKey()).build().parseSignedClaims(token).getPayload()`
       - Build mutated request with headers:
         - Always: `.header("X-User-Id", claims.getSubject())`
         - Always: `.header("X-User-Role", claims.get("role", String.class))`
         - Null-safe for group_id: `Object groupId = claims.get("group_id"); if (groupId != null) requestBuilder.header("X-Group-Id", String.valueOf(groupId));`
         - Null-safe for is_headman: `Object isHeadman = claims.get("is_headman"); if (isHeadman != null) requestBuilder.header("X-Is-Headman", String.valueOf(isHeadman));`
       - Return `chain.filter(exchange.mutate().request(mutatedRequest).build())`
    7. On catch → log debug "JWT validation failed: {}" with exception message, return `unauthorized(exchange)`

    **`isPublicRoute(String path)`**: return true if `PUBLIC_PATHS.contains(path)` OR any `PUBLIC_PREFIXES` prefix matches via `path::startsWith`.

    **`unauthorized(ServerWebExchange exchange)`**: set status `HttpStatus.UNAUTHORIZED`, return `exchange.getResponse().setComplete()`. Empty body (no RFC 7807 body needed per research recommendations).

    **`getOrder()`**: return `-100` (run before routing filters).

    Imports needed: `io.jsonwebtoken.Claims`, `io.jsonwebtoken.JwtException`, `io.jsonwebtoken.Jwts`, `org.slf4j.Logger/LoggerFactory`, `org.springframework.cloud.gateway.filter.GatewayFilterChain`, `org.springframework.cloud.gateway.filter.GlobalFilter`, `org.springframework.core.Ordered`, `org.springframework.http.HttpHeaders`, `org.springframework.http.HttpStatus`, `org.springframework.http.server.reactive.ServerHttpRequest`, `org.springframework.stereotype.Component`, `org.springframework.web.server.ServerWebExchange`, `reactor.core.publisher.Mono`, `ru.rutcampustrack.gateway.config.PublicKeyConfig`, `java.util.List`, `java.util.Set`

    **CRITICAL anti-patterns to avoid:**
    - Do NOT use `OncePerRequestFilter` or `HttpServletRequest` — this is reactive WebFlux
    - Do NOT use `parseClaimsJws()` — deprecated in JJWT 0.12, use `parseSignedClaims()`
    - Do NOT use `setSigningKey()` — removed in JJWT 0.12, use `verifyWith(PublicKey)`
    - Do NOT call WebClient or any blocking I/O inside the filter method
    - Do NOT use `String.valueOf(claims.get("group_id"))` without null check — it returns "null" string which confuses downstream
