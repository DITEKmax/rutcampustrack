## Сохраняемые эксплуатационные ограничения

Существующее M15 исключение DS-0002 для перечисленных nginx Dockerfile
сохранено при замене путей прежних PWA/TMA на Vue. Работа nginx от root
остаётся известным риском. Нового согласования владельцем этого риска
11 октября не было. Переход на непривилегированный nginx требует отдельного
согласованного изменения портов, proxy и проверки runtime. Новые исключения
CVE не добавляются. Долг незавершённой веб-панели сохраняется до её разработки.

Проверка индексов должна отличать создание новой таблицы от online-индекса
существующей таблицы. Применённые атомарные миграции допускаются только
точным списком index/version с объяснением; общий cutoff не передвигается
ради PASS. Исторический `V27` Academic, `idx_sgh_group_user_joined`, — отдельное
исключение неизменяемой миграции, не утверждение об атомарной необходимости.
При обновлении нагруженной существующей БД его обычное создание индекса
может задержать запись; допустимость этой задержки локальными тестами
не доказана. Будущие online-индексы существующих таблиц требуют отдельной
миграции `CREATE INDEX CONCURRENTLY` и companion `.sql.conf` с
`executeInTransaction=false`. Комментарий `-- ##` не заменяет эту настройку.

Текущее задание не выполняет production-миграции или ручной deploy.
Automatic Deploy после успешного CI сохраняется по явному решению владельца.
