# Демонстрация экранов RutCampusTrack

Открой `index.html` локально. Активны две автономные галереи:

- `student-final.html` — финальные экраны студента, сгруппированные по типам.
- `headman-profile-more.html` — реальные общие компоненты профиля и меню старосты.

Слева PWA, справа браузерная TMA. Поиск, фильтр типов, увеличение кадра и нижние кадры работают без сервера; изображения и шрифты встроены. Это демонстрация сохранённых состояний компонентов, не интерактивная копия приложения.

Состояния реальных компонентов с тестовым API. TMA показана в браузерной оболочке; работа внутри Telegram и обновление общего локального стенда не подтверждены. Выбор темы сохраняется, палитра пока тёмная.

Шесть предыдущих HTML сохранены неизменными как архив; текущий index показывает только финальные галереи. `manifest.json` содержит точные количества и SHA256 активных файлов, исходную provenance архивов и SHA256 их сохранённых рабочих байтов.
