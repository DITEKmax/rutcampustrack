1. ПК-105 Карта — сначала задай мне вопрос, а не додумывай.
   В API есть POST /attendance/checkin (геоотметка), блокировки пары старостой

   Но геоотметка с настольного компьютера сомнительна: точность браузерной
   геолокации на десктопе низкая, студент за ПК.
   Спроси меня: на ПК этот экран информационный (где проходит пара, корпус,
   аудитория) или на нём тоже происходит отметка?
   Разбор начинай после моего ответа.

   Если отметка есть — обязательно опиши состояния разрешения геолокации:
   не запрошено / запрошено / разрешено / отклонено / недоступно,
   а также: пара заблокирована старостой, гео отключено, вне зоны, время вышло.

   Важно: в API НЕТ эндпоинтов с координатами зданий, аудиторий или разрешённых зон.
   Откуда карта берёт геометрию кампуса и радиус — не выдумывай.
   Опиши, что нужно экрану, и пометь [предложение по бэкенду].

2. ПК-107 Заявки и тикеты — в API это ДВЕ разные сущности:
   - тикеты о пропуске: POST /attendance/excuses, POST /attendance/excuses/with-file,
     GET /attendance/excuses/me, GET /attendance/excuses/{id};
     статусы меняет не студент (PATCH .../status — сторона согласующего);
   - запросы на отметку старосте: POST /attendance/late-checkin/{lessonId}.

   Определи по скану и уточни у меня: это один общий список или два раздела.
   Для загрузки файла опиши состояния: выбор, загрузка с прогрессом, успех,
   ошибка размера, ошибка формата, удаление вложения, превью.
   Для статусов — что видит студент: на рассмотрении, одобрено, отклонено,
   и есть ли причина отклонения.

3. ПК-108 Настройки — доступно в API:

   POST/DELETE /push/subscribe + GET /push/vapid-public-key (web push работает

   Эндпоинта для редактирования остальных полей профиля НЕТ — только аватар.

   подтверждения и обратную связь.
   Если на экране есть переключатель темы — учти, что тем две (dark/light).
