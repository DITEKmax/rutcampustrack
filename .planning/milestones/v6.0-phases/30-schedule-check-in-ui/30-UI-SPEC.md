| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap (`gap-1`), badge inner padding |
| sm | 8px | Compact stacking inside cards (`gap-2`), status badge padding `px-2 py-0.5` |

| 2xl | 48px | — (reserved, not used in this phase) |
| 3xl | 64px | — (reserved, not used in this phase) |

- Touch targets: all interactive elements minimum `44px` height and `44px` width (`min-h-[44px] min-w-[44px]`). Source: `BottomNav.tsx` pattern.

- Offline banner clearance: when offline banner is visible (h-8 = 32px), page content gains `pt-8` to avoid overlap.

| `absent` | `bg-red-100` | `text-red-700` | н |
| `excused` | `bg-yellow-100` | `text-yellow-700` | у |

## Interaction Contracts

### WeekDayTabs navigation

- 7 tabs, one per day of the current week (Mon–Sun), labeled with abbreviated day names: Пн, Вт, Ср, Чт, Пт, Сб, Вс
- Under each day abbreviation: date number (e.g. "6")
- Active tab: `text-primary font-semibold`, bottom border `border-b-2 border-primary` or filled pill `bg-primary text-primary-foreground rounded-full`
- Inactive tabs: `text-muted-foreground`
- Strip scrolls horizontally if needed on small screens (unlikely for 7 short items but handle gracefully)
- Tapping a tab updates the displayed lesson list without a page reload (local state, no navigation)
- Default selected tab: today's day of week; if today is weekend, select the nearest past weekday (Friday)
- Tab change transition: `AnimatePresence` with `initial={{ opacity: 0, x: 8 }} animate={{ opacity: 1, x: 0 }} exit={{ opacity: 0 }}` duration 0.12s
- Swipe gesture on the lesson list (horizontal swipe) advances to the next or previous day tab — use `motion` drag with `dragDirectionLock` and `onDragEnd` threshold of 50px

### Check-in flow

1. Student taps "Отметиться" button on an active lesson card
2. Button immediately shows GPS spinner (replace label text with `<span class="h-4 w-4 animate-spin rounded-full border-2 border-primary-foreground border-t-transparent"/>`) — pattern from LoginPage
3. Browser calls `navigator.geolocation.getCurrentPosition` with timeout 10000ms, maximumAge 30000ms
4. If GPS denied or unavailable: show failure toast "Не удалось получить геолокацию. Разрешите доступ в настройках браузера"
5. On GPS success: POST to `/api/attendance/check-in` with `{ lessonId, latitude, longitude }`
6. On API success (HTTP 200): show success toast "Отметка принята" — auto-dismiss 3s
7. Button enters `disabled` state after success (cannot re-check-in); update card to show personal attendance status as `present`
8. On API failure: show failure toast with specific message (see Copywriting Contract)
9. Button re-enables after failure (student can retry if appropriate)
10. Total perceived time from tap to toast on good connection: under 3 seconds (per CHKIN-01 success criterion)

### Real-time update (STOMP WebSocket)

- Connect to STOMP at `ws://[gateway]/api/ws` on app mount (after auth)
- Subscribe to topic `/topic/attendance/{groupId}` for `attendance.marked` events
- On event received: update the attendance count (`X / Y чел`) on the matching lesson card using React Query `queryClient.setQueryData` (no re-fetch)
- Count update animation: `motion` layout animation on the count span, `transition={{ type: "spring", stiffness: 300, damping: 30 }}`
- No toast for other students' check-ins — only silent count update

### Offline / stale cache

- TanStack Query `staleTime` for schedule queries: 60 * 60 * 1000 (1 hour) — overrides the global 5-minute default
- When `navigator.onLine === false` AND cached data is available: render the lesson list normally; show `OfflineStaleNotice` inline banner below the day tabs
- When offline AND no cache: show empty state "Нет данных. Подключитесь к интернету для загрузки расписания"
- The "Отметиться" button is disabled when `navigator.onLine === false` (check-in strictly requires network)

## Animation Contracts

All animations use `motion/react`. Durations follow the Phase 29 baseline: 0.15s for page transitions.

| Interaction | Animation | Duration |
|-------------|-----------|----------|
| Day-tab switch (lesson list) | `opacity: 0→1, x: ±8→0` via `AnimatePresence mode="wait"` | 0.12s easeOut |
| Swipe to next/prev day | `motion` horizontal drag, threshold 50px, snap via tab state update | gesture |
| Toast slide-in (success) | `y: 64→0, opacity: 0→1` | 0.2s easeOut |
| Toast slide-out (auto) | `y: 0→64, opacity: 1→0` | 0.15s easeIn |
| Check-in button GPS loading | CSS `animate-spin` on border spinner (no Motion needed) | continuous |
| Attendance count update | `motion` layout animation on count span | spring stiffness 300 damping 30 |
| LessonCard mount | `opacity: 0→1` staggered via `motion` with `staggerChildren: 0.04s` on the list container | 0.04s per card |

No parallax, no decorative animations. All animations serve state feedback or orientation purposes.
