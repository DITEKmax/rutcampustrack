**2. Create `frontends/pwa/src/features/homework/api.ts`:**

Four exports:

- `useActiveSemester()`: `queryKey: ['semester', 'active']`. `queryFn` calls `apiClient.get('/academic/semesters', { params: { size: 50 } })`. Extracts `data._embedded?.semesterResponseList ?? data._embedded?.[Object.keys(data._embedded ?? {})[0]] ?? []`. Finds entry where `active === true`. Returns `active?.id ?? null` as `number | null`. `staleTime: 24 * 60 * 60 * 1000` (24hr -- semester rarely changes).

- `useHomework(groupId: number | undefined, semesterId: number | null | undefined)`: `queryKey: ['homework', groupId, semesterId]`. `queryFn` calls `apiClient.get('/academic/homeworks', { params: { groupId, semesterId } })`. Extracts `data._embedded?.homeworkResponseList ?? data._embedded?.[Object.keys(data._embedded ?? {})[0]] ?? []`. Returns `HomeworkResponse[]` (normalized flat array -- critical per Research Pitfall 4 for optimistic updates). `staleTime: 60 * 60 * 1000` (1hr per D-07), `refetchOnReconnect: true` (per D-08), `enabled: !!groupId && !!semesterId` (per Research Pitfall 3 -- don't fetch until semesterId resolves).

- `useToggleHomework()`: `useMutation` with `mutationFn: async ({ id, completed }: { id: number; completed: boolean }) => { if (completed) { await apiClient.post(`/academic/homeworks/${id}/complete`) } else { await apiClient.delete(`/academic/homeworks/${id}/complete`) } }`.

  Optimistic update (per D-02):
  - `onMutate`: Cancel queries `['homework']`. Snapshot previous data via `queryClient.getQueryData`. Update cache using `queryClient.setQueryData(['homework', groupId, semesterId], (old: HomeworkResponse[] | undefined) => old?.map(h => h.id === id ? { ...h, completed } : h))`. Return `{ previous }`.
  - `onError`: Revert cache: `queryClient.setQueryData(['homework', groupId, semesterId], context?.previous)`. Return error info so component can show inline error.
  - `onSettled`: `queryClient.invalidateQueries({ queryKey: ['homework'] })`.

  The mutation function accepts `{ groupId, semesterId }` alongside `{ id, completed }` so `onMutate` can target the correct cache key.

- Re-export `useSubjectName` from `@/features/schedule/api` for convenience: `export { useSubjectName } from '@/features/schedule/api'`.
