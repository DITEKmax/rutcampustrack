## Контракт переноса

1. На главной сначала ручной учёт. В боковой колонке независимый выбор пары в закрытом по умолчанию журнале, задания и прямые ссылки на заявки. Ручное «у» сохраняет выбранных студента и пару, причину, валидацию и обработку отказа.
2. В журнале и статистике остаются недельный и предметный режимы, фиксированные заголовки, внутренняя прокрутка и параметры выгрузки. Динамика раскрывается по запросу и сохраняет выбранное состояние.
3. В заявках в сводке ФИО, причина, период и статус. Подробности и решение доступны после раскрытия, исходный состав пар и право принять решение берутся из сервера. В ДЗ упорядочены редактор и история. Иллюстрации относятся к подтверждённому пустому результату фильтра.
4. В группе отделены права, лимит и восстановление доступа выбранного студента. В редакторе предмета первыми идут название и типы. Конструктор и управление парами используют компактные ячейки, различимые состояния и точные идентификаторы.
5. Общие настройки, карта, меню и уведомления проверяются в роли старосты на компонентах, перенесённых в Web студента. Полный патч из архива расходится с уже изменённым профилем.

## Первые наблюдения

- В эталоне на 1280 CSS px активная пара имеет заливку `#DDCFF9`. Журнал открывается справа и сохраняет свой выбор пары. В соседней области ссылки содержат точные ID 8000 и 8001.
- В строке ручного «у» пустая причина блокирует подтверждение. Выбор «Болезнь» включает кнопку. Отмена закрывает строку.
- В широком прогоне Web студента обнаружены два устаревших ожидания мобильного интеграционного теста. После принятого изменения карточки счётчики переехали в детали, а фильтр архива получил доступные кнопки. Тесты обновлены с проверками серверных счётчиков, свежего подтверждения и фильтрации.

## Исправления после независимого ревью

- Ссылка на заголовок под `v-for` в Vue оказалась массивом. В браузере открытие настроек вызывало ошибку фокуса. После исправления фокус последовательно пришёл в карточку Бориса, затем Алексея и вернулся к его кнопке после закрытия.
- Неделя публикуется независимо от дополнительного запроса меток. При задержке этого запроса на 8,5 секунды сетка появилась примерно за 0,7 секунды. Обычная пара открылась и осталась доступна после отказа. Кнопка «Обновить пометки» доступна отдельно.
- При конфликте смены аудитории введённое значение А-917 сохранилось. После отправки с ревизией 1 получена актуальная пара 90002 с ревизией 2 и аудиторией Б-777. Явный повтор ушёл с ревизией 2, затем сетка показала А-917.
- На 390 CSS px при шрифте 125% корневой размер 20 px, ячейка 175 px. Область прокрутки 341 px при содержимом 1400 px. Страница целиком не прокручивается по горизонтали. Снимок и замеры в `.agent/evidence/web-headman-v2/vue-schedule-390-font125.png` и `corrections-browser.json`.
- При увеличенном шрифте найдено обрезание второй строки названия. После исправления «Информационные системы» занимает две целые строки по 22,75 px. В выборке из 20 карточек управления парами нет частично обрезанных строк названия или статуса. Полное доступное имя сохранено. Замеры в `schedule-text-fit.json`.
- Перепроверка трёх исправлений и отдельная перепроверка переноса текста прошли. Загруженные главные Vue и HTML сохранены в `vue-headman-home-1280.png` и `proposal-headman-home-1280.png`.

## Сборка и серверные проверки

- Строгая сборка Web, 101 тест в восьми файлах, проверка diff и ESLint изменённых строк прошли. После исправлений прошли строгая сборка и 87 целевых тестов. Vite выдал существующее предупреждение о чанке более 500 КБ.
- На MongoDB прошли четыре сценария HTTP записи и прав журнала, два сценария частичного решения и один сценарий формирования DOCX. Два MVC-теста проверили бинарную выдачу вложения и ограничение запроса бюджета.
- На PostgreSQL прошли четыре адресных сценария. Для ДЗ проверены создание по дате, точный повтор, редактирование, история и архив. Для выгрузок проверены отозванное право помощника, запрет на состав группы и чтение того же артефакта после восстановления. В первом прогоне выявлены CRLF в тестовой копии миграции и отсутствующая схема события. После восстановления тестовых файлов из Git адресные сценарии прошли. Дополнительный первый тест про неизменность параметров выгрузки при активации семестра остановился на дедлайне холодного Auth gRPC, до выполнения бизнес-проверки. Логи обоих прогонов сохранены в `.agent/evidence/web-headman-v2/checks`.
- Тесты создания разовой пары с точным ID и запрета чужой группы на PostgreSQL описаны в [мобильном пакете старосты](02-HEADMAN-MOBILE.md). Web использует тот же контракт.
