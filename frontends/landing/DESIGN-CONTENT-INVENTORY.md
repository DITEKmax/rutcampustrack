# Дизайн и типографика RutCampusTrack

Карта материалов для страницы «Дизайн и типографика». В ней 84 идеи по Web, PWA, Telegram Mini App, общим компонентам, дизайн-источникам и самому Vue-лендингу. Для кадров интерфейсов лендинга в первую очередь используем PWA. Web и TMA помогают объяснить решения на уровне проекта. [Страница на стенде](http://127.0.0.1:14312/presentation/design/)

Источники разделены по смыслу. Файлы Vue и PCSS показывают реализацию в этой рабочей копии. Figma-спецификации и брендбук фиксируют намерение. Сохранённые кадры и галереи показывают состояние на момент съёмки. Ниже предложены форматы будущей страницы. Иллюстрации, демонстрации и вырезки для публикации ещё предстоит собрать.

| Формат | Что стоит показать |
| --- | --- |
| **Figma** | Кадр, матрица состояний, Variables и Component Set. Использовать выбранный подтверждённый исходник или сохранённый снимок с версией. |
| **Код** | Небольшая вырезка Vue, PCSS, TS или JSON, которая объясняет одну видимую деталь. Рядом результат её применения. |
| **Витрина** | Пара кадров, короткий переход, интерактивный стенд на синтетических данных или аннотированный экран. |

В Figma брать утверждённые фрагменты Variables, Component Sets и сохранённые панели состояний. В кодовой вставке показывать одну связь между источником и результатом, например `tabular-nums` рядом с выравниванием времени. Для сцен с одинаковой разметкой подходят переключатели «две темы», «цвет / без цвета», «обычное / сокращённое движение». Для меняющегося сценария подходят последовательность кадров и доступная альтернатива действию, например подтверждение с клавиатуры для свайпа ДЗ. Для сравнений фиксировать ширину, тему, роль и ревизию.
