    ```java
    private void handleOneOffLessonCancelled(Map<String, Object> envelope) {
        Map<String, Object> payload = extractPayload(envelope);
        if (payload == null) return;
        Long groupId = extractLong(payload, "group_id");
        String dateStr = (String) payload.get("date");
        Integer lessonNumber = ((Number) payload.get("lesson_number")).intValue();
        if (groupId == null || dateStr == null || lessonNumber == null) {
            log.warn("lesson.one_off.cancelled: missing fields, ignoring: {}", payload);
            return;
        }
        LocalDate date = LocalDate.parse(dateStr);
        lessonEventService.processOneOffLessonCancelled(groupId, date, lessonNumber.shortValue());
    }
    ```

    2. В `LessonEventService.java` добавить метод:
    ```java
    /**
     * D-22: Каскадно удаляет attendance docs для разовой пары при получении lesson.one_off.cancelled.
     * Idempotent: если docs уже удалены — нет ошибки (deleteResult.deletedCount может быть 0).
     */
    public void processOneOffLessonCancelled(Long groupId, LocalDate date, Short lessonNumber) {
        Query filter = Query.query(
            Criteria.where("group_id").is(groupId)
                    .and("lesson_date").is(date)
                    .and("lesson_number").is(lessonNumber)
        );
        DeleteResult result = mongoTemplate.remove(filter, AttendanceDocument.class);
        log.info("lesson.one_off.cancelled: groupId={}, date={}, lessonNumber={}, deletedCount={}",
                groupId, date, lessonNumber, result.getDeletedCount());
    }
    ```

    ВАЖНО: Использовать `mongoTemplate.remove(filter, AttendanceDocument.class)` — этот паттерн уже используется в LessonEventService для других операций. Idempotency гарантируется MongoDB: remove на пустую коллекцию просто возвращает 0 deleted.
