## 1. Соглашения об именовании

- Компоненты — `PascalCase`, семантические, без указания на визуал: `LessonCard`, не `BlueBox`.
- Layout-обёртки — суффикс `Layout` или `Shell`: `AppShell`, `AuthLayout`.
- Состояния — отдельными компонентами: `EmptyState`, `ErrorState`.
- Не использовать в именах: цвета, размеры в пикселях, позиционирование.
- **Варианты вместо синонимов.** Если компонент показывает ту же сущность в другой компоновке — это `variant`, а не новый компонент. Действующие примеры: `LessonCard` (`featured` / `row` / `cell`), `HomeworkItem` (`compact` / `full`), `TicketForm` (`excused` / `absent`), `TicketCard` (`pending` / `archived`), `NewPasswordForm` (`reset` / `change`), `PermissionList` (`readonly` / `editable`), `AttendanceStatusPicker` (`row` / `cell`), `HeadmanHomeworkItem` (`editable` / `readonly`), `GroupStatsTable` (`scope: all / subject`), 🆕 `TicketCard` (`pending` / `archived` / `incoming`), 🆕 `StatsDetailPanel` (`region` / `row`), 🆕 `ScheduleSlotCell` (`full` / `split`), 🆕 `SubjectFilter` и `LessonTypeToggleGroup` (`context: filter / form`), 🆕 `UserCreateForm` (`create` / `add-role`), 🆕 `FloorPlanUploadForm` (`create` / `replace`), 🆕 `SemesterForm` и `GroupCreateForm` (`create` / `edit`).
- Компоненты-формы — суффикс `Form`, всплывающее содержимое — `Popover`, наборы вкладок — `Tabs`, списки сущностей — `List`, поля формы — `Field`.

## 2. Владение компонентом (важно для микрофронтендов)

| Уровень | Что это | Признак |
|---|---|---|
| `shared` | Общая UI-библиотека, используется в ≥2 микрофронтендах | Не знает о домене, только UI |
| `domain` | Общий для роли/домена, но не для всех | Знает о сущностях домена |
| `local` | Живёт внутри одного микрофронтенда | Используется в одном месте |

Правило: компонент попадает в `shared` только когда реально понадобился во втором месте. Не помещай туда «на будущее».

**Исключение — каркас приложения.** `AppShell`, `AppHeader`, `MainNav`, `RoleSwitcher`, `ProfileMenu` знают о ролях, но по определению общие для всех микрофронтендов. Владение `shared`, состав пунктов и ролей приходит снаружи пропами, внутрь не зашивается.

## 3. Layout-обёртки (владеют только размещением)

| Компонент | Назначение | Пропы (layout) | Владение |
|---|---|---|---|
| `AppShell` | Каркас авторизованных страниц: `<header>` + `<main>` + skip-link на `#main` | slots: header, main | `shared` |
| `AppHeader` | Контейнер шапки: переключатель ролей, навигация, профиль | slots | `shared` |
| `AuthLayout` | Каркас неавторизованных экранов: brand-зона + панель. Brand-зона на этапе 1 — пустая заглушка, структура решается на этапе 2 | slots: brand, panel | `local` (auth) |

| перечень аудиторий этажа | текстовый список аудиторий, наполняемый администратором. Текстовая альтернатива схеме | список кабинетов |
| назначение преподавателя | связь «преподаватель × предмет × группа × семестр», а с чата 6 — **× тип занятия**. Единица прав и границ данных роли teacher: он видит то, что покрыто его назначениями | нагрузка, привязка |

| удаление | финальное необратимое уничтожение данных. Требует пароля и **предпросмотра последствий числами** | архивация, скрытие |
| предпросмотр последствий (dry-run) | ответ сервера с количествами того, что изменится или будет уничтожено, **до** подтверждения. Образец в системе — `promote/preview` | подтверждение, предупреждение |

| спрос на этаж | сколько раз этаж открывали на 105. Часть подсистемы продуктовых событий, общей с метрикой «просмотры карты» на 131 | популярность, статистика |
| суточный прирост | разница с концом предыдущих суток. У карточек масштаба показывается всегда, у метрик активности — **только в режиме «сегодня»** | динамика, тренд |

**Отменённые термины:** «красная зона», «порог посещаемости», «свободное посещение» (снято и как статус, и как тип причины), «вид занятия» (использовать «тип занятия»), «excuse-тикет» (использовать «тикет на "у"» — ради симметрии с «тикетом на "н"»), 🆕 «массовая отметка» (механика отменена целиком, чат 4), 🆕 «`%у + н`» (метрика избыточна, используется `%(+ и у)`), 🆕 «тип предмета» (в заметках сканов 114 — читать как «тип занятия»). ✏️ **Чат 6: «Excel снят» больше не действует** — формат возвращён, перечень выгрузки docx · pdf · png · html · xlsx. 🆕 **Чат 7:** «кодовая фраза» (заменена уровнями `DangerousActionChallenge`), «массовое создание пользователей» (механика снята), «логин вида `studentXXXXX` / `teacherXXXXX`» (схема несовместима с многоролевым аккаунтом).
