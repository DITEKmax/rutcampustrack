# v9.0 Frontend Unification — Milestone Summary

**Статус:** Архивирована 2026-04-13 (план полностью выполнен, 9/9 фаз completed)
**Предыдущая:** v8.0 CI/CD, Deployment & Documentation
**Цель milestone:** Исправить критичные post-v8.0 production frontend баги и доставить полноценные web-кабинеты для STUDENT и HEADMAN, объединённые единой точкой входа `/login`. Расширить React PWA ролью HEADMAN. Перенести лендинг на `/presentation/`.

## Что сделано

### Infrastructure fixes (Phase 49)
- Nginx-маршрутизация исправлена: корневой URL больше не отправляет всех пользователей в студенческий PWA
- Лендинг доступен по `/presentation/` (не `/`)
- Три мёртвые ссылки `https://t.me/` в лендинге заменены на `/login`

### Unified login + role-based web routing (Phase 50)
- Angular `web-panel` `baseHref` мигрирован с `/panel/` на `/`
- Единый `/login` обрабатывает все 4 роли (ADMIN, TEACHER, STUDENT, HEADMAN)
- Новые role guards + role-based redirect после логина: `/admin/*`, `/teacher/*`, `/student/*`, `/headman/*`

### Student web cabinet (Phases 51-53)
Новые Angular-маршруты `/student/*`:
- `/student/dashboard` — home + quick actions
- `/student/schedule` — расписание с текущей парой highlight
- `/student/checkin` — геоотметка с STOMP real-time status
- `/student/homework` — ДЗ tracker
- `/student/stats` — персональная статистика посещаемости
- `/student/notifications` — история уведомлений
- `/student/profile` — профиль + смена пароля
- `/student/excuses` — создание/просмотр excuse-тикетов
- `/student/late-checkin` — late check-in запросы
- Non-intrusive PWA install banner (React PWA) с dismissal persistence

### Headman web cabinet (Phases 54-55)
- Backend WPAN-13 fix: relaxed `@RequireRole` для HEADMAN эндпоинтов
- `/headman/dashboard` — home + quick metrics
- `/headman/group` — управление составом группы + помощник старосты
- `/headman/subjects` — CRUD предметов и преподавателей
- `/headman/journal` — массовая отметка + bulk edit
- `/headman/excuses` — рассмотрение excuse-тикетов
- `/headman/late-checkin` — рассмотрение late check-in
- `/headman/stats` — per-subject red-zone threshold + группа-level статистика

### PWA HEADMAN mode (Phase 56)
- React PWA получил HEADMAN branch
- Новая вкладка «Группа» в BottomNav с доступом ко всем headman-функциям mobile-first
- Service Worker cache расширен для новых эндпоинтов
- 63 существующих теста сохранены зелёными

### Landing + Documentation (Phase 57)
- Новая секция `#architecture-flow` на `/presentation/` с GSAP scroll-driven анимацией (pin+scrub desktop / batch reveal mobile / static reduced-motion)
- Карточка «Староста» обновлена под v9.0 capabilities
- `CLAUDE.md`, `docs/url-layout.md`, `docs/job-stories.md`, `.planning/PROJECT.md` синхронизированы с v9.0 state
- +18 новых job stories (JS-STUDENT-WEB-*, JS-HEADMAN-WEB-*)
